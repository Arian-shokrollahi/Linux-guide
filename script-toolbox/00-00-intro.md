# اول بریم یه پیش نیازی از هر انچه قراره بخونیم ببنیم؟

## شل چیست؟
ا-**Shell** برنامه‌ای است که دستورهای تو را می‌گیرد و به سیستم‌عامل می‌گوید اجرا کند
- چند Shell معروف در لینوکس:

- ا-`bash` — رایج‌ترین گزینه
- ا-`zsh`
- ا-`fish`
- ا-`sh`
- ا-<mark>نکته:</mark>برایه دیدن مقدار شل ورود (login shell)یا همون شلی که به طور پیش فرض تنظیم شده باید به مقدار متغیر محیطی (SHELL$)رجوع کنیم----> echo $SHELL
- اما به این توجه کنید که شل فعلیتون رو نشون نمیده شلی رو نشون میده که برای هنگام ورود از اون استفاده میکند نه شلی که صد همین الان ازش استفاده میکنید.
```bash
zsh
echo $shell-->output-->/bin/bash
```
---
## اسکریپت چیست؟
**اسکریپت (Script)** یک فایل متنی است که چند دستور را به‌ترتیب داخل خود نگه می‌دارد تا بتوانی آن‌ها را یک‌جا و خودکار اجرا کنی.

## کاربرد شل اسکریپت؟
شل اسکریپت برای خودکارسازی کارهاست، مثل:
- بکاپ‌گرفتن از فایل‌ها
- نمایش وضعیت سیستم
- نصب چند برنامه با یک دستور
- مدیریت فایل‌ها و پوشه‌ها
- اجرای دستورهای تکراری
- و کلی کار دیگر ... استفاده میشود
