# 01-بریم درون این قسمت این دو چیز رو بگیم:
- در کجا درست کنیم اون فایل اسکریپت رو 
- چجوری اسکریپت هارو فعل کنیم و چه جوری از هرکجا بتونیم بهش دسترسی داشته باشیم
---
# 1)کجا درست کنیم اون فایل اسکریپت رو 
ببین👀شما بخواید هر جا اون شل اسکریپت رو درست کنید مشکلی نیست چون اون رو در متغیر محیطی PATH که مسیر هایه فایل هایه اجرایی درون اون است تعریف میکنید و اوکیه ولی به نظرم جوری درست کنید اسکریپت رو که مرتب باشد و بفهمید چی به چیه در این جا خوب توضیح دادم مطالعه کنید [script](../23-shellscript-loop/00-intro-writefirst-shellscript.md)
مثال:
- میخوام 3 اسکریپت درست کنم که درمورد سیستم بهم اطلاع بده:
- ا- mkdir -p /bin/sysinfo
- بعد این مسیر رو درون PATH تعریف میکنم
---
# 2)و اخرین نکته بریم بار دیگر توضیح بدیم 0 تا 100 فعال کردن اسکریپت فایل رو تا در هرجایی قابل دسترس باشد
- 1)درست کردن مسیری که میخواهید درون اون اسکریپت بزارید مثال: mkdir -p ~/bin
- 2)رفتن درون bashrc با ادیتورمتن مثل(vim,nano...etc) رفتن به خط اخر bashrc و اکسپورت کردن اون مسیر فایل هایه اسکریپت درون متغیر محیطی PATH با این ساختار:
```bash
export PATH="scriptsfolderpath:$PATH" -->ex: nano ~/.bashrc -->alt + / for go to 
last line next in last line write-->export PATH="~/bin:\$PATH"-->save and exit
```


- 3) اون فایل اسکریپت هم بهش دسترسی اجرا بدید
```bash
- model1) chmod +x scriptfilename
- model2) chmod 755 scriptfilename
```
- 4)حالا از هر جایی در دسترسه برنامه هایی (فایل هایه اسکریپت) که درون فولدری که مسیرش رو به متغیر محیطی PATH اضافه کردیم ساختیم 
---
# مثال پایانی چالشی :
ما اگر دو کاربر داشته باشیم ali mehdi و درون مهدی باشیم و فولدر اسکریپت درون علی باشددرون مسیر خانگی علی درون پوشه bin و ما به کاربر علی در مهدی دسترسی داشته باشیم چه میکنیم.
```bash
- 1) mehdi:~$nano ~/.bashrc
- 2)alt + / for go to last line
- 3)last line of bashrc write-->export PATH="$/home/ali/bin:\$PATH"
```
- و حالا دیگه شما به فایل هایه اسکریپتی که درون کاربر علی ساخته شده بود دسترسی دارید.
- چرا: چون که ما اومدیم مسیر فولدر اسکریپت فایل هایه کاربر علی رو به مسیر هایی که شل برایه فایل هایه اجرایی دنبالش میگرده اضافه کردیم
