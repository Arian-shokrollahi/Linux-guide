# cursor movement
---
دستورات حرکت مکان‌نما (Cursor Movement)
| کلید | عملکرد |
|---|---|
| CTRL-A | انتقال مکان‌نما به ابتدای خط |
| CTRL-E | انتقال مکان‌نما به انتهای خط |
| CTRL-F | حرکت مکان‌نما یک کاراکتر به جلو؛ مشابه کلید فلش راست |
| CTRL-B | حرکت مکان‌نما یک کاراکتر به عقب؛ مشابه کلید فلش چپ |
| ALT-F | حرکت مکان‌نما یک کلمه به جلو |
| ALT-B | حرکت مکان‌نما یک کلمه به عقب |
| CTRL-L | پاک کردن صفحه و انتقال مکان‌نما به گوشه بالا-چپ؛ مشابه دستور clear |
