# history command
---
## دستور history برایه چی استفاده میشه
در لینوکس دستور `history` برای **دیدن تاریخچه دستورهایی که قبلاً در ترمینال اجرا کرده‌ای** استفاده می‌شود.

یعنی Bash (یا Shellهای دیگر) دستورهایی که می‌زنی را ذخیره می‌کند و با `history` می‌توانی دوباره آن‌ها را ببینی.

### استفاده ساده:

```
history
```

خروجی چیزی شبیه این است:

```
  101  ls
  102  cd /etc
  103  cat passwd
  104  sudo apt update
```

عدد سمت چپ شماره آن دستور است.

---

### اجرای دوباره یک دستور از history

مثلاً دستور شماره 102:

```
!102
```

اجرا می‌کند:

```
cd /etc
```

---

### اجرای آخرین دستور قبلی

```
!!
```

مثلاً:

```
sudo apt update
```

بعد می‌فهمی sudo یادت رفته:

```
sudo !!
```

اجرا می‌شود:

```
sudo apt update
```

---

### جستجو در history
- ا-<mark>من خودم عاشق اینم</mark> 😍

با `Ctrl + r`:

مثلاً:

```
(reverse-i-search)`ssh':
```

شروع کن تایپ کردن:

```
ssh
```

و دستورات قبلی که ssh داشتند را پیدا می‌کند.

---

### دیدن تعداد مشخصی از دستورات آخر

مثلاً 10 تای آخر:

```
history 10
```

---

### پاک کردن history

پاک کردن تاریخچه فعلی:

```
history -c
```

پاک کردن فایل ذخیره‌شده:

```
rm ~/.bash_history
```

---

### محل ذخیره history

در Bash معمولاً:

```
~/.bash_history
```

است.

مثلاً:

```
cat ~/.bash_history
```

---

### یک نکته مهم برای مدیریت سیستم:

اگر چند ترمینال باز داشته باشی، همه دستورها بلافاصله داخل فایل نوشته نمی‌شوند؛ Bash معمولاً هنگام خروج از Shell آن‌ها را در `~/.bash_history` ذخیره می‌کند.

برای ذخیره فوری:

```
history -w
```

برای خواندن دوباره فایل:

```
history -r
```

خلاصه:

|دستور|کاربرد|
|---|---|
|`history`|نمایش دستورات قبلی|
|`!!`|اجرای دستور قبلی|
|`!number`|اجرای دستور با شماره مشخص|
|`Ctrl+r`|جستجو در تاریخچه|
|`history -c`|پاک کردن history|
|`history -w`|ذخیره فوری history|
