# 01 ls command 
---
## دستور ls  چیست و چیکار میکند؟
دستور **`ls`** (مخفف **List Directory Contents**) یکی از پرکاربردترین دستورات لینوکس است. وظیفهٔ آن **لیست کردن و نمایش فایل‌ها و دایرکتوری‌های موجود** است.

## ساختار دستور ls به چه صورته:

```
ls [options/flags] [path]
```
- اگر هیچ مسیری ندهی، محتوای **دایرکتوری فعلی** را نشان می‌دهد.
- اگر مسیر (مطلق یا نسبی) بدهی، محتوای **همان مسیر** را نشان می‌دهد:
---
## کدوم فلگ/اپشن از همه فلگ ها مهم تره ؟
- فلگ l- (long format) مهمترین فلگ دستور ls است که شما باید بتونید خروجی اون رو کامل تحلیل کنید چون اطلاعات سوپر مهمی رو به ما میده 
- وقتی دستور `ls -l` را می‌زنی، هر خط ۷ بخش اطلاعاتی به تو می‌دهد:
```bash
-rw-r--r-- 1 tafavote tafavote 4.2K Aug 27 10:30 app.py 
drwxr-xr-x 2 tafavote tafavote 4.0K Aug 27 10:32 configs 
lrwxrwxrwx 1 tafavote tafavote   15 Aug 27 10:35 logs -> /var/log/nginx`
```

بیایید این خط اول (`-rw-r--r-- ...`) را جزء‌به‌جزء بررسی کنیم:

1. **نوع فایل و دسترسی‌ها (`-rw-r--r--`):**
    - کاراکتر اول: نوع فایل (`-` یعنی فایل معمولی، `d` یعنی Directory، `l` یعنی Symlink).
    - ۹ کاراکتر بعدی (۳ تا ۳ تا): به ترتیب دسترسی‌های **مالک (User)**، **گروه (Group)** و **سایرین (Others)** برای خواندن (`r`)، نوشتن (`w`) و اجرا (`x`).
2. **تعداد پیوندها / Hard links (`1`):** تعداد ارجاعات مستقیم به این فایل.
3. **نام مالک / Owner (`tafavote`):** کاربری که مالک فایل است.
4. **گروه مالک / Group (`tafavote`):** گروه کاربریِ صاحب فایل.
5. **حجم فایل (`4.2K`):** اندازه فایل روی دیسک.
6. **تاریخ و زمان آخرین ویرایش (`Aug 27 10:30`):** زمان آخرین باری که فایل تغییر کرده است.
7. **نام فایل یا پوشه (`app.py`):** نام موجودیت (اگر لینک باشد با `->` مقصدش را هم نشان می‌دهد).

### حالا جلوتر با wildcards expansion ها اشنا میشیم که شما میتونید از اون ها برایه لیست کردن سریع استفاده کنید.
- 1-لیست تمام فایل هایه پایتونی
- 2-لیست تمام فایل هایی که با کارکتر c شروع میشوند
- 3-لیست فایل هایی که پسوند دو حرفی دارند
```bash
1--->ls *.py
2--->ls c*
3--->ls *.??
```

## این جا هم براتون همه فلگ ها و گزینه هارو اوردم مرتب

| flag | longflag            | description                                                                                        |
| ---- | ------------------- | -------------------------------------------------------------------------------------------------- |
| `-a` | `--all`             | نمایش تمام فایل‌ها و دایرکتوری‌ها، از جمله فایل‌های مخفی (که با `.` شروع می‌شوند)                  |
| `-A` | `--almost-all`      | نمایش همه فایل‌ها شامل فایل‌های مخفی، به جز خود `.` (پوشه جاری) و `..` (پوشه والد)                 |
| `-l` |                     | نمایش جزئیات کامل فایل‌ها به صورت لیستی (دسترسی‌ها، تعداد لینک‌ها، مالک، گروه، حجم، تاریخ و نام)   |
| `-h` | `--human-readable`  | نمایش حجم فایل‌ها به فرمت خوانا برای انسان (مانند K، M، G) — نیازمند استفاده همراه با `-l`         |
| `-t` |                     | مرتب‌سازی لیست بر اساس زمان آخرین تغییر (از جدیدترین به قدیمی‌ترین)                                |
| `-r` | `--reverse`         | معکوس کردن ترتیب مرتب‌سازی (مثلاً برعکس کردن ترتیب الفبا، زمان یا حجم)                             |
| `-S` |                     | مرتب‌سازی فایل‌ها بر اساس حجم (از بزرگ‌ترین به کوچک‌ترین)                                          |
| `-R` | `--recursive`       | لیست کردن محتوای تمام زیرپوشه‌ها به صورت تو در تو و بازگشتی                                        |
| `-d` | `--directory`       | نمایش اطلاعات خودِ پوشه به جای ورود و لیست کردن محتویات داخل آن                                    |
| `-F` | `--classify`        | اضافه کردن نماد شناسایی نوع فایل به انتهای نام (`/` برای پوشه، `*` برای اجرایی، `@` برای سیم‌لینک) |
| `-1` |                     | چاپ هر فایل در یک خط جداگانه (تک‌ستونی، مناسب برای اسکریپت‌نویسی)                                  |
| `-m` |                     | نمایش فایل‌ها در قالب یک خط پشت سر هم و جدا شده با ویرگول (`,`)                                    |
| `-i` | `--inode`           | نمایش شماره Inode (شناسه فایل در سیستم فایل دیسک) در کنار هر فایل                                  |
| `-n` | `--numeric-uid-gid` | مشابه `-l` با این تفاوت که به جای نام کاربری و گروه، شناسه عددی (UID/GID) را نشان می‌دهد           |
| `-X` |                     | مرتب‌سازی فایل‌ها به ترتیب الفبایی بر اساس پسوند (Extension) فایل                                  |
|      | `--color[=WHEN]`    | فعال یا غیرفعال کردن نمایش رنگی فایل‌ها بر اساس نوع (`auto`، `always`، `never`)                    |

---
### خلاصهٔ سریع:

- **فقط نام فایل‌ها:** `ls`
- **با جزئیات و حجم خوانا:** `ls -lh`
- **دیدن فایل‌های مخفی:** `ls -la` یا `ls -A`
- **بر اساس آخرین تغییرات:** `ls -lt`
