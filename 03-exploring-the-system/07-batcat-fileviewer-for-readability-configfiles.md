# betcat 
----
## برایه دیدن فایل هایه کانفیگ از چی استفاده کنیم که خوانایی مون بالا بره:

برایه خوندن فایل هایه کانفیگ از batcat استفاده کنید تا خوانایی تان بالا برود.

#### 1-برایه نصبش

```
sudo apt install bat -y
```

#### 2-در Ubuntu و Debian معمولاً دستور اجرایی آن batcat است:

```
batcat --paging=always /etc/nginx/nginx.conf
```

مزایای bat:

- رنگ‌بندی Syntax
    
- شماره خطوط
    
- تشخیص نوع فایل
    
- جست‌وجوی راحت‌تر
    

### چند کلید کاربردی در less

|کلید|عملکرد|
|---|---|
|`Space`|صفحه بعد|
|`b`|صفحه قبل|
|`j`|یک خط پایین|
|`k`|یک خط بالا|
|`/listen`|جست‌وجوی listen|
|`n`|نتیجه بعدی جست‌وجو|
|`g`|ابتدای فایل|
|`G`|انتهای فایل|
|`q`|خروج|

نکته: دستور `less -R` به‌تنهایی Syntax Highlighting ایجاد نمی‌کند؛ فقط اجازه نمایش رنگ‌هایی را می‌دهد که ابزار دیگری تولید کرده است.

برای کارهای روزمره مدیریت Nginx، من `batcat` را پیشنهاد می‌کنم. 🚀
