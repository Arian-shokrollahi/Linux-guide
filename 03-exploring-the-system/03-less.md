# راهنمای جامع دستور `less` در لینوکس

دستور **`less`** یکی از پرکاربردترین ابزارهای خط فرمان در سیستم‌های لینوکسی است که در دسته‌بندی **صفحه‌بندی‌کننده‌های متنی (Pagers)** قرار می‌گیرد. این ابزار برای مشاهده، پیمایش و جستجو در فایل‌های متنی طولانی بدون شلوغ کردن محیط ترمینال استفاده می‌شود.

---
## اینم مهمترین چیزه یادتون باشه اولین چیزی که برایه دستور تعاملی (interactive)باید بلد باشید این است که از اون خارج شوید چون کنترل ترمینال رو ازتون میگیرد و در این دستور شما میتونید با q خارج شوید.
---

## ۱. چرا `less`؟ (تفاوت با `cat` و `more`)

- **در مقایسه با `cat`:** دستور `cat` تمام محتوای فایل را یک‌باره در ترمینال چاپ می‌کند که برای فایل‌های طولانی (مثل لاگ‌ها) باعث پر شدن بافر ترمینال می‌شود. اما `less` فایل را صفحه‌به‌صفحه نشان می‌دهد.
- **در مقایسه با `more`:** ابزار قدیمی‌تر `more` فقط اجازه حرکت به سمت جلو (پایین) را می‌داد. نام `less` یک شوخی بر اساس عبارت *"less is more"* است؛ چرا که امکان حرکت رو به بالا، جستجوی پیشرفته و کنترل خطوط را نیز فراهم می‌کند.

- **ویژگی مهم:** `less` برای نمایش فایل، کل آن را در حافظه RAM بارگذاری نمی‌کند؛ بنابراین باز کردن فایل‌های لاگ چند گیگابایتی با آن فوق‌العاده سریع و بهینه است.

# کلید هایه میانبر درون دستور less
| کلید میانبر (Key) | عملکرد و توضیحات |
| :--- | :--- |
| **`q`** | **خروج (Quit)** از برنامه و بازگشت به ترمینال |
| **`Space`** یا **`f`** | رفتن به اندازه **یک صفحه رو به جلو** (Page Down / Forward) |
| **`b`** | رفتن به اندازه **یک صفحه رو به عقب** (Page Up / Backward) |
| **`d`** | رفتن به اندازه **نصف صفحه رو به جلو** (Half-page Down) |
| **`u`** | رفتن به اندازه **نصف صفحه رو به عقب** (Half-page Up) |
| **`j`** یا **`Enter`** یا **`↓`** | رفتن **یک خط به پایین** (Line Down) |
| **`k`** یا **`↑`** | رفتن **یک خط به بالا** (Line Up) |
| **`g`** یا **`1G`** | پرش مستقیم به **ابتدای فایل** (خط اول) |
| **`G`** (Shift + g) | پرش مستقیم به **انتهای فایل** (خط آخر) |
| **`[number]G`** (مثلاً `50G`) | پرش مستقیم به **شماره خط مشخص** (مثلاً خط ۵۰) |
| **`/pattern`** | **جستجو رو به جلو** برای کلمه/عبارت مورد نظر |
| **`?pattern`** | **جستجو رو به عقب** برای کلمه/عبارت مورد نظر |
| **`n`** | رفتن به **نتیجه بعدی** جستجو (Next Match) |
| **`N`** | رفتن به **نتیجه قبلی** جستجو (Previous Match) |
| **`F`** (Shift + f) | ورود به حالت **مانیتورینگ زنده** (مانند `tail -f`) |
| **`Ctrl + C`** | توقف مانیتورینگ زنده و بازگشت به حالت ناوبری |
| **`h`** | نمایش صفحه راهنما و لیست تمام کلیدها (Help) |

----
### نکات مهم درون دستور less:
- میتونید با slash(/)سرچ کنید اون الگو مورد نظرتون 
- برایه پایین رفتن-->j-->من اینطوری حفظ کردم جایین 
- برایه بالا رفتن--->k--> اینم اینطوری حفظ کردم کالا
