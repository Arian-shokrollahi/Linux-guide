# تفاوت Disk / Partition / File System

برای درک Storage در لینوکس باید این سه مفهوم را از هم جدا کنیم:

```
Disk
 |
 └── Partition
          |
          └── File System
                    |
                    └── Files
```

---

# 1. ا-Disk چیست؟

ا-**Disk (دیسک)** همان وسیله فیزیکی ذخیره‌سازی است.

مثال‌ها:

- HDD
- SSD
- NVMe

در لینوکس معمولاً به شکل زیر دیده می‌شود:

```
/dev/sda
/dev/sdb
/dev/nvme0n1
```

مثلاً:

```
/dev/sdb
```

یعنی یک دیسک کامل.

تصور کن یک هارد 1 ترابایتی داری:

```
+--------------------------------+
|                                |
|            1 TB Disk           |
|                                |
+--------------------------------+
```

در این مرحله هنوز مشخص نیست فایل‌ها کجا ذخیره شوند.

---

# 2. ا-Partition چیست؟

ا-**Partition یعنی تقسیم کردن یک Disk به چند قسمت منطقی.**

مثلاً یک Disk یک ترابایتی را تقسیم کنیم:

```
/dev/sdb

+-------------------------------+
|                               |
|  /dev/sdb1     500GB          |
|                               |
+-------------------------------+
|                               |
|  /dev/sdb2     300GB          |
|                               |
+-------------------------------+
|                               |
|  /dev/sdb3     200GB          |
|                               |
+-------------------------------+
```

هر Partition یک بخش جدا از Disk است.

ساخت Partition معمولاً با ابزارهایی مثل:

```
fdisk
parted
```

انجام می‌شود.

مثلاً:

```
fdisk /dev/sdb
```

نتیجه:

```
/dev/sdb1
/dev/sdb2
```

---

# 3. ا-File System چیست؟

ا-**File System ساختاری است که داخل Partition ساخته می‌شود تا بتوان فایل ذخیره کرد.**

ا-Partition به تنهایی قابل استفاده برای ذخیره فایل نیست.

مثلاً:

قبل از Format:

```
/dev/sdb1

+----------------+
|                |
|   Empty Space  |
|                |
+----------------+
```

بعد از Format:

```
mkfs.ext4 /dev/sdb1
```

نتیجه:

```
/dev/sdb1

+----------------+
|                |
|     ext4       |
|                |
+----------------+
```

حالا می‌توانیم فایل ایجاد کنیم:

```
/data

├── file.txt
├── backup.tar
└── database.sql
```

---

# مقایسه در جدول

|مورد|Disk|Partition|File System|
|---|---|---|---|
|چیست؟|سخت‌افزار ذخیره‌سازی|تقسیم‌بندی Disk|ساختار مدیریت فایل|
|فیزیکی است؟|بله|خیر|خیر|
|مثال لینوکس|`/dev/sda`|`/dev/sda1`|ext4, xfs|
|ایجاد با|خرید/اضافه کردن دیسک|fdisk, parted|mkfs|
|شامل چه چیزی است؟|Partitionها|File System|فایل‌ها و پوشه‌ها|
|قابل Mount شدن؟|معمولاً نه|بعد از داشتن File System|بله|

---

# مثال کامل در یک سرور

فرض کن یک SSD جدید اضافه کردی:

## مرحله 1: Disk

سیستم می‌بیند:

```
lsblk
```

خروجی:

```
sdb     1TB
```

یعنی:

```
/dev/sdb
```

---

## مرحله 2: Partition

تقسیم می‌کنیم:

```
fdisk /dev/sdb
```

نتیجه:

```
/dev/sdb1    1TB
```

---

## مرحله 3: File System

ا-Format می‌کنیم:

```
mkfs.xfs /dev/sdb1
```

نتیجه:

```
/dev/sdb1
 |
 XFS
```

---

## مرحله 4: Mount

وصلش می‌کنیم:

```
mount /dev/sdb1 /data
```

حالا:

```
/data

├── backup
├── logs
└── files
```

---

# یک مثال ساده برای تصور

فرض کن یک ساختمان داری:

### ا-Disk = زمین

```
زمین بزرگ
```

---

### ا-Partition = تقسیم زمین

```
زمین
 |
 +--- بخش A
 |
 +--- بخش B
 |
 +--- بخش C
```

---

### ا-File System = روش مدیریت هر بخش

مثلاً:

```
بخش A
 |
 سیستم شماره‌گذاری و مدیریت اتاق‌ها
```

---

### ا-Files = وسایل داخل اتاق‌ها

```
File System
 |
 ├── file1
 ├── file2
 └── file3
```

---

# نکته مهم لینوکسی

همیشه این ترتیب را به خاطر بسپار:

```
1) Disk
      ↓
2) Partition
      ↓
3) File System
      ↓
4) Mount Point
      ↓
5) Files
```

مثال واقعی:

```
/dev/sdb
    |
    └── /dev/sdb1
              |
              └── ext4
                    |
                    └── /data
                           |
                           └── backup.tar
```

این زنجیره پایه‌ی تمام کارهای **Storage Management در Linux Server** است.
