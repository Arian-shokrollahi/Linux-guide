## بخش اول: File System چیست؟

ا-**File System (سیستم فایل)** روشی است که سیستم‌عامل با استفاده از آن **اطلاعات را روی دیسک ذخیره، سازمان‌دهی و مدیریت می‌کند**.

به زبان ساده:

وقتی یک فایل مثل `test.txt` ایجاد می‌کنیم، سیستم‌عامل باید بداند:

- فایل کجا روی دیسک قرار گرفته است.
- حجم فایل چقدر است.
- مالک فایل چه کسی است.
- چه دسترسی‌هایی دارد.
- چگونه سریع پیدا و خوانده شود.

این وظیفه بر عهده **File System** است.

مثلاً یک هارد خام فقط مجموعه‌ای از بلوک‌های صفر و یک است. File System این فضای خام را تبدیل می‌کند به:

```
/
├── home
│   └── user
│       └── file.txt
├── var
├── etc
└── tmp
```

یعنی یک ساختار قابل فهم برای انسان و سیستم‌عامل ایجاد می‌کند.

---

# بخش دوم: انواع File System

در لینوکس File Systemهای مختلفی وجود دارند:

|File System|توضیح|کاربرد|
|---|---|---|
|**ext2**|یکی از اولین File Systemهای لینوکس، بدون Journal|سیستم‌های قدیمی|
|**ext3**|نسخه بهبود یافته ext2 با Journal|سیستم‌های قدیمی لینوکس|
|**ext4**|محبوب‌ترین File System لینوکس|سرورها و دسکتاپ|
|**XFS**|مناسب حجم‌های خیلی بزرگ و عملیات سنگین|سرورها، دیتابیس|
|**Btrfs**|امکانات پیشرفته مثل Snapshot و Compression|سیستم‌های مدرن|
|**ZFS**|بسیار قدرتمند با مدیریت Storage پیشرفته|Storage Server|
|**FAT32**|قدیمی و ساده|فلش، تجهیزات مختلف|
|**NTFS**|File System ویندوز|Windows Disk|
|**NFS**|File System شبکه‌ای|اشتراک فایل بین سرورها|
|**tmpfs**|در RAM ساخته می‌شود|فایل‌های موقت|

---

## معروف‌ترین File Systemهای لینوکس

### 1. ext4

ویژگی‌ها:

- پیش‌فرض بسیاری از توزیع‌های لینوکس
- دارای Journal
- پایدار و قابل اعتماد
- مناسب برای اکثر کاربردها

مثال:

```
/dev/sda1   ext4
```

---

### 2. XFS

ویژگی‌ها:

- سرعت بالا
- مناسب فایل‌های خیلی بزرگ
- مناسب سرورها

مثال کاربرد:

- Database Server
- Storage Server

---

### 3. Btrfs

ویژگی‌ها:

- Snapshot
- Compression
- مدیریت Volume

مثلاً:

قبل از آپدیت سیستم یک Snapshot می‌گیریم:

```
Snapshot 1
     |
Update System
     |
Problem
     |
Rollback
```

---

### 4. FAT32

ویژگی‌ها:

- تقریباً همه سیستم‌ها می‌توانند بخوانند.
- محدودیت حجم فایل دارد.

مثلاً:

فلش USB

---

### 5. NTFS

ا-File System اصلی ویندوز:

```
Windows
   |
   NTFS
```

لینوکس می‌تواند آن را Mount کند.

# بخش سوم: چرا File System ساخته شد؟

بدون File System دیسک فقط یک فضای خام است.

دلایل ایجاد File System:

---

## 1. مدیریت فایل‌ها

بدون File System نمی‌دانیم:

```
file.txt
photo.jpg
database.sql
```

کجا هستند.

---

## 2. مدیریت فضای دیسک

ا-File System مشخص می‌کند:

کدام Block آزاد است؟

مثلاً:

```
Block 1  -> file.txt
Block 2  -> empty
Block 3  -> image.png
```

---

## 3. افزایش سرعت دسترسی

به جای گشتن کل دیسک، File System مسیر فایل را می‌داند.

مثلاً:

```
/home/user/test.txt
```

سریع پیدا می‌شود.

---

## 4. کنترل دسترسی‌ها

در لینوکس File System اطلاعات Permission را نگه می‌دارد:

مثلاً:

```
-rwxr-xr--
```

یعنی:

- Owner چه کاری می‌تواند انجام دهد.
- Group چه کاری می‌تواند انجام دهد.
- Others چه کاری می‌توانند انجام دهند.

---

## 5. جلوگیری از خراب شدن اطلاعات

بعضی File Systemها مثل ext4 و XFS دارای:

**Journal**

هستند.

Journal یعنی:

قبل از تغییر واقعی، تغییرات ثبت می‌شوند.

اگر برق قطع شود:

```
Write Operation
       |
     Journal
       |
    Disk
```

سیستم راحت‌تر Recovery می‌شود.

---

# نکات پایانی مهم

### 1. Partition با File System فرق دارد

ا-Partition:

تقسیم‌بندی دیسک است.

مثلاً:

```
/dev/sda
 |
 ├── sda1
 ├── sda2
 └── sda3
```

File System:

فرمت داخل Partition است.

مثلاً:

```
/dev/sda1
       |
      ext4
```

---

### 2. هر Partition یک File System دارد

مثلاً:

```
/dev/sdb1  ---> ext4
/dev/sdb2  ---> xfs
```

---

### 3. قبل از استفاده باید Mount شود

مثلاً:

```
mount /dev/sdb1 /data
```

بعد:

```
/data
```

قابل استفاده می‌شود.

---

### 4. انتخاب File System مهم است

برای:

|کاربرد|پیشنهاد|
|---|---|
|سیستم معمولی لینوکس|ext4|
|سرور با فایل‌های بزرگ|XFS|
|Snapshot و امکانات جدید|Btrfs|
|اشتراک با ویندوز|NTFS/FAT32|
|Storage حرفه‌ای|ZFS|

---

# خلاصه نهایی

ا-**File System** ساختاری است که دیسک خام را تبدیل به محیطی قابل مدیریت برای ذخیره فایل‌ها می‌کند.

کارهای اصلی:

```
File System
     |
     ├── مدیریت فایل‌ها
     ├── مدیریت فضای دیسک
     ├── کنترل Permission
     ├── افزایش سرعت دسترسی
     └── جلوگیری از خرابی اطلاعات
```

در لینوکس مهم‌ترین‌ها:

```
ext4  → عمومی و پایدار
XFS   → سرور و فایل‌های بزرگ
Btrfs → امکانات پیشرفته
ZFS   → Storage حرفه‌ای
```

و یادت باشد:

```
Disk
 |
Partition
 |
File System
 |
Mount Point
 |
Files
```

این زنجیره پایه‌ی مبحث **Storage در لینوکس** است.
