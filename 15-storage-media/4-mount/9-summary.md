 # خلاصه خیلی کوتاه

ا-**Mount:**

> وصل کردن یک File System به یک مسیر در Linux برای قابل استفاده شدن فایل‌ها.

ا-**Unmount:**

> جدا کردن امن آن File System از مسیر، بدون حذف اطلاعات.

ساختار نهایی:

```
/dev/sdb1
    |
    ↓
  ext4
    |
    ↓
 /data
    |
    ↓
 Files
```

این مفهوم پایه‌ای است چون تقریباً تمام مدیریت Storage در لینوکس بر اساس همین ایده کار می‌کند.
