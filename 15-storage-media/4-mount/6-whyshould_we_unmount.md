# چرا باید Unmount کنیم؟

چون ممکن است هنوز اطلاعاتی در حافظه باشند که روی Disk نوشته نشده‌اند.

مثلاً:

```
Application
     |
     |
 Cache
     |
     |
 Disk
```

اگر ناگهانی Disk را جدا کنیم:

- احتمال خراب شدن File System وجود دارد.
- اطلاعات ممکن است از بین برود.

ا-Unmount باعث می‌شود سیستم:

- اطلاعات باقی‌مانده را بنویسد.
- ارتباط را امن قطع کند.
