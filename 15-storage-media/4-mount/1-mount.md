# ا-Mount چیست؟

ا-**Mount یعنی وصل کردن یک File System به یک مسیر در ساختار فایل‌های لینوکس.**

در لینوکس همه چیز داخل یک درخت فایل قرار دارد و یک Disk یا Partition جدید تا زمانی که Mount نشود، از طریق مسیرهای معمول قابل استفاده نیست.

مثلاً یک هارد جدید داری:

```
/dev/sdb1
```

داخل آن:

```
ext4 File System
```

ساخته شده است.

اما هنوز جایی در سیستم قرار نگرفته.

بعد از Mount:

```
/
|
├── home
├── var
├── etc
└── data
       |
       ├── file1
       └── file2
```

حالا `/data` به آن Disk وصل شده است.

یعنی وقتی وارد:

```
/data
```

می‌شوی، در واقع داری محتوای آن Partition را می‌بینی.
