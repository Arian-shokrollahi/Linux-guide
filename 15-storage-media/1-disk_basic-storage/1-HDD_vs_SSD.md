# 1) ا-HDD و SSD چیست؟

## ا-HDD (Hard Disk Drive)

ا-**HDD** یک نوع Storage Media است که داده‌ها را روی **صفحه‌های مغناطیسی چرخان (Platter)** ذخیره می‌کند.

داخل HDD چند بخش اصلی وجود دارد:

- **Platter** → دیسک‌های چرخان که اطلاعات روی آن‌ها ذخیره می‌شود.
- **Spindle** → موتور چرخاندن Platter
- **Read/Write Head** → هد خواندن و نوشتن اطلاعات
- **Actuator Arm** → بازویی که هد را حرکت می‌دهد

نحوه کار:

```
Data
 |
 v
Magnetic Platter
 |
 v
Read/Write Head
 |
 v
Controller
```

وقتی سیستم می‌خواهد یک فایل را بخواند:

1. Platter می‌چرخد.
2. Head به محل داده حرکت می‌کند.
3. اطلاعات خوانده می‌شود.

---

## ا-SSD (Solid State Drive)

ا-**SSD** یک Storage Media است که اطلاعات را روی **حافظه فلش NAND** ذخیره می‌کند.

برخلاف HDD:

- قطعه متحرک ندارد.
- اطلاعات به صورت الکترونیکی خوانده و نوشته می‌شود.

ساختار کلی:

```
Data
 |
 v
NAND Flash Memory
 |
 v
Controller
 |
 v
Computer
```

ا-SSD معمولاً از این بخش‌ها تشکیل شده:

- **NAND Flash** → محل ذخیره اطلاعات
- **Controller** → مدیریت خواندن و نوشتن
- **Cache** → حافظه موقت برای افزایش سرعت

---

# 2) مقایسه HDD و SSD

|ویژگی|HDD|SSD|
|---|---|---|
|روش ذخیره‌سازی|مغناطیسی|حافظه فلش NAND|
|قطعه متحرک|دارد|ندارد|
|سرعت خواندن/نوشتن|کمتر|بسیار بیشتر|
|زمان دسترسی (Latency)|زیاد|خیلی کم|
|مصرف برق|بیشتر|کمتر|
|صدای کارکرد|دارد|تقریباً بی‌صدا|
|مقاومت در برابر ضربه|کمتر|بیشتر|
|قیمت به ازای هر GB|ارزان‌تر|گران‌تر|
|طول عمر|معمولاً خوب|وابسته به میزان Write|
|ظرفیت‌های بزرگ|ارزان‌تر|گران‌تر|

---

# 3) تفاوت سرعت

مثال تقریبی:

|عملیات|HDD|SSD|
|---|---|---|
|Boot سیستم‌عامل|حدود ۳۰ تا ۶۰ ثانیه|حدود ۱۰ تا ۲۰ ثانیه|
|باز کردن برنامه‌ها|کندتر|سریع‌تر|
|انتقال فایل|100-200 MB/s|500 MB/s تا چند GB/s|

ا-SSDهای NVMe حتی سریع‌تر هستند:

```
SATA SSD
    |
    v
NVMe SSD
```

---

# 4) انواع SSD

|نوع|توضیح|
|---|---|
|SATA SSD|از رابط SATA استفاده می‌کند، جایگزین HDD معمولی|
|NVMe SSD|از PCIe استفاده می‌کند و بسیار سریع‌تر است|
|M.2 SSD|شکل فیزیکی SSD، می‌تواند SATA یا NVMe باشد|

مثال:

```
HDD
 |
SATA SSD
 |
NVMe SSD
```

از نظر سرعت معمولاً:

```
HDD < SATA SSD < NVMe SSD
```

# ا-5) HDD و SSD در لینوکس

در لینوکس هر دو به شکل **Block Device** دیده می‌شوند.

مثال:

```
lsblk
```

خروجی:

```
sda
├── sda1
└── sda2
```

یا NVMe:

```
nvme0n1
├── nvme0n1p1
└── nvme0n1p2
```
