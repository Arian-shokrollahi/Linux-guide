## ا-Storage Media چیست؟

ا-**Storage Media (رسانه ذخیره‌سازی)** به هر وسیله یا محیطی گفته می‌شود که برای **ذخیره، نگهداری و بازیابی اطلاعات (Data)** استفاده می‌شود.

در سیستم‌های کامپیوتری، داده‌ها مثل:

- فایل‌ها
- سیستم‌عامل
- برنامه‌ها
- دیتابیس‌ها
- لاگ‌ها
- تنظیمات سیستم

باید روی یک نوع Storage Media ذخیره شوند تا بعداً قابل استفاده باشند.

در لینوکس، Storage Media معمولاً به شکل **Device** دیده می‌شود و سیستم‌عامل آن را مدیریت می‌کند. مثلاً:

```
/dev/sda
/dev/nvme0n1
/dev/sdb
```

این‌ها نماینده‌ی دیسک‌های ذخیره‌سازی هستند.

## 2) انواع Storage Media

| نوع Storage Media       | توضیح                                                    | مثال               |
| ----------------------- | -------------------------------------------------------- | ------------------ |
| HDD (Hard Disk Drive)   | ذخیره‌سازی مکانیکی با دیسک چرخان، ظرفیت زیاد و قیمت کمتر | هارد لپ‌تاپ، سرور  |
| SSD (Solid State Drive) | ذخیره‌سازی با حافظه فلش، سریع‌تر و بدون قطعه متحرک       | SATA SSD، NVMe SSD |
| USB Flash               | حافظه قابل حمل برای انتقال داده                          | فلش مموری          |
| Optical Media           | ذخیره‌سازی نوری                                          | CD، DVD، Blu-ray   |
| Tape                    | ذخیره‌سازی نواری، بیشتر برای Backupهای بزرگ              | LTO Tape           |
| Network Storage         | ذخیره‌سازی روی شبکه                                      | NAS، SAN           |
| Cloud Storage           | ذخیره‌سازی روی زیرساخت ابری                              | Object Storage     |
