# 01-DHCP-Server
# 01 این قسمت درمورد سرویس DHCP است
---
## سرویس <MARK>DHCP</MARK> مخفف چیست و مسولیت چه کاری رو بر عهده دارد:
- سرویس DHCP مخفف (Dynamic host configuration protocol) که کاره اصلی این سرویس این است که دستگاهی که به شبکه وصل میشود رو به صورت خودکار تنظیمات شبکه رو بهش بدهد که این تنظیمات عبارت اند از:
- -1- ادرس ای پی (<MARK>IP Address</MARK>): مثل 192.168.1.25
- -2-ماسک هایه شبکه (<MARK>subnet mask & prefix length</MARK>): محدوده ی شبکه ی شما رو معلوم میکنه 24/ 20/
- -3- ادرس روتر یا دروازه خروجی به شبکه هایه دیگر (<MARK>Default gateway</MARK>) : مثل 192.168.1.1
- -4-ادرس سرویس(<MARK>Default gateway</MARK>) یا تبدیل کننده نامه دامنه به IP
- گاهی تنظیمات دیگر: NTP، domain name، PXE boot و…
- درمورد 1تا4 مفصل توضیح میدم نگران نباشید🎃.


## یه مثال ساده بزنیم که چه نقشی رو ایفا میکند این سرویس:
فرض کن لپ‌تاپت به Wi‑Fi خانه وصل می‌شود.
بدون DHCP باید دستی بگویی:
```
IP:      192.168.1.20
Mask:    255.255.255.0
Gateway: 192.168.1.1
DNS:     8.8.8.8
```
اما با DHCP، لپ‌تاپ هنگام اتصال می‌گوید:
«من تازه وارد شبکه شده‌ام؛ تنظیمات شبکه می‌خواهم
روتر یا DHCP Server پاسخ می‌دهد:

> «این IP را بگیر: `192.168.1.20`
> 
>ا Gateway تو: `192.168.1.1`
> 
>ا DNS تو: `192.168.1.1`
> 
> این تنظیمات مثلاً تا 24 ساعت معتبر است.»

## اینم در ادامش بگیم که ایا این تنظماتی که میدهد همیشگی است یا موقت و به چه صورت---><mark>Lease</mark> را توضیح دهید

اگر ریز بشوید درون تنظیمات DHCP حتما یه همچین چیزی رو میبینید:
```
IP: 192.168.1.20
Lease time: 24 hours
```
قبل از تمام شدن این زمان، دستگاه تلاش می‌کند Lease را تمدید کند.

این کار باعث می‌شود IPهای شبکه بهتر مدیریت شوند، مخصوصاً در شبکه‌هایی که دستگاه‌ها مرتب وصل و قطع می‌شوند.

---
## اگر درمورد سرویس DHCP بخونید حتما به کلمه ی DORA میخورید که این کلمه مخفف مراحلی است که بین دستگاه درون شبکه و DCHP ردوبدل میشه:
فرآیند رایج DHCP چهار مرحله دارد که به آن **DORA** می‌گویند:

- . ا<mark>**Discover**</mark>
- کلاینت در شبکه Broadcast می‌فرستد تا DHCP Server را پیدا کند.

- . ا<mark>**Offer**</mark>
- سرور یک IP پیشنهادی و تنظیمات شبکه ارائه می‌کند.

- 2.ا <mark>**Request**</mark>
- کلاینت اعلام می‌کند که می‌خواهد همان IP پیشنهادی را بگیرد.

- 3.ا<mark> **Acknowledge (ACK)**</mark>
- سرور تأیید نهایی می‌دهد و IP به کلاینت اختصاص پیدا می‌کند.





بریم یه نمایه خیلی ساده هم ازش ببینیم:
```
Client                     DHCP Server
  | --- DHCP Discover ---> |
  | <---- DHCP Offer ----- |
  | --- DHCP Request ----> |
  | <----- DHCP ACK -------|
```

---
## واخرین قسمت ما چند مدل میتونیم IP بدهیم به دستگاه هایه متصل به شبکه: <mark>2مدل</mark> 
- ای پی ثابت (static IP)--->به صورت دستی تنظیم برایه مثلا سرور، پرینتر شبکه، تجهیزات شبکه
-  ای متغیر ،سرویس(DHCP)-->به صورت شانسی بر اساس بازه مشخص شده و تنظیمات اونDHCP
- برای مثال، یک وب‌سرور معمولاً باید IP ثابت داشته باشد تا همیشه با همان آدرس قابل دسترس باشد؛ اما گوشی و لپ‌تاپ بهتر است از DHCP استفاده کنند.
- ا<MARK>نکته </MARK>## نکتهٔ مهم: DHCP Reservation

اگر بخواهی یک دستگاه همیشه یک IP مشخص بگیرد، لازم <MARK>نیست حتماً روی خودش Static IP تنظیم کنی</MARK>.

می‌توانی در DHCP Server یک **Reservation** بسازی:

`MAC Address دستگاه  →  همیشه IP مشخص AA:BB:CC:DD:EE:FF   →  192.168.1.50`

این روش برای پرینتر، سرور خانگی، Raspberry Pi و VMها بسیار خوب است؛ چون مدیریت IP همچنان از سمت DHCP انجام می‌شود.

---
### جمع‌بندی DHCP

**DHCP** سرویسی در شبکه است که تنظیمات لازم برای اتصال دستگاه‌ها را **به‌صورت خودکار** می‌دهد.

مهم‌ترین چیزهایی که ارائه می‌کند:

- IP Address
- Subnet Mask
- Default Gateway
- DNS Server
- زمان اعتبار IP یا **Lease**

مراحل کارش هم به‌ترتیب این است:
`Discover → Offer → Request → Acknowledge`

یعنی دستگاه DHCP Server را پیدا می‌کند، سرور IP پیشنهاد می‌دهد، دستگاه درخواست می‌کند و سرور تأیید نهایی می‌فرستد.

**هدف اصلی DHCP:**

مدیریت راحت‌تر شبکه و جلوگیری از تنظیم دستی و تکراری IP برای هر دستگاه.

> در اکثر خانه‌ها، مودم یا روتر همان DHCP Server است.
