# 05 Private & Public IP for IPV4
# درس 05 ایپی عمومی و خصوصی برایه IPV4
---
## قبل از شروع ادرس «عمومی (Public)» و «خصوصی (Private)» یک مفهوم مختص IPv4 است. IPv6 هم آدرس خصوصی داره، ولی اسم و ساختارش فرق داره.


## اIPv4 (دو دسته اصلی)

**1. ا<mark>IP عمومی (Public)</mark>:** قابل مسیریابی در اینترنت، توسط IANA به RIR ها تخصیص داده میشه و هر کدوم منحصر بفرده. آدرس عمومی برای سرورها و دستگاههایی که باید از بیرون قابل دسترسی باشن.

**2. ا<mark>IP خصوصی </mark>(Private / RFC 1918):**

- 10.0.0.0 – 10.255.255.255
- 172.16.0.0 – 172.31.255.255
- 192.168.0.0 – 192.168.255.255


خب، نکته‌ی تو درسته که برای IPv4 دو دسته کلی داریم. ولی برای کامل‌تر شدن:

- ا   IP های **Public** (عمومی): در سطح اینترنت قابل روئیت و یونیک.
-ا      IP های **Private** (خصوصی): پشت NAT در شبکه های محلی.

---
# استاندارد Private IP ها؟
ما برایه Private IPV4 ها استانداردی داریم به اسم  RFC1918 که این RFC سه رنج در سه بازه رو برایه شبکه های خصوصی مشخص میکند.

| Private range                      | CIDR             | تعداد تقریبی |
| ---------------------------------- | ---------------- | ------------ |
| `10.0.0.0` تا `10.255.255.255`     | `10.0.0.0/8`     | 16Mil        |
| `172.16.0.0` تا `172.31.255.255`   | 172.16.0.0/12    | 1mil         |
| `192.168.0.0` تا `192.168.255.255` | `192.168.0.0/16` | 65k          |

این IPها در اینترنت **route نمی‌شوند**؛ یعنی روترهای اینترنت آن‌ها را به مقصد نمی‌رسانند. برای اتصال دستگاه‌های دارای Private IP به اینترنت معمولاً از **NAT** استفاده می‌شود.
#### ا<mark>درمورد NAT درون فایل06 بخونید</mark>



```
+-------------------------------------------------------------------+
|                        فضای کل آدرس‌های IPv4                      |
|                                                                   |
|   +--------------------------+     +--------------------------+   |
|   |   Private IPs (RFC 1918) |     |        Public IPs        |   |
|   |  (استفاده در شبکه داخلی) |     |  (مسیریابی در اینترنت)   |   |
|   |                          |     |                          |   |
|   |  • 10.0.0.0/8            |     |  • سایر IPهای غیررزرو    |   |
|   |  • 172.16.0.0/12         |     |  • مثال: 8.8.8.8         |   |
|   |  • 192.168.0.0/16        |     |  • تخصیص توسط ISP       |   |
|   +--------------------------+     +--------------------------+   |
+-------------------------------------------------------------------+

```
