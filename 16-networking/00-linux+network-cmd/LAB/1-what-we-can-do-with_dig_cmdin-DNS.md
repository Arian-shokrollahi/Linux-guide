### 1. پیدا کردن IP یک سایت

وقتی می‌خواهی ببینی یک Domain به چه IPv4ای اشاره می‌کند:

```
dig google.com A +short
```

**کاربرد روزمره:** بررسی DNS یا اینکه بفهمی یک سایت به چه IPای resolve می‌شود.

---

### 2. بررسی اینکه DNS سیستم درست کار می‌کند یا نه

مثلاً:

```
dig google.com
```

اگر جواب بگیری، یعنی سیستم توانسته از DNS سؤال کند.

حتی می‌توانی DNSهای مختلف را تست کنی:

```
dig @8.8.8.8 google.com
dig @1.1.1.1 google.com
```

**کاربرد روزمره:** وقتی اینترنت داری ولی Domainها باز نمی‌شوند و شک داری مشکل از DNS باشد.

---

### 3. پیدا کردن Mail Server یک Domain

مثلاً:

```
dig google.com MX
```

**کاربرد روزمره:** وقتی با تنظیمات Email و Mail Server کار می‌کنی و می‌خواهی ببینی ایمیل‌های یک Domain به کدام Server تحویل داده می‌شوند.

---

### 4. پیدا کردن Domain مربوط به یک IP

Reverse DNS:

```
dig -x 8.8.8.8 +short
```

**کاربرد روزمره:** وقتی یک IP داری و می‌خواهی ببینی آیا برای آن hostname/domain ثبت شده است یا نه.

---

### خلاصه‌ی ۴ کاربرد

| کاری که می‌خواهی انجام بدهی | دستور                         |
| --------------------------- | ----------------------------- |
| 🌐 پیدا کردن IPv4 سایت      | `dig example.com A +short`    |
| 🔧 تست DNS                  | `dig example.com`             |
| 📧 پیدا کردن Mail Server    | `dig example.com MX`          |
| 🔄 ا-IP → Domain            | `dig -x 8.8.8.8 +short`       |
| 🌐پیدا کردن IPV6            | `dig example.com AAAA +short` |

**اگر بخواهی فقط ۲ تا از `dig` را برای کار واقعی حفظ کنی:**  
ا-`dig domain A +short` و `dig @DNS-SERVER domain` بیشترین استفاده را در troubleshooting شبکه دارند.
