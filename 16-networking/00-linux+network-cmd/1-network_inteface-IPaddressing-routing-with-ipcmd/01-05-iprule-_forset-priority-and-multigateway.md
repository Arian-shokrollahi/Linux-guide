# 🔹 پس `ip rule` کجای کاره؟

حالا فرض کن کامپیوترت **دو تا مسیر اینترنت** داره:

تو می‌خوای بگی:

> بعضی Packetها از Internet A برن و بعضی‌ها از Internet B.

اینجا یک Routing Table معمولی ممکنه کافی نباشه.

پس می‌گی:

> «اگر Packet این شرایط رو داشت، برو Routing Table شماره 100 رو نگاه کن؛ اگر شرایط دیگری داشت، برو Table شماره 200 رو نگاه کن.»

این کار رو **`ip rule`** انجام می‌ده.

# ⭐ فقط این یک جمله رو فعلاً حفظ کن

> ا-**`ip rule` به Linux می‌گوید بر اساس یک شرط، کدام Routing Table را برای پیدا کردن مسیر استفاده کند.**

# Part two work with ip rule

---
# ا-Switchهای مهم `ip rule`

ا-Syntax کلی:

```
ip rule [OPTIONS] [COMMAND]
```

مهم‌ترین چیزهایی که باید بشناسی:

|Switch / گزینه|کاربرد|
|---|---|
|`show`|→ نمایش Ruleهای موجود|
|`add`|→ اضافه کردن Rule|
|`del` / `delete`|→ حذف Rule|
|`flush`|→ پاک کردن Ruleها|
|`priority`|→ تعیین اولویت Rule|
|`from`|→ انتخاب Rule بر اساس Source IP|
|`to`|→ انتخاب Rule بر اساس Destination IP|
|`table` / `lookup`|→ مشخص کردن Routing Table مورد استفاده|
|`fwmark`|→ انتخاب Rule بر اساس Firewall Mark|
|`iif`|→ انتخاب بر اساس Interface ورودی|
|`oif`|→ انتخاب بر اساس Interface خروجی|

---

# ⭐ دو گزینه‌ای که فعلاً خیلی مهم‌اند

اگر تازه `ip rule` را یاد می‌گیری، فعلاً روی این دو تا تمرکز کن:

## 1️⃣ ا-`from`

```
ip rule add from 192.168.1.10 lookup 100
```

یعنی:

> ا-Packetهایی که **Source IP آنها `192.168.1.10`** است، برای پیدا کردن مسیر از **Table 100** استفاده کنند.

پس:

```
Source IP
   ↓
 from
   ↓
Routing Table
```

این برای **Source-Based Routing** خیلی مهم است.

---

## 2️⃣ ا-`priority`

```
ip rule add priority 100 from 192.168.1.10 lookup 100
```

یعنی:

> این Rule با اولویت `100` بررسی شود.

ا-Linux Ruleها را از **Priority کوچک‌تر به بزرگ‌تر** بررسی می‌کند:

```
100
 ↓
200
 ↓
300
 ↓
32766
 ↓
32767
```

پس `100` زودتر از `200` بررسی می‌شود.

---

# 🔥 یک گزینه خیلی مهم دیگر: `lookup`

مثلاً:

```
ip rule add from 192.168.1.10 lookup 100
```

اینجا:

```
from 192.168.1.10
        ↓
lookup 100
        ↓
Routing Table 100
```

یعنی `lookup` می‌گوید:

> **برای این Packet برو Table شماره 100 را بررسی کن.**

ا-`table` هم می‌تواند همین کار را انجام دهد:

```
ip rule add from 192.168.1.10 table 100
```

---

# 🧪 حالا یک خروجی واقعی را ببینیم

اگر بزنی:

```
ip rule
```

ممکن است خروجی این باشد:

```
0:      from all lookup local
100:    from 192.168.1.0/24 lookup 100
200:    from 10.0.0.0/24 lookup 200
32766:  from all lookup main
32767:  from all lookup default
```

حالا خط‌به‌خط تحلیل کنیم.

---

### 🟢 خط اول

```
0: from all lookup local
```

یعنی:

```
Priority = 0
Source = همه
Table = local
```

→ ا-Linux اول **Local Routing Table** را بررسی می‌کند.

مثلاً IPهای خود سیستم و بعضی Routeهای Local اینجا قرار دارند.

---

### 🟢 خط دوم

```
100: from 192.168.1.0/24 lookup 100
```

یعنی:

```
Priority = 100
Source = 192.168.1.0/24
Table = 100
```

→ اگر Packet از محدوده:

```
192.168.1.0/24
```

باشد، Linux می‌رود **Table 100** را بررسی می‌کند.

---

### 🟢 خط سوم

```
200: from 10.0.0.0/24 lookup 200
```

یعنی:

```
Priority = 200
Source = 10.0.0.0/24
Table = 200
```

→ اگر Source داخل:

```
10.0.0.0/24
```

باشد، Linux **Table 200** را بررسی می‌کند.

---

### 🟢 خط چهارم

```
32766: from all lookup main
```

یعنی:

```
Priority = 32766
Source = همه
Table = main
```

→ اگر Ruleهای قبلی چیزی را تعیین نکرده باشند، Linux به **Main Routing Table** می‌رود.

---

### 🟢 خط پنجم

```
32767: from all lookup default
```

یعنی:

```
Priority = 32767
Source = همه
Table = default
```

→ این آخرین Rule پیش‌فرض است.

---

# 🧠 حالا کل خروجی را مثل یک داستان بخوان

ا-Linux می‌گوید:

```
اول:
Priority 0
↓
Local را بررسی کن

بعد:
Priority 100
↓
آیا Source از 192.168.1.0/24 است؟
↓
بله → Table 100

اگر نه:
Priority 200
↓
آیا Source از 10.0.0.0/24 است؟
↓
بله → Table 200

اگر هیچ‌کدام نبود:
Priority 32766
↓
Main Table

و در آخر:
Priority 32767
↓
Default Table
```

# ⚠️ یک نکته خیلی مهم

`ip rule` خودش نمی‌گوید:

> «از Gateway شماره X برو.»

بلکه می‌گوید:

> **«برای پیدا کردن مسیر، این Routing Table را بررسی کن.»**

بعد داخل آن Table، `ip route` تصمیم می‌گیرد که Packet از کدام Gateway و Interface برود.

یعنی:

```
             Packet
                ↓
             ip rule
                ↓
       انتخاب Routing Table
                ↓
             ip route
                ↓
       Gateway + Interface
```

### ⭐ جمله‌ای که برای جزوه‌ات حفظ کن:

> **`ip rule` = انتخاب اینکه کدام Routing Table بررسی شود؛ `ip route` = انتخاب مسیر داخل آن Table.**
