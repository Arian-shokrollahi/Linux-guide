## مقدمه

دستور `ping` یکی از ابزارهای پایه برای بررسی ارتباط شبکه است. این دستور با ارسال **ICMP Echo Request** به یک مقصد، بررسی می‌کند که آیا مقصد قابل دسترس است یا نه و در صورت دریافت پاسخ، اطلاعاتی مانند **زمان پاسخ (RTT/Latency)** و **Packet Loss** را نمایش می‌دهد.
## ساختار دستور ping

```
ping [OPTIONS] DESTINATION
```

مثال:

```
ping 8.8.8.8
```

یا:

```
ping google.com
```

## Switchهای پرکاربرد

|Switch|کاربرد|
|---|---|
|`-c`|تعیین تعداد Pingها|
|`-i`|تعیین فاصله زمانی بین هر Ping|
|`-W`|تعیین زمان انتظار برای پاسخ هر Packet|
|`-w`|تعیین حداکثر زمان اجرای کل دستور|
|`-4`|استفاده از IPv4|
|`-6`|استفاده از IPv6|
|`-s`|تعیین اندازه Packet|
|`-q`|نمایش خروجی خلاصه|

## کاربردهای `ping` در Troubleshooting

- بررسی قابل دسترس بودن یک **Host**
- تست ارتباط با **Default Gateway**
- بررسی ارتباط با یک **IP Address**
- کمک به تشخیص مشکلات **Network Connectivity**
- بررسی **Packet Loss**
- بررسی **Latency / RTT**
- بررسی ناپایداری یا تغییرات زیاد در زمان پاسخ
- کمک به تشخیص مشکل **DNS** با مقایسه Ping به IP و Domain
- کمک به تشخیص اینکه مشکل از **Local Network** است یا مسیرهای بعدی شبکه
