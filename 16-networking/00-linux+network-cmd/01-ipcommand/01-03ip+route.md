# 04-ip-route 
# 04- این قسمت بریم سراغه دستور ip route
---
## دستور ip route (ip r) (Linux routing table)چیست؟
- دستور **`ip route`** (یا خلاصه آن `ip r`) یکی از مهم‌ترین دستورهای شبکه در لینوکس است.
- کار این دستور نمایش و مدیریت **جدول مسیریابی (Routing Table)** هسته لینوکس است؛ یعنی به سیستم می‌گوید هر بسته دیتا باید از **کدام کارت شبکه** و از طریق **کدام گِیت‌وی (Gateway/مودم/روتر)** به مقصد فرستاده شود.
## نمونه ای از دستور ip route (ip r)

```bash
default via 192.168.1.1 dev ens33 proto dhcp metric 100 
192.168.1.0/24 dev ens33 proto kernel scope link src 192.168.1.50 metric 100
```

## حالا بریم سراغه کالبد شکافی خروجی دستور ip route(ip r)
### خط اول: مسیر پیش‌فرض (Default Gateway / اینترنت)
```bash
default via 192.168.1.1 dev ens33 proto dhcp metric 100
```
- ا-**`default`**: یعنی هر مقصدی که در خطوط پایین‌تر مشخص نشده باشد (کل اینترنت). معادل `0.0.0.0/0`.
- ا-**`via 192.168.1.1`**: بسته‌ها باید به این آدرس تحویل داده شوند (آی‌پی مودم، روتر یا گیت‌وی سرور).
- ا-**`dev ens33`**: بسته باید از این کارت شبکه (Device/Interface) خارج شود.
- ا-**`proto dhcp`**: این مسیر به‌صورت خودکار توسط DHCP دریافت شده است.
- ا-**`metric 100`**: اولویت مسیر است. **هرچه این عدد کمتر باشد، اولویت آن مسیر بالاتر است.**
### خط دوم: شبکه محلی (LAN
```bash
192.168.1.0/24 dev ens33 proto kernel scope link src 192.168.1.50
```
- ا- **`192.168.1.0/24`**: برای ارتباط با دستگاه‌های داخل همین رنج (مثلاً `192.168.1.20`)، نیازی به رد شدن از گیت‌وی نیست.
- ا-**`scope link`**: ارتباط مستقیم در لایه شبکه داخلی است.
- ا-**`src 192.168.1.50`**: آی‌پی خود سیستم شما روی این کارت شبکه است.
## تغییر یا اضافه کردن گیت‌وی پیش‌فرض (Default Gateway)
اگر اینترنت قطع شد یا می‌خواهید گیت‌وی را دستی مشخص کنید:
```bash
# اضافه کردن مسیر دیفالت
sudo ip route add default via 192.168.1.1 dev ens33

# جایگزین کردن مسیر فعلی با مسیر جدید
sudo ip route replace default via 192.168.1.254 dev ens33

# حذف مسیر دیفالت
sudo ip route del default

```
