 # interfaces in ip command 
# رابط ها درون دستور ip
---
کارت هایه شبکه درون دستور ip و linux میتونند یکی از این ها باشند:
- کارت هایه شبکه واقعی--->ens33 &  enp0s3 & eth0
- وای فای--->wlan0
- لوپ بک سیستم--->lo --><mark>همونی که برایه تست کردن سرویس ها و ... بود</mark>
- رابط هایه مجازی docker مثل--->docker0
- رابط هایه VPN مثل tun0 & wg0
- و رابط هایه Bond & Bridge & VLAN
--- 
# به صورت کلی ما چند نوع کارت شبکه داریم:
ا-<mark>به صورت کلی ما 2 نوع داریم ولی ریز 4 مدل</mark>
- اون <mark>2</mark> مدل کلی که گفتیم --->Physical NIC & VNIC(virtual NIC)
- اون <mark>4</mark> مدل دقیق میشه--->PhysicyNIC & LogicalNIC & tunnel & virtual
---
# اون <mark>2</mark> مدل کلی:
## 1-کارت شبکه فیزیکی(Physical NIC)
سخت افزار واقعی است یعنی رویه مادربرد یا به صورت PCle & USB وجود دارد
- نمونه‌ها:
  - پورت Ethernet مثل `eth0` یا نام‌های جدیدتر مثل `enp3s0`
  - کارت Wi‑Fi مثل `wlan0` یا `wlp2s0`
  - دانگل USB شبکه
      - شما با دستور ip link میتونید این رابط هارو ببنید.

---
## 2-کارت شبکه مجازی(Virtual NIC/VNIC)
سخت افزار واقعی نیست : توسط سیستم عامل،،VMware،VPN،Dockerو.. ساخته شده
نمونه‌های مهم:

- کارت شبکهٔ ماشین مجازی در VMwareمثلاً داخل Ubuntu مهمان ممکن است `ens33` باشد.
- آداپتورهای VMware روی ویندوز میزبانمثل:
- ا`VMnet1` برای **Host-Only**
- ا`VMnet8` برای **NAT**
- رابط Dockerمثل `docker0`
- رابط VPNمثل `tun0` یا `wg0`
- رابط Loopbackمثل `lo` با IP معروف `127.0.0.1`
```
lo       → ارتباط سیستم با خودش
docker0  → شبکهٔ مجازی Docker
ens33    → کارت مجازی ارائه‌شده به VM
tun0     → تونل VPN
```

# اگر بخواهیم به صورت ریز تر نگاه بکنیم ما کارت هایه شبکه رو به <mark>4</mark> قسمت تقسیم میکنیم
| دسته             | نمونه                   | کاربرد                              |
| ---------------- | ----------------------- | ----------------------------------- |
| فیزیکی           | Wi-Fi/Ethernet          | اتصال واقعی به مودم ، سوییچ یا شبکه |
| مجازی            | VMwareNIC,Docker bridge | شبکه سازی VM, کانتینر               |
| منطقی/نرم افزاری | lo, Vlan, bond, bridge  | ساختار یا مدیریت شبکه در سیستم عامل |
| تونلی            | tun0, wg0               | وی پی ان و انتقال ترافیک تونل       |



`مرز «مجازی» و «منطقی» گاهی دقیق نیست؛ معمولاً هر چیزی که سخت‌افزار مستقل ندارد را در گفت‌وگوی روزمره مجازی می‌گویند.`
