# 02-nc command
---
## چیست دستور nc؟
ا-`nc` یا **Netcat** ابزار سبک برای ساخت اتصال TCP/UDP، تست پورت، ارسال و دریافت داده است. مهم‌ترین کاربردهای عملی‌اش: در Ubuntu معمولاً نسخهٔ `netcat-openbsd` نصب است و بعضی گزینه‌ها ممکن است با نسخه‌های دیگر فرق جزئی داشته باشند.

---
## این دو کار رو بکنید:
- 1-برایه برسی نصب بودن:
- دستور ls /bin | grep nc رو بزنید nc خالی رو ببنید اوکیه معمولا یعنی برنامش هست
- 2- ولی اگر نبود 
```bash
sudo apt update
sudo apt install -y netcat-openbsd
```

# کاربرد دستور nc
###### کاربرد 1- در یکی از رایج‌ترین کاربردها، `nc` بررسی می‌کند که آیا از سیستم تو می‌شود به یک **host** (دامنه یا IP) روی یک **پورت مشخص** اتصال برقرار کرد یا نه.
- 2-یه چیز دیگه میتونی یه بازه مشخص کنی که بره و کله اون بازه رو از اول تا اخر چک کنه و بگه رویه اون کدوم پورت بازه
```bash
nc -zvw numberforwaite (domain/ipaddress) port
```
- دستور nc
- حالا گزینه ی zvw-
- -1گزینه ی z یعنی zero i/o یعنی بسته ای نفرست
- -2گزینه ی v خروجی با جزیات بیشتر
- -3 تایم اوتش رو میگه میگه مثلا تا فلان ثانیه صبر کن
- -دامنه یا پورت
- -معولا از این دستور برایه باز بودن پورت هایه http , https ,... استفاده میکنیم
---
##### کاربرد 2-چک کردن پورت هایه رویه یک بازه

- نکته:⚠️ **نکته بسیار مهم اخلاقی و قانونی:**
اسکن کردن بازه پورت‌ها را **فقط روی سرورهای خودت، ماشین مجازی (VMware)، WSL یا شبکه‌ای که اجازه کتبی داری** انجام بده. اسکن کردن بازه پورت سرورهای عمومی در اینترنت ممکن است توسط فایروال‌های آن‌ها حمله شناسایی شده و IP شما مسدود (Blacklist) شود.
- این کار هم معمولا برایه پیدا کردن پورت باز /برسی عملکرد فایروال و خیلی چیزهایه دیگه استفاده میشود ولی رویه سرویس هایه خودت استفاده میشود.
```bash
nc -zvw numberforwaite (domain/ipaddress) rangeport1-rangeport2
ex: nc -zvw 1 ipserverkhodemon 20-200
```
