
# pipeline
---
## ا-Pipeline (`|`) چیست؟

در لینوکس، **Pipeline** یا پایپ‌لاین با علامت `|` استفاده می‌شود و خروجی یک دستور را مستقیماً به‌عنوان **ورودی دستور بعدی** می‌فرستد.

یعنی:

```bash
command1 | command2
```

به زبان ساده:

```text
خروجی command1 → ورودی command2
```

### نکته مهم

پایپ‌لاین باعث می‌شود بتوانی چند دستور را با هم ترکیب کنی و روی خروجی یک دستور، دستور دیگری اجرا کنی.

### مثال‌ها

**1. پیدا کردن یک کلمه در خروجی:**

```bash
ls | grep txt
```

خروجی `ls` وارد `grep` می‌شود و فقط مواردی که `txt` دارند نمایش داده می‌شوند.

**2. شمردن تعداد فایل‌ها:**

```bash
ls | wc -l
```

خروجی `ls` به `wc` داده می‌شود و `-l` تعداد خطوط را می‌شمارد.

**3. چند Pipeline پشت سر هم:**

```bash
cat file.txt | grep error | wc -l
```

یعنی:

```text
file.txt
   ↓
 cat
   ↓
 grep error
   ↓
 wc -l
   ↓
تعداد خطوط شامل error
```

---
وقتی چند دستور را با `|` پشت سر هم قرار می‌دهیم و هرکدام خروجی مرحله قبل را **پردازش یا فیلتر** می‌کند، معمولاً به آن **Pipeline** می‌گویند و دستورهای داخل آن را می‌توان **filter** در نظر گرفت.

مثلاً:

```bash
cat file.txt | grep "error" | sort | uniq
```

اینجا:

```text
cat → grep → sort → uniq
```

هر مرحله روی داده مرحله قبل کاری انجام می‌دهد؛ بنابراین یک **Pipeline از فیلترها** ساخته‌ایم.

**پس برای امتحان:**

> چند فیلتر که با `|` به هم متصل شده باشند = **Pipeline**.
