if [ "$a" -eq 10 ]; then

## قانون دوم ما برایه مقایسه رشته ها درون شرط :
- برابر--->=
- برابرنیست--->=!
```bash
name="ali"

if [ "$name" = "ali" ]; then
    echo "The name is Ali"
fi
---
if [ "$name" != "reza" ]; then
    echo "The name is not Reza"
fi

```

## قانون سوم و برایه مقایسه اعداد با هم درون شرط:
ما از 
```bash
-eq   برابر--->equal
-ne   نابرابر--->not equal
-lt   کوچکتر--->less than
-le   کوچکتر یا مساوی--->less equal
-gt   بزرگتر--->great 
-ge   بزرگتر یا مساوی--->great equal
```
استفاده میکنیم مثال:اگر مقدار عددی `a` بزرگ‌تر از `5` باشد، پیام را چاپ کن.
```bash
a=10

if [ "$a" -gt 5 ]; then
    echo "a is greater than 5"
fi

```

# جمع بندی 
- برایه شرط به دلیل اینکه براکت مربعی خودش یک دستور است از دیواره هایه داخلی باید فاصله رو رعایت
- برایه مقایسه اعداد درون شرط از اون گزینه ها استفاده میکنیم
- برایه مقایسه رشته ها هم درون شرط ها از از  علامت = & =! استفاده میکنیم
