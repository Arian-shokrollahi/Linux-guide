## How can we see our operating system?

----
## کدام فایل اطلاعات مربوط به سیستم عامل رو رویه سیستم نشون میده

فایل `/etc/os-release` اطلاعات مربوط به سیستم‌عامل لینوکس نصب‌شده روی سرور را نگهداری می‌کند.

با استفاده از این فایل می‌توانیم توزیع (Distribution)، نسخه و نام سیستم‌عامل را تشخیص دهیم.

مشاهده محتویات فایل:

```
cat /etc/os-release
```

مثال خروجی:

```
NAME="Ubuntu"
VERSION="24.04 LTS"
ID=ubuntu
VERSION_ID="24.04"
PRETTY_NAME="Ubuntu 24.04 LTS"
```

کاربردهای مهم:

- تشخیص توزیع لینوکس
    
- مشاهده نسخه سیستم‌عامل
    
- استفاده در اسکریپت‌های Bash برای تشخیص نوع سیستم‌عامل
    
- انتخاب دستورات نصب متناسب با توزیع
    

نکته: این فایل اطلاعات سیستم‌عامل را معرفی می‌کند و معمولاً نباید آن را به‌صورت دستی تغییر بدهی.

---
## برسی ستون هایه این دستور 

### جدول فیلدهای فایل `/etc/os-release`

|فیلد|کاربرد|
|---|---|
|`NAME`|نام سیستم‌عامل|
|`VERSION`|نسخه کامل سیستم‌عامل|
|`ID`|شناسه توزیع لینوکس|
|`ID_LIKE`|توزیع‌های مشابه و والد آن|
|`VERSION_ID`|شماره نسخه سیستم‌عامل|
|`PRETTY_NAME`|نام کامل و خوانای سیستم‌عامل|
|`ANSI_COLOR`|کد رنگ پیشنهادی برای نمایش نام توزیع در ترمینال|
|`CPE_NAME`|شناسه استاندارد سیستم‌عامل در قالب CPE|
|`HOME_URL`|آدرس وب‌سایت رسمی|
|`SUPPORT_URL`|آدرس صفحه پشتیبانی|
|`BUG_REPORT_URL`|آدرس گزارش مشکلات و باگ‌ها|
|`PRIVACY_POLICY_URL`|آدرس سیاست حفظ حریم خصوصی|
|`VERSION_CODENAME`|نام رمز نسخه سیستم‌عامل|
|`UBUNTU_CODENAME`|نام رمز نسخه Ubuntu (در نسخه‌های مبتنی بر Ubuntu)|

### مثال خروجی در Ubuntu

```
NAME="Ubuntu"
VERSION="24.04.3 LTS (Noble Numbat)"
ID=ubuntu
ID_LIKE=debian
PRETTY_NAME="Ubuntu 24.04.3 LTS"
VERSION_ID="24.04"
VERSION_CODENAME=noble
UBUNTU_CODENAME=noble
HOME_URL="https://www.ubuntu.com/"
```

### سه فیلد مهم که باید به خاطر بسپاری

- ا-`ID`: برای تشخیص نوع Distribution در اسکریپت‌ها.
    
- ا-`VERSION_ID`: برای تشخیص شماره نسخه.
    
- ا-`ID_LIKE`: برای تشخیص خانواده توزیع و سازگاری تقریبی آن با توزیع‌های دیگر.
    

مثال کاربردی:

```
source /etc/os-release

echo "$NAME"
echo "$VERSION_ID"
echo "$ID"
```

این روش در اسکریپت‌های Bash برای تشخیص سیستم‌عامل و اجرای دستورات متناسب با آن بسیار کاربردی است.

نکته: همه فیلدها در تمام توزیع‌های لینوکس وجود ندارند؛ بسته به توزیع ممکن است بعضی از آن‌ها حذف شده باشند.
