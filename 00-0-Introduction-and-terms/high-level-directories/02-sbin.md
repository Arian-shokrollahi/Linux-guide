# 02-/sbin
----
## فولدر سطح بالا sbin/ چیست؟
- مخفف : system binaries (superuser binaries)
- داخلش چیست؟ دستورات اجرایی سطح بالا و مدیریتی که معمولا مختص مدیر سیستم (root/superuser)هستند، مانند 
```bash
fdisk, iptables, ip, reboot, shutdown, fsck
```
- نکته تکمیلی ; کاربران عادی هم میتونند از خیلی از این دستور ها استفاده کنند ولی برایه تغییر نیاز به دسترسی روت یا استفاده از sudo دارند. این پوشه هم معمولا شورت کات(symbolic linki)به پوشه Usr/sbin/ لینک است

- خواستید دستورا پوشه ی sbin/ رو ببنید یا همون دستورات کاربر ویژه رو 2 کار
- 1-دیدن سیم لینک اون در مسیر bin/
- 2-دیدن فایل اصلی که bin/ بهش لینک شده sbin/
