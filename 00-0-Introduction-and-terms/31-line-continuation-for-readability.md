### چیکار کنیم تا در هنگام زدن کد هامون درون شل خوانایی بیشتر شه
---
### باید از  line continuation استفاده کنیم
توی Shell لینوکس برای اینکه دستور قطع نشه و بری خط بعد، آخر خط `\` بذار و بعد Enter بزن.

مثلاً:

```
docker run -d \
  --name my-container \
  -p 8080:80 \
  nginx
```

یعنی این:

```
\
```

به Shell می‌گه: «دستور هنوز تموم نشده، ادامه‌ش توی خط بعدیه.»

نکته مهم: بعد از `\` چیزی نذار، حتی بهتره فاصله هم نباشه. یعنی این درست:

```
docker run -d \
  --name nginx \
  nginx
```

ولی این ممکنه مشکل‌ساز بشه:

```
docker run -d \ 
```

پس کی‌استروکش عملاً اینه:

```
Backslash \  +  Enter
```

روی کیبورد معمولاً کلید `\` نزدیک Enter قرار داره.
