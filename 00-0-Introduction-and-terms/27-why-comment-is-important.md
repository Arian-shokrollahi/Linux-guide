# چرا Comment ها مهم هستند؟

وقتی فایل‌های تنظیمات مثل:

```
~/.bashrc
/etc/profile
```

را تغییر می‌دهیم، بهتر است کنار تغییرات خودمان **توضیح (Comment)** بنویسیم.

دلیل:

امروز یادت هست چه چیزی را تغییر دادی، اما:

- ۶ ماه بعد چه؟
- اگر شخص دیگری فایل را ببیند چه؟
- اگر مشکلی پیش بیاید چطور بفهمی این خط برای چه اضافه شده؟

ا-Comment کمک می‌کند بفهمیم **چرا یک تغییر انجام شده است.**

---

# ا-Comment در Bash چگونه نوشته می‌شود؟

در Bash و Shell Script علامت:

```
#
```

شروع Comment است.

مثال:

```
# Add my custom path
export PATH=$PATH:/opt/myapp/bin
```

خط اول فقط توضیح است و اجرا نمی‌شود.

ا-Bash فقط این را اجرا می‌کند:

```
export PATH=$PATH:/opt/myapp/bin
```

---

# ا-Comment در فایل‌های تنظیمات

بیشتر فایل‌های تنظیمات Linux Comment دارند.

مثلاً:

```
# Set default editor
export EDITOR=vim
```

خط با `#` برای انسان است، نه برای برنامه.

---

# ا-Comment کردن یک خط برای غیرفعال کردن آن

گاهی یک خط تنظیمات وجود دارد ولی می‌خواهیم موقتاً اجرا نشود.

مثلاً:

قبل:

```
alias ll='ls -l'
```

این Alias فعال است.

اگر `#` اول آن بگذاریم:

```
#alias ll='ls -l'
```

حالا Bash آن را نادیده می‌گیرد.

این کار را می‌گویند:

```
Comment out
```

یعنی تبدیل کردن یک خط فعال به Comment.

---

# ا-Uncomment چیست؟

برعکس آن:

قبل:

```
#alias ll='ls -l'
```

با حذف `#`:

```
alias ll='ls -l'
```

فعال می‌شود.

به این می‌گویند:

```
Uncomment
```

---

# مثال Ubuntu `.bashrc`

داخل `.bashrc` ممکن است ببینی:

```
# some more ls aliases

#alias ll='ls -l'
#alias la='ls -A'
#alias l='ls -CF'
```

این سه خط در اصل Alias هستند، ولی چون `#` دارند، فعال نیستند.

اگر تبدیل شوند به:

```
alias ll='ls -l'
alias la='ls -A'
alias l='ls -CF'
```

فعال می‌شوند.

---

# نکات مهم

### 1) Comment برای توضیح دادن تغییرات است

مثال خوب:

```
# Add Java path for development
export JAVA_HOME=/usr/lib/jvm/java-17
```

---

### 2) Comment کردن راهی برای خاموش کردن تنظیمات است

به جای حذف خط:

```
#export EDITOR=vim
```

آن را غیرفعال می‌کنیم ولی اطلاعاتش را نگه می‌داریم.

---

### 3) همیشه قبل از تغییرات بزرگ توضیح بنویس

مثلاً:

```
# Changed PATH to include custom scripts directory
export PATH=$PATH:$HOME/scripts
```

بعداً سریع متوجه می‌شوی چرا این خط وجود دارد.

---

خلاصه:

```
# = Comment

Comment:
- اجرا نمی‌شود
- برای توضیح انسان است
- برای غیرفعال کردن موقت تنظیمات استفاده می‌شود

Uncomment:
حذف # و فعال کردن دوباره تنظیمات
```

در Linux Admin، Comment نویسی خوب باعث می‌شود فایل‌های تنظیمات بعد از مدت طولانی قابل فهم باقی بمانند.
