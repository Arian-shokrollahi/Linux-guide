# 02-cd command
# 02-دستور cd
---
## دستور cd چیست ؟
دستور cd مخفف change directory است که به معنایه تغیر دایرکتوری است ما گفتیم همه چیز از یک دایرکتوری شروع میشه به اسم دایرکتوری روت و همینطوری به صورت سلسه مراتبی (hierarchical)میره پایینی حالا برایه اینکه بخوای در شاخه ها که مظورمون همون دایرکتوری ها هستند جابجا شوی از این دستور استفاده میکنی
## ساختار دستور cd به چه صورت است؟
شما دستور cd رو مینویسید و سپس جلویه اون مسیر اون دایرکتوری که میخواید برید توش رو میزارید:
```bash
cd [path]
```
- و در قسمت قبل هم گفتیم برایه اینکه ببنید کجا هستید شما میاید دستور pwd رو میزنید
---
## نماد هایه بسیار مهم درون دستور cd بسیار مهم است
به نماد ها دقت کنید:

| نماد | معنی                             | مثال  |
| ---- | -------------------------------- | ----- |
| /    | ریشه فایل سیستم یا پوشه روت      | cd /  |
| .    | دایرکتوری فعلی                   | cd .  |
| ..   | دایرکتوری والدی یه لایه بالاتر   | cd .. |
| ~    | دایرکتوری پوشه خانگی  کاربر فعلی | cd ~  |
| -    | دایرکتوری فعلی                   | cd -  |
