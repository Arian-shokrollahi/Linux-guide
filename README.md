# Linux Guide

راهنمای فارسی و متن‌باز لینوکس با رابط ترمینالی و پشتیبانی مستقیم از Markdown.

## امکانات سایت

- حالت روشن و تاریک با ذخیره انتخاب کاربر
- جست‌وجو در عنوان و محتوای درس‌ها
- نمایش فایل‌های Markdown، جدول‌ها، تصاویر و بلوک‌های کد
- دکمه کپی برای دستورها و فهرست خودکار هر صفحه
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- انتشار خودکار روی GitHub Pages

فایل‌های Markdown خالی عمداً در منوی سایت نمایش داده نمی‌شوند و بعد از اضافه‌شدن محتوا، با اجرای دوباره تولیدکننده فهرست وارد سایت خواهند شد.

## اجرای محلی

ابتدا فهرست فایل‌های Markdown را بساز:

```bash
node scripts/generate-content-index.mjs
```

بعد سایت را با یک وب‌سرور محلی اجرا کن:

```bash
python3 -m http.server 8080
```

سپس آدرس `http://localhost:8080` را در مرورگر باز کن. به‌دلیل استفاده از `fetch` برای خواندن Markdown، فایل `index.html` را مستقیماً با پروتکل `file://` باز نکن.

## اضافه‌کردن درس جدید

فایل Markdown را در فصل مناسب قرار بده و دوباره این دستور را اجرا کن:

```bash
node scripts/generate-content-index.mjs
```

در GitHub Actions این مرحله هنگام هر Push به شاخه `master` به‌صورت خودکار اجرا می‌شود.

## انتشار

در تنظیمات مخزن، از بخش **Settings → Pages**، مقدار **Source** را روی **GitHub Actions** قرار بده. پس از Push روی `master`، Workflow سایت را منتشر می‌کند.
