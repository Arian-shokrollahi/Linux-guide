# introduction to diff command
## دستور (diff) چیست و ما اون رو کجا دیده ایم🤔؟
دستور (diff) برای مقایسه محتوا دو فایل استفاده میشه که بفهمیم این چی داشت چی در جدیده جاشو گرفت چی اضافه شد چی ثابت در هر دو و تغییری نکرده .
## دلیل محبوبیت این دستور؟
به این دلیل محبوبه چون فک کنید شما باید دوفایل رو برید توش و تک نگاه کنید چی کم شده چی ریاد شده ولی با این دستور خیلی راحت این تغییرات رو میفهمید🧠.

# diff command structure
# ساختار دستور diff به چه صورته؟
- diff command structure---> diff file1(old file) file2(new file) --like> diff text.txt project.txt
 
## مثال ما دوفایل داریم به اسم هایه ali.txt b.txt که هر کدوم رو با cat محتواشو نشون دادم ali old file & b new file بریم تغییرات دو فایل رو ببینیم.
