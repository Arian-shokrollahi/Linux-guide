# 03-دستور (command)چیست
---
## دستور (command )چیست؟
دستور چیزی است که تو به شل میدی تا کاری رو انجام بده.

## انواع دستور ها؟
| انواع دستور           | توضیح                                                                                                                        | مثال                             |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| external command      | برنامهٔ جداگانه‌ای است که معمولاً در مسیرهایی مثل `/usr/bin` یا `/bin` قرار دارد. Shell آن را به‌صورت یک پردازش اجرا می‌کند. | ls,grep,cat,cp                   |
| shell built-in        | دستور داخلی خود Shell است؛ فایل برنامهٔ جداگانه ندارد یا Shell نسخهٔ داخلی آن را اجرا می‌کند.                                | cd,echo,read,export              |
| Alias(shorcut)        | نام کوتاه یا جایگزینی که برای یک دستور ساخته‌ای.                                                                             | ll--->ls -alF                    |
| shell function        | مجموعه‌ای از دستورها که با یک نام تعریف می‌کنی؛ شبیه تابع در برنامه‌نویسی.                                                   | mkcd(){ mkdir "$1" && cd "$1"; } |
| keyword/reserved word | کلمه‌های ویژهٔ زبان Shell برای ساختن شرط، حلقه و…؛ برنامه یا دستور عادی نیستند.                                              | if, then, for, while, do, done   |
- ترتیب برسی شل برایه دستور ها
```
Alias → Function → Built-in → External command
```
- دستور type command به ما میگه که این دستور ها از چه نوعی هستند

----
## از کجا میشه تشخیص داد که دستور از چه نوعی است؟
ما به کمک دستور <mark>type</mark> میتونیم بفهمیم اون دستور از چه نوعی
```bash
type ls
type cd
type if
---output
ls is aliased to `ls --color=auto`
cd is a shell builtin
if is a shell keyword
```
