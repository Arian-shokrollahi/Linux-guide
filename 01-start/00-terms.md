# رابط یا interface یعنی چی؟
رابط یا واسطه یعنی چیزی که بین دو چیز قرار میگیرد تا بتوانند با هم ارتباط برقرار کنند. مثلا در کامپیوتر ما چیزی داریم به اسمه User Interface که یعنی چی ؟
- روشی که کاربر با کامپیوتر یا یک برنامه ارتباط برقرار میکند مثلا:
- وقتی روی یک دکمه کلیک می‌کنی، آن دکمه بخشی از **رابط کاربری** است.
--
## رابط گرافیکی و رابط خط فرمان (CLI&GUI)چیست
-  رابط خط فرمان و رابط گرافیکی دو نوع رابط هستند برای ارتباط کاربر با سیستم عامل
```
User (کاربر)
      ↓
GUI یا CLI
      ↓
Operating System (سیستم‌عامل)

```

| interface type                | mean                | function                       |
| ----------------------------- | ------------------- | ------------------------------ |
| GUI(graphical user interface) | رابط کاربری گرافیکی | ماوس،آیکن،پنجره،دکمه           |
| CLI(command line interface)   | رابط خط فرمانی      | تایپ کردن دستور و شل و ترمینال |
- هر دو در نهایت از سیستم‌عامل می‌خواهند یک کار را انجام دهد؛ فقط **روش ارتباط** متفاوت است.
--
## ترمینال چیه ؟ (terminal)
- **ترمینال** یک برنامه یا پنجره است که به تو اجازه می‌دهد با تایپ‌کردن دستورها با کامپیوتر ارتباط برقرار کنی.
- داخل ترمینال معمولاً یک **Shell** مثل `bash` اجرا می‌شود. شل دستور تو را می‌فهمد و از سیستم‌عامل می‌خواهد آن را اجرا کند.

## شبیه ساز ترمینال(terminal emulatur)چیست؟
- شبیه ساز ترمینال (Terminal emulator)برنامه ای است که یک ترمینال قدیمی رو شبیه سازی میکند و محیطی رو برایه اجرا شل فراهم میکند.
- امروزه وقتی میگوییم Terminal،معمولا منظورمان همون Terminal emulator است که یک پنجره است که شل درون اون اجرا میشود
## حالا چرا شبیه ساز(emulator)
چون قدیم ترمینال یک دستگاه فیزیکی بود ،و نه یک برنامه ، که این ترمینال قدیمی که فیزیکی بود و یه دستگاه بود شامل:
- یک کیبورد 
- یک صحفه نمایش یا گاهی چاپگر  که به یک کامپیوتر بزرگ مرکزی وصل میشد
-- 
## ایا ما شبیه ساز ترمینال زیادی داریم؟
بله. برنامه‌های Terminal Emulator زیادی وجود دارند؛ کار اصلی همه تقریباً یکی است، اما امکانات، ظاهر، سرعت و تنظیماتشان فرق دارد.
```
GNOME Terminal → bash
kitty          → bash
Windows Terminal → WSL → bash
```
---
## شل (shell)چیست؟
- ا-**Shell** یک برنامه است که دستورهای متنی تو را می‌گیرد، معنی‌شان را می‌فهمد و آن‌ها را اجرا می‌کند یا از سیستم‌عامل می‌خواهد اجرا شوند.
```
تو → Terminal → Shell → Kernel / سیستم‌عامل
```
- ا-**Terminal**: جایی که دستور را تایپ می‌کنی و خروجی را می‌بینی.
- ا **Shell**: دستور را تحلیل و اجرا می‌کند.
- ا **Kernel**: بخش اصلی سیستم‌عامل که به سخت‌افزار و منابع سیستم دسترسی دارد.
- ما شل هایه زیادی داریم ولی معمولا اینا خیلی محبوبن:
- bash, zsh, fish, sh
- و در ابونتویی که ما کار میکنیم معمولا shell پیش فرض کاربر bash است
