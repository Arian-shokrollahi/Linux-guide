## اول <mark>Source code </mark>یعنی چی ؟
سورس کد یا کد منبع ، یعنی اون متن دستوری که  اون برنامه نویس مینویسه تا یک برنامه ساخته شه.
مثلا این یک سورس کد یا کد منبع خیلی ساده 😡است که به زبون c نوشته شده:
```
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```
که به طور مثال اون برنامه نویس میاد این محتوا رو درون فایلی به اسمه hello.c میگذارد🙄:

حالا مشکل چیه🤔؟مشکل اینه که انسان میتونه این کد رو بخونه ولی CPU نمیتونه.

## حالا <mark>compile</mark> یعنی چی؟
حالا کامپایل کردن /compile یعنی تبدیل کد منبع یا سورس کد  به برنامه ای که سیستم عامل و پردازنده بتوانند اون رو اجرا کنند.

## حالا <mark>compiler</mark> چیکار میکند؟
کامپایلر همون مترجمی است که میاد کد منبع یا سورس کد رو به زبان قابل فهم برایه ماشین درمیاره چند نمونه از کامپایلر ها :
- gcc --->C language
- ++g-->compiler C++

## توضیح درمورد هر کدومشون:
#### (1) برنامهٔ کامپایل‌شونده (compiled)

کد منبع قبل از اجرا به یک فایل اجرایی جدا تبدیل می‌شود:
`hello.c → gcc → hello`

بعد فایل خروجی را اجرا می‌کنی:
`./hello`

فایل `hello` شامل کد ماشین مناسب CPU است.

---
#### (2) برنامه های تفسیری  (Scripted/Interpreted)
فایل اصلی معمولاً همان فایل کدی است که نوشته‌ای:
`hello.py hello.sh`

هنگام اجرا، یک مفسر آن را می‌خواند و اجرا می‌کند:
`python3 hello.py bash hello.sh`

یعنی معمولاً خودت یک فایل اجرایی مستقل مثل خروجی `gcc` تولید نمی‌کنی.
