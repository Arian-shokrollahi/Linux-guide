## دستور gcc مخفف چیست و چه کاری رو انجام میده؟

دستور gcc مخفف <mark> GNU C Compiler </mark>است که این دستور، که این دستور کاره کامپایل رو انجام میده و میاد اون کد C رو به زبون ماشین (object file) تبدیل میکند.

## برای ساختن یک برنامه فقط نوشتن کد کافی نیست. چند ابزار لازم داریم:

- ا**Compiler (کامپایلر):**کد C را به زبان ماشین یا فایل object تبدیل می‌کند.
- ا**Linker (لینکر):**فایل‌های object و کتابخانه‌ها را به هم وصل می‌کند تا فایل اجرایی نهایی ساخته شود.
- ا**make:**ابزاری برای خودکار کردن فرایند build است؛ یعنی لازم نباشد هر بار همه دستورها را دستی بنویسی.

## خب در فایل 03 توضیح دادم درمورد کامپایل کردن ولی یه مروری بکنیم: ما دو مدل میتونستیم کامپایل کنیم :
- ا <mark>مدل (1) سخت چند مرحله ای :</mark> 
- مرحله 1 --->gcc -E filename.c -o filename.i
- مرحله2 --->gcc -S filename.i -o filename.s
- مرحله3--->gcc -c filename.s -o filename.o
- مرحله4--->gcc filename.o -o filename
- ا<mark>مدل (2) اسون تک مرحله ای</mark>
- در مدل اسون شما با استفاده از دستور بدون گزینه gcc filename.c -o filename میاید اون برنامه رو درست میکنید و دیگر نیاز به این مراحل طولانی نیست

## دستور gcc به تنهایی میتونه کدام مراحل را طی کند:
 gcc:
 - preprocessor
 - compiler
 - assembler
 - linker

دستور gcc میتونه به تنهایی این مراحل را طی کند حالا  دستور make چیکار میکند:

---
## حالا دستور make چیکار میکند؟
ا make یک ابزار ساخت پروژه است که با خواندن فایل makefile تصمیم میگیرد چه فایل هایی باید ساخته یا دوباره ساخته شوند.
## کارش چیست؟

- فایل‌های وابسته را بررسی می‌کند
- فقط چیزهایی را که لازم است کامپایل می‌کند
- اگر چیزی تغییر نکرده باشد، دوباره‌کاری نمی‌کند

## برایه اینکه ببینی این دستور gcc درکجا نصب شده چیکار کنیم:
- از دستور <mark>which</mark> استفاده میکنیم
- which gcc------>output--->/usr/bin/gcc
