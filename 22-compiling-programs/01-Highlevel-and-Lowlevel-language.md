# برسی سطوح مختلف در زبان هایه برنامه نویسی
---
## زبان هایه برنامه نویسی رو به چند سطح میتوان تقسیم کرد؟
معمولا به دودسته -->زبان هایه سطح بالا و پایین تقسیم میکنند ولی فنی تر بخوایم بگیم به سه سطح تقسیم میشوند زبان ها درون برنامه نویسی:
- 1-سطح پایین (<mark>Low-level-language</mark>) : نزدیک به سخت افزار ، کنترل شده ، سخت و طولانی
- 2-سطح متوسط (<mark>Mid-level-language</mark>) : هم نزدیک به سخت افزار ، هم دارای امکانات سطح بالا
- 3-سطح بالا (<mark>High-level-language</mark>) : دور از سخت افزار ساده خوانا سریع تر 

---
## بریم درمورد هرکدوم از این 3 بخش توضیح بدیم:
### <mark>1-Low-level-language</mark>
- ا <mark>(1)</mark>زبان ماشین (Machine language)
- باینری و فقط 0 و 1 است
- فقط cpu میفهمد
- خیلی خیلی سخت و غیرفابل خواندن است
```
00010101 0101 010
```

- ا <mark>(2)</mark> اسمبلی (Assembly)
- نزدیک به زبان ماشین ، ولی با کلمات کوتاه تر
- به جای 0 و 1 از  MOV, ADD,CPY
- و توسط  assembler به زبان ماشین و قابل فهم برای CPU تبدیل میشه
```
Assembly Code  ────> assembler ────>Machine Code (باینری ۰ و ۱)
```

---
### <mark>2-Mid-level-language</mark>

- ا <mark>(1)</mark> زبان  C
- - **مهم‌ترین زبان برای لینوکس**
- هم قدرتمند، هم کنترل دقیق حافظه
- پایهٔ خیلی از سیستم‌عامل‌ها (لینوکس، ویندوز قدیم)
```
int x = 5 + 3;
```

- ا<mark>(2)</mark> زبان  ++C
- - ادامهٔ C با قابلیت‌های بیشتر
- شی‌گرایی (OOP)
- برای بازی‌ها، نرم‌افزارهای سنگین
```
std::cout << "Hello";
```

---
### <mark>3-High-level-language</mark>

- ا<mark>(1)</mark> زبانه Python
- دور از سخت‌افزار، ساده‌تر، خوانا و سریع‌تر نوشتن.
- **ساده‌ترین برای شروع**
- خودکار مدیریت حافظه
- برای وب، دیتا، اسکریپت‌نویسی، هوش مصنوعی
```
print("Hello")
```

- ا <mark>(2)</mark> زبانه java
- - شی‌گرا، روی هر سیستم اجرا می‌شود (JVM)
- برای اندروید و نرم‌افزارهای سازمانی
```
System.out.println("Hello");
```

- ا <mark>(3)</mark> زبانه JavaScript
- - مخصوص **وب** (مرورگرها)
- برای سایت‌های تعاملی
```
console.log("Hello");
```

- ا <mark>(4)</mark> زبانه  Go / Golang
- - ساده و سریع، ساخت‌شده توسط گوگل
- برای سرورها و ابزارهای شبکه
```
fmt.Println("Hello")
```
- ا<mark>(5)</mark>زبانه rust
- مدرن، امن، خیلی سریع
- جایگزین C/C++ در خیلی پروژه‌ها
```
println!("Hello");
```

---
- **پایین‌تر** → کنترل بیشتر روی سخت‌افزار، ولی سخت‌تر و طولانی‌تر
- **بالاتر** → ساده‌تر و سریع‌تر نوشتن، ولی کنترل کمتر و اجرای کندتر
---
## زبان سطح بالا (High-Level)

- نیاز **کمتری** به درک جزئیات سخت‌افزار دارد.
- برای انسان خواناتر و یادگیری آن راحت‌تر است.
- بیشتر روی حل مسئله تمرکز می‌کنی.
- مثال: `Python`، `Java` و `JavaScript`

## زبان سطح پایین (Low-Level)

- نیاز **بیشتری** به درک پردازنده، حافظه و سخت‌افزار دارد.
- نوشتن و خواندن آن سخت‌تر است.
- به سخت‌افزار نزدیک‌تر است و کنترل بیشتری می‌دهد.
- مثال: زبان ماشین و `Assembly`
