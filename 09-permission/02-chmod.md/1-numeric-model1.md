## روش اول دادن عددی دسترسی
---
### روش Numeric در `chmod`

در روش **Numeric**، Permissionها را با عدد مشخص می‌کنیم:

```
r = 4
w = 2
x = 1
```

هر سه Permission را با هم جمع می‌کنیم و یک عدد بین `0` تا `7` به دست می‌آید.

مثلاً:

```
rwx = 4 + 2 + 1 = 7
rw- = 4 + 2 = 6
r-x = 4 + 1 = 5
r-- = 4
```

بعد برای **Owner، Group و Others** سه عدد پشت سر هم می‌نویسیم.

مثلاً:

```
chmod 755 file
```

یعنی:

```
7 → Owner
5 → Group
5 → Others
```

پس:

```
755 = rwxr-xr-x
```

یعنی در روش Numeric، ساختار کلی این است:

```
chmod [Owner][Group][Others] file
```

و هر بخش یک عدد `0` تا `7` است.
