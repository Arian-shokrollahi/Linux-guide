# su command
---
# دستور su چیست و برایه چی استفاده میشه
دستور **`su`** در لینوکس برای **Switch User** است؛ یعنی با آن می‌توانی به حساب کاربر دیگری وارد شوی یا یک shell با هویت آن کاربر باز کنی.

### 1. رفتن به کاربر دیگر

```
su alfa
```

از تو پسورد `alfa` را می‌خواهد:

```
Password:
```

اگر درست باشد، وارد shell کاربر `alfa` می‌شوی.

---

### 2. رفتن به root

```
su -
```

یا:

```
su - root
```

علامت `-` مهم است؛ باعث می‌شود محیط کاربر مقصد، مثل `HOME` و تنظیمات login، هم بارگذاری شود.

---

### 3. تفاوت `su` و `su -`

```
su alfa
```

هویت کاربر عوض می‌شود، ولی محیط فعلی تا حد زیادی حفظ می‌شود.

```
su - alfa
```

یک **login shell** برای `alfa` ایجاد می‌کند و محیط او را بارگذاری می‌کند.

---

### 4. استفاده از sudo

اگر کاربر فعلی اجازه sudo داشته باشد:

```
sudo su -
```

یا معمولاً بهتر:

```
sudo -i
```

در این حالت معمولاً پسورد **کاربر فعلی** برای sudo درخواست می‌شود، نه پسورد root.

### خروج از `su`

هر وقت خواستی برگردی:

```
exit
```

مثلاً:

```
user@kali:~$ su alfa
alfa@kali:/home/user$ exit
user@kali:~$
```

**خلاصه:**  
`su` = تغییر کاربر  
`su - user` = تغییر کاربر + محیط login آن کاربر  
`sudo -i` = گرفتن یک login shell با دسترسی root (در صورت داشتن مجوز sudo)
