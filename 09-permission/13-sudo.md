# su command
---
حتماً. دستور **`sudo`** مخفف **SuperUser Do** است و برای اجرای یک دستور با دسترسی کاربر دیگری، معمولاً `root`، استفاده می‌شود.

### 1. اجرای یک دستور با دسترسی root

```
sudo command
```

مثلاً:

```
sudo apt update
```

یا:

```
sudo systemctl restart ssh
```

سیستم معمولاً **پسورد کاربر فعلی** را می‌خواهد:

```
[sudo] password for user:
```

---

### 2. اجرای دستور به عنوان یک کاربر مشخص

```
sudo -u alfa whoami
```

خروجی:

```
alfa
```

یعنی دستور `whoami` را با هویت `alfa` اجرا کرده‌ای.

---

### 3. گرفتن shell به عنوان root

```
sudo -i
```

بعد:

```
whoami
```

خروجی:

```
root
```

برای خروج:

```
exit
```

---

### 4. تفاوت `sudo` و `su`

**`su`**:

```
su alfa
```

می‌گوید:

> برو داخل حساب `alfa`

و معمولاً پسورد **alfa** را می‌خواهد.

**`sudo`**:

```
sudo command
```

می‌گوید:

> این دستور را با دسترسی مجاز دیگری، معمولاً root، اجرا کن.

و معمولاً پسورد **کاربر فعلی** را می‌خواهد.

---

### 5. یک نکته خیلی مهم

هر کاربری نمی‌تواند از `sudo` استفاده کند. باید در تنظیمات sudo مجوز داشته باشد.

برای دیدن اینکه چه دسترسی‌هایی داری:

```
sudo -l
```

مثلاً ممکن است ببینی:

```
User user may run the following commands:
    (ALL : ALL) ALL
```

یعنی کاربر اجازه اجرای همه دستورها با sudo را دارد.

**خلاصه:**

```
su       → تغییر هویت کاربر
sudo     → اجرای یک دستور با دسترسی بالاتر/کاربر دیگر
sudo -i  → ورود به shell به عنوان root
sudo -l  → دیدن مجوزهای sudo
```
