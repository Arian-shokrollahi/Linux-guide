# از کجا بفهمیم که setfacl تنظیم شده؟
---
از روی خروجی **`getfacl`** می‌فهمی که روی فایل `setfacl` تنظیم شده یا نه.

مثلاً:

```
getfacl file.txt
```

اگر فقط این‌ها را ببینی:

```
user::rw-
group::r--
other::r--
```

یعنی **ACL اختصاصی تنظیم نشده**.

اما اگر چیز اضافه‌ای مثل این ببینی:

```
user:ali:rw-
```

یا:

```
group:developers:rwx
```

یعنی روی فایل **ACL با `setfacl` تنظیم شده**. ⭐

همچنین در خروجی `ls -l` اگر یک `+` بعد از Permissionها ببینی:

```
-rw-rw-r--+  file.txt
          ↑
```

این `+` یعنی فایل **ACL اضافی دارد**.

### خلاصه حفظی:

```
ls -l
   +
   ↓
ACL دارد

getfacl
   ↓
user:ali:rw-
یا group:...
   ↓
ACL اختصاصی تنظیم شده
```
