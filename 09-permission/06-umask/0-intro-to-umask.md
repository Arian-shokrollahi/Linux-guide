---
### 1. مفهوم `umask`

`umask` مشخص می‌کند وقتی یک **فایل یا دایرکتوری جدید** ساخته می‌شود، چه Permissionهایی به‌صورت پیش‌فرض داده نشوند.

مثلاً:

```
umask 022
```

یعنی بعضی دسترسی‌ها، مخصوصاً `write` برای Group و Others، حذف شوند.

---

### 2. کاربرد `umask`

برای تعیین **Permission پیش‌فرض فایل‌ها و فولدرهای جدید** استفاده می‌شود.

مثلاً اگر بخواهیم فایل‌های جدید برای کاربران دیگر قابل نوشتن نباشند، می‌توانیم از:

```
umask 022
```

استفاده کنیم.

---

### 3. Permission پیش‌فرض فایل‌ها

Permission پایه برای فایل‌های جدید معمولاً:

```
666
```

است:

```
rw-rw-rw-
```

اما فایل جدید معمولاً نمی‌تواند به‌صورت پیش‌فرض `execute` داشته باشد.

بعد `umask` از این Permission کم می‌کند.

---

### 4. Permission پیش‌فرض دایرکتوری‌ها

Permission پایه برای دایرکتوری جدید:

```
777
```

است:

```
rwxrwxrwx
```

بعد `umask` بعضی Permissionها را حذف می‌کند.

---

### 5. نحوه محاسبه Permission با `umask`

مثلاً:

```
Directory: 777
umask:     022
Result:    755
```

پس:

```
777 → rwxrwxrwx
022 → ---w--w-
755 → rwxr-xr-x
```

برای فایل:

```
666
022
---
644
```

پس فایل می‌شود:

```
rw-r--r--
```

---

### 6. ساختار `umask`

مثلاً:

```
umask 022
```

سه رقم اصلی داریم:

```
0 2 2
  ↑ ↑
  │ └── Others
  └──── Group
```

رقم اول مربوط به `Owner` است.

بنابراین:

```
0 = Owner
2 = Group
2 = Others
```

---

### 7. معنی هر رقم در `umask`

ارزش Permissionها:

```
r = 4
w = 2
x = 1
```

پس مثلاً:

```
2 = write
7 = read + write + execute
5 = read + execute
```

در `umask` این اعداد نشان می‌دهند چه دسترسی‌هایی **حذف شوند**.

---

### 8. `umask 022`

یکی از رایج‌ترین مقادیر است:

```
umask 022
```

برای دایرکتوری:

```
777 - 022 → 755
```

برای فایل:

```
666 - 022 → 644
```

نتیجه:

```
Directory: rwxr-xr-x
File:      rw-r--r--
```

یعنی Owner می‌تواند بنویسد، ولی Group و Others نمی‌توانند.

---

### 9. `umask 002`

```
umask 002
```

برای دایرکتوری:

```
777 → 775
```

برای فایل:

```
666 → 664
```

یعنی Group می‌تواند Write داشته باشد.

این حالت در محیط‌هایی که چند کاربر یک گروه مشترک دارند، رایج است.

---

### 10. `umask 027`

```
umask 027
```

برای دایرکتوری:

```
777 → 750
```

برای فایل:

```
666 → 640
```

یعنی Others هیچ دسترسی‌ای ندارند و Group هم Write ندارد.

---

### 11. `umask 077`

```
umask 077
```

برای دایرکتوری:

```
777 → 700
```

برای فایل:

```
666 → 600
```

یعنی فقط Owner دسترسی دارد.

این مقدار برای اطلاعات خصوصی مناسب است.

---

### 12. مشاهده مقدار `umask`

فقط بنویس:

```
umask
```

مثلاً خروجی:

```
0022
```

یعنی `umask` فعلی برابر `022` است.

---

### 13. مشاهده به شکل حروفی

با:

```
umask -S
```

می‌توانی مقدار را به شکل Symbolic ببینی.

مثلاً ممکن است چیزی شبیه این ببینی:

```
u=rwx,g=rx,o=rx
```

یعنی:

```
Owner   → rwx
Group   → r-x
Others  → r-x
```

---

### 14. تغییر موقت `umask`

مثلاً:

```
umask 077
```

از این لحظه در همان Shell، فایل‌ها و فولدرهای جدید با این `umask` ساخته می‌شوند.

اما معمولاً این تغییر بعد از خروج از Shell باقی نمی‌ماند.

---

### 15. تغییر دائمی `umask`

اگر بخواهی `umask` بعد از ورودهای بعدی هم باقی بماند، باید آن را در فایل‌های تنظیمات Shell قرار دهی.

مثلاً:

```
umask 022
```

داخل فایل مناسب Shell.

---

### 16. تنظیم `umask` در `.bashrc`

برای Bash می‌توانی داخل:

```
~/.bashrc
```

بنویسی:

```
umask 022
```

بعد تنظیمات را reload کنی:

```
source ~/.bashrc
```

---

### 17. تنظیم `umask` در `/etc/profile`

اگر بخواهی تنظیمات در سطح سیستم اعمال شود، یکی از جاهای مهم:

```
/etc/profile
```

است.

مثلاً:

```
umask 022
```

اما تغییر فایل‌های سیستمی نیاز به دسترسی مناسب دارد و باید با احتیاط انجام شود.

---

### 18. تفاوت `umask` و `chmod`

`chmod` برای **تغییر Permission یک فایل یا فولدر موجود** استفاده می‌شود:

```
chmod 755 test
```

ولی `umask` برای تعیین Permission **هنگام ساخت فایل یا فولدر جدید** است.

خلاصه:

```
umask → قبل/هنگام ساخت
chmod → بعد از ساخت
```

---

### 19. تفاوت `umask` و `chown`

`chown` برای تغییر **Owner و Group** است.

مثلاً:

```
chown ali file.txt
```

اما `umask` مربوط به Permissionهای پیش‌فرض است.

```
umask → Permission
chown → Owner / Group
```

---

### 20. تأثیر `umask` روی فایل‌های جدید

فرض کنیم:

```
umask 022
```

و بزنیم:

```
touch test.txt
```

Permission پایه فایل:

```
666
```

بعد `umask` اعمال می‌شود:

```
666 → 644
```

پس:

```
-rw-r--r--
```

---

### 21. تأثیر `umask` روی دایرکتوری‌های جدید

مثلاً:

```
umask 022
mkdir test
```

Permission پایه:

```
777
```

نتیجه:

```
755
```

یعنی:

```
drwxr-xr-x
```

---

### 22. مثال‌های محاسبه

مثلاً:

```
umask = 022
```

دایرکتوری:

```
777 → 755
```

فایل:

```
666 → 644
```

مثلاً:

```
umask = 077
```

دایرکتوری:

```
777 → 700
```

فایل:

```
666 → 600
```

مثلاً:

```
umask = 002
```

دایرکتوری:

```
777 → 775
```

فایل:

```
666 → 664
```

---

### 23. نکات امنیتی `umask`

هرچه `umask` محدودکننده‌تر باشد، فایل‌های جدید خصوصی‌تر می‌شوند.

مثلاً:

```
022 → معمولی
027 → محدودتر
077 → خصوصی
```

اگر اطلاعات حساس داشته باشی، `077` می‌تواند مناسب باشد چون Group و Others دسترسی نمی‌گیرند.

---

### 24. Numeric و Symbolic

`umask` را می‌توان به شکل عددی دید:

```
umask 022
```

یا Symbolic:

```
umask u=rwx,g=rx,o=rx
```

عددها برای کار روزمره بسیار رایج‌تر هستند.

---

### 25. نکات مهم امتحانی

این‌ها را **حتماً بلد باش**:

```
umask = Permissionهای ممنوع‌شده برای فایل/دایرکتوری جدید

File base       = 666
Directory base  = 777

umask 022:
File       = 644
Directory  = 755

umask 077:
File       = 600
Directory  = 700

umask 002:
File       = 664
Directory  = 775
```

و دستورات اصلی:

```
umask
umask -S
umask 022
```

**مهم‌ترین نکته:** `umask` را با `chmod` قاطی نکن؛ `umask` روی **چیزهای جدیدی که ساخته می‌شوند** اثر می‌گذارد، ولی `chmod` Permission **چیز موجود** را تغییر می‌دهد.
