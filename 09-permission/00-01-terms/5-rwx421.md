# قضیه ی اینکه r=4 و w=2 و x=1 چیست؟
----
این `r=4, w=2, x=1` از یک **سیستم عددگذاری باینری** میاد، نه اینکه خود لینوکس ذاتاً بگه Read برابر ۴ است.

### اصل ماجرا

برای هر دسته‌ی Permission، سه جایگاه داریم:

```
r   w   x
4   2   1
```

چرا؟

چون لینوکس Permissionها را می‌تواند به شکل **سه بیت باینری** در نظر بگیرد:

```
r   w   x
↓   ↓   ↓
2²  2¹  2⁰

4   2   1
```

یعنی:

- `r` → بیت اول → `2² = 4`
- `w` → بیت دوم → `2¹ = 2`
- `x` → بیت سوم → `2⁰ = 1`

---

### حالا ترکیبشان کن

مثلاً:

```
rwx
```

یعنی هر سه روشن هستند:

```
r w x
1 1 1
```

در باینری:

```
111
```

و:

```
1×4 + 1×2 + 1×1 = 7
```

پس:

```
rwx = 7
```

---

### چند مثال مهم

```
r-- = 100 = 4
-w- = 010 = 2
--x = 001 = 1
```

ترکیبی:

```
rw- = 110
```

پس:

```
4 + 2 = 6
```

بنابراین:

```
rw- = 6
```

و:

```
r-x = 101
```

پس:

```
4 + 1 = 5
```

یعنی:

```
r-x = 5
```

در نتیجه جدول کامل:

|Permission|Binary|عدد|
|---|---|---|
|`---`|`000`|`0`|
|`--x`|`001`|`1`|
|`-w-`|`010`|`2`|
|`-wx`|`011`|`3`|
|`r--`|`100`|`4`|
|`r-x`|`101`|`5`|
|`rw-`|`110`|`6`|
|`rwx`|`111`|`7`|
- چون ما سه عدد داریم rwx و سیستم هم با زبان 01 یا باینری میفهمه در مبنا هایه اعداد باینری گفتیم که ما میتونیم هر سه عدد باینری رو با یه عدد در مبنا نشان بدیم 
- و گفتیم 0 یعنی خاموش 1 یعنی روشن و هر جایگاه تایمی وجود دارد که یک باشد همانطوری که بالا مشاهده میکنید
### حالا `755` از کجا میاد؟

مثلاً:

```
chmod 755 file
```

سه رقم داریم:

```
7    5    5
│    │    │
│    │    └── others
│    └─────── group
└──────────── owner
```

و:

```
7 = rwx
5 = r-x
5 = r-x
```

پس:

```
755
 ↓
rwxr-xr-x
```

یعنی Owner دسترسی کامل دارد و Group و Others فقط Read و Execute دارند.

**پس کل فلسفه‌ی عددهای `0 تا 7` در chmod همین سه بیت `rwx` است:**

```
r = 4
w = 2
x = 1

4 + 2 + 1 = 7
```

این ارتباط **باینری ↔ Permission ↔ chmod** یکی از مهم‌ترین چیزهایی است که اگر بفهمی، `chmod 644` و `chmod 755` و `chmod 700` دیگه حفظی نیستند.
