# rwx
---
بخش **`rwx`** قلب مبحث Permission در لینوکس است. هر کدام از این سه حرف یک نوع دسترسی را نشان می‌دهند، و هر کدام می‌توانند **وجود داشته باشند (`r/w/x`) یا وجود نداشته باشند (`-`)**.

## 1. `r` — Read

`r` یعنی **Read = خواندن**

|مقدار|معنی|
|---|---|
|`r`|اجازه خواندن وجود دارد|
|`-`|اجازه خواندن وجود ندارد|

برای **فایل معمولی**:

```
r
```

یعنی کاربر می‌تواند محتوای فایل را بخواند.

مثلاً:

```
cat file.txt
```

اگر Permission خواندن نداشته باشی، معمولاً نمی‌توانی محتوای فایل را بخوانی.

برای **Directory**، `r` کمی متفاوت است: یعنی اجازه داری **لیست نام فایل‌ها و دایرکتوری‌های داخل آن را ببینی**.

---

## 2. `w` — Write

`w` یعنی **Write = نوشتن / تغییر دادن**

|مقدار|معنی|
|---|---|
|`w`|اجازه نوشتن وجود دارد|
|`-`|اجازه نوشتن وجود ندارد|

برای **فایل**، یعنی می‌توانی محتوای فایل را تغییر بدهی.

مثلاً:

```
echo "hello" > file.txt
```

برای **Directory**، `w` یعنی می‌توانی تغییراتی در محتویات Directory ایجاد کنی؛ مثلاً ایجاد، حذف یا تغییر نام فایل‌های داخل آن، البته در کنار Permissionهای لازم دیگر.

---

## 3. `x` — Execute

`x` یعنی **Execute = اجرا کردن**

|مقدار|معنی|
|---|---|
|`x`|اجازه اجرا وجود دارد|
|`-`|اجازه اجرا وجود ندارد|

برای **فایل معمولی**، معمولاً یعنی فایل می‌تواند به‌عنوان یک برنامه/اسکریپت اجرا شود.

مثلاً:

```
./script.sh
```

اگر فایل `x` نداشته باشد، ممکن است با خطای Permission مواجه شوی.

برای **Directory**، `x` معنای مهمی دارد: یعنی اجازه **ورود/عبور (traverse)** از آن Directory را داری؛ یعنی می‌توانی به فایل‌های داخل آن از طریق مسیرشان دسترسی پیدا کنی، مشروط به سایر Permissionها.

---

# حالت‌های مختلف `rwx`

هر Permission می‌تواند دو حالت داشته باشد:

```
r یا -
w یا -
x یا -
```

بنابراین برای یک دسته کاربر مثل Owner، Group یا Other، **۸ حالت مختلف** داریم:

|Mode|r|w|x|معنی|
|---|---|---|---|---|
|`rwx`|✅|✅|✅|خواندن + نوشتن + اجرا|
|`rw-`|✅|✅|❌|خواندن + نوشتن|
|`r-x`|✅|❌|✅|خواندن + اجرا|
|`r--`|✅|❌|❌|فقط خواندن|
|`-wx`|❌|✅|✅|نوشتن + اجرا|
|`-w-`|❌|✅|❌|فقط نوشتن|
|`--x`|❌|❌|✅|فقط اجرا|
|`---`|❌|❌|❌|هیچ دسترسی|

### پس `rwx` می‌تواند این ۸ حالت را داشته باشد:

```
rwx
rw-
r-x
r--
-wx
-w-
--x
---
```

# چرا همیشه سه‌تایی می‌بینیم؟

چون Permissionها برای **سه گروه** تعریف می‌شوند:

```
Owner    Group    Other
```

مثلاً:

```
-rwxr-xr--
```

آن را جدا می‌کنیم:

```
- | rwx | r-x | r--
    │     │     │
    │     │     └── Other
    │     └──────── Group
    └────────────── Owner
```

یعنی:

- **Owner:** `rwx` → همه دسترسی‌ها
- **Group:** `r-x` → خواندن و اجرا
- **Other:** `r--` → فقط خواندن

---

## یک نکته خیلی مهم

`rwx` برای **File** و **Directory** دقیقاً یک معنی ندارد.

|Permission|روی File|روی Directory|
|---|---|---|
|`r`|خواندن محتوای فایل|دیدن لیست محتویات|
|`w`|تغییر محتوای فایل|ایجاد/حذف/تغییر نام محتویات|
|`x`|اجرای فایل|ورود/عبور از Directory|

این تفاوت مخصوصاً برای **`x` روی Directory** خیلی مهم است و در مبحث Linux Permissions باید خوب یادش بگیری.
