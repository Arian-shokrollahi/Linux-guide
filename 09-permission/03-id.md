# id command 
---
## دستور id چیست و چیکار میکند؟
دستور `id` اطلاعات مربوط به کاربر فعلی یا یک کاربر مشخص را نمایش می‌دهد.

```
id
```

مثلاً ممکن است ببینی:

```
uid=1000(arian) gid=1000(arian) groups=1000(arian),27(sudo)
```

معنی بخش‌ها:

- `uid` → شناسه کاربر (User ID)
- `gid` → شناسه گروه اصلی (Group ID)
- `groups` → گروه‌هایی که کاربر عضو آن‌هاست

### برای یک کاربر خاص

```
id username
```

مثلاً:

```
id root
```

### گزینه‌های مهم

فقط UID:

```
id -u
```

فقط GID:

```
id -g
```

گروه‌های کاربر:

```
id -G
```

نام گروه‌ها:

```
id -Gn
```
