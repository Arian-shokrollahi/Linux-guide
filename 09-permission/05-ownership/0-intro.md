### ا-Ownership در لینوکس

در لینوکس هر **File** و **Directory** یک <mark>مالک (**Owner**) و یک گروه (**Group**)</mark> دارد.

ا-Ownership مشخص می‌کند **چه کاربری مالک فایل است و فایل متعلق به کدام گروه است**. در کنار Ownership، Permissionها تعیین می‌کنند Owner، Group و سایر کاربران چه دسترسی‌هایی به فایل یا Directory داشته باشند.

مثلاً وقتی با `ls -l` یک فایل را می‌بینیم:

```
-rw-r--r-- 1 ali developers 1200 Sep 7 test.txt
             │      │
             │      └── Group
             └───────── Owner
```

برای مدیریت Ownership، مهم‌ترین دستورهایی که بعداً یاد می‌گیریم:
- برایه مدیریت و تغییر مالک و اینکه متعلق به کدوم گروه است مااز دستور هایه زیر استفاده میکنیم
```
chown → تغییر Owner و Group
chgrp → تغییر Group
```

پس به‌صورت ساده:

```
Ownership → این فایل مال کیست؟
Permission → این شخص چه کاری می‌تواند با فایل انجام دهد؟
```
