# SGID
---
### ا-SGID چیست؟

ا-**SGID = Set Group ID**

یکی از **Special Permission**های لینوکس است.

ا-SGID دو کاربرد مهم دارد:

1. روی **فایل اجرایی**
2. روی **دایرکتوری**

---

### 1. ا-SGID روی فایل اجرایی

اگر یک فایل اجرایی SGID داشته باشد، برنامه هنگام اجرا با **Permissionهای Group صاحب فایل** اجرا می‌شود.

مثلاً:

```
Owner: root
Group: developers
SGID: فعال
```

اگر کاربر `ali` برنامه را اجرا کند، برنامه با **Group ID مربوط به `developers`** اجرا می‌شود.

یعنی:

```
User → برنامه را اجرا می‌کند
          ↓
برنامه → Group فایل را استفاده می‌کند
```

---

### 2. شکل SGID در Permission

ا-Permission عادی:

```
rwxr-xr-x
```

با SGID:

```
rwxr-sr-x
```

دقت کن `s` در قسمت **Group** ظاهر می‌شود:

```
rwx r-s r-x
    ↑
   SGID
```

پس:

```
SUID → s در قسمت User
SGID → s در قسمت Group
```

---

### 3. فعال کردن SGID روی فایل

با عددی:

```
chmod 2755 file
```

عدد **2** در ابتدای `2755` یعنی SGID.

یا به روش Symbolic:

```
chmod g+s file
```

---

### 4. ا-SGID روی دایرکتوری ⭐

این قسمت خیلی مهم‌تر است.

وقتی روی یک **دایرکتوری** SGID فعال باشد، فایل‌ها و دایرکتوری‌های جدیدی که داخل آن ساخته می‌شوند، معمولاً **Group دایرکتوری را به ارث می‌برند.**

مثلاً:

```
Directory:
Owner = ali
Group = developers
SGID = فعال
```

حالا `reza` داخل آن یک فایل می‌سازد:

```
touch test.txt
```

فایل جدید Group را از دایرکتوری می‌گیرد:

```
test.txt
Group = developers
```

به همین دلیل SGID برای **دایرکتوری‌های اشتراکی** خیلی کاربردی است.

---

### 5. شکل SGID روی دایرکتوری

مثلاً:

```
ls -ld shared
```

ممکن است ببینی:

```
drwxrwsr-x
```

اینجا:

```
drwx rws r-x
    ↑
   SGID
```

---

### 6. مثال کاربردی

فرض کن یک تیم داریم:

```
developers
```

و یک فولدر مشترک:

```
/project
```

می‌خواهیم هر فایلی که اعضای تیم داخل `/project` می‌سازند، Group آن `developers` باشد.

SGID را فعال می‌کنیم:

```
chmod g+s /project
```

حالا:

```
/project
   ↓
file1 → developers
file2 → developers
file3 → developers
```

این یکی از کاربردهای مهم SGID است.

---

### تفاوت SUID و SGID

```
SUID
↓
فایل با User/Owner فایل اجرا می‌شود

SGID
↓
فایل با Group فایل اجرا می‌شود

SGID روی Directory
↓
فایل‌های جدید Group دایرکتوری را به ارث می‌برند
```

### چیزی که برای امتحان حتماً حفظ کن:

> ا-**SGID روی فایل اجرایی → اجرای برنامه با Group صاحب فایل**

> ا-**SGID روی دایرکتوری → فایل‌ها و دایرکتوری‌های جدید، Group دایرکتوری را به ارث می‌برند.**

و عددش:

```
SUID = 4
SGID = 2
Sticky Bit = 1
```
