## 1. مقدمه‌ای بر Vim

ا-**Vim** مخفف **Vi IMproved** است و یکی از قدرتمندترین **Text Editor**های لینوکس محسوب می‌شود. برخلاف ادیتورهایی مثل Nano، کار با Vim بر اساس **Mode (حالت)** انجام می‌شود.

مهم‌ترین حالت‌ها:

|Mode|کاربرد|
|---|---|
|**Normal Mode**|جابه‌جایی، حذف، کپی، اجرای دستورات|
|**Insert Mode**|تایپ و وارد کردن متن|
|**Visual Mode**|انتخاب کردن متن|
|**Command Mode**|اجرای دستوراتی مثل ذخیره، خروج و جستجو|

نکتهٔ خیلی مهم:

```
Normal → i → Insert
Insert → Esc → Normal
Normal → : → Command
Normal → v → Visual
```

یعنی در Vim قرار نیست همیشه در حال تایپ باشی؛ **بخش زیادی از کار با دستورات و ترکیب کلیدها انجام می‌شود.**

# 2. Shortcutهای مهم Vim

### 🟢 باز کردن، ذخیره و خروج

|Shortcut|کاربرد|
|---|---|
|`vim file.txt`|باز کردن فایل|
|`i`|ورود به Insert Mode|
|`Esc`|برگشت به Normal Mode|
|`:w`|ذخیره|
|`:q`|خروج|
|`:wq`|ذخیره و خروج|
|`:q!`|خروج بدون ذخیره|
|`ZZ`|ذخیره و خروج|
|`ZQ`|خروج بدون ذخیره|

|Shortcut|کاربرد|
|---|---|
|`h`|چپ|
|`j`|پایین|
|`k`|بالا|
|`l`|راست|
|`0`|ابتدای خط|
|`$`|انتهای خط|
|`w`|رفتن به ابتدای کلمه بعدی|
|`b`|برگشت به ابتدای کلمه قبلی|

|`gg`|ابتدای فایل|

|`Ctrl + u`|نیم‌صفحه بالا|
|`Ctrl + f`|یک صفحه پایین|
|`Ctrl + b`|یک صفحه بالا|

### 🔴 حذف، کپی و Paste

|Shortcut|کاربرد|
|---|---|
|`x`|حذف یک کاراکتر|
|`dd`|حذف یک خط|
|`dw`|حذف یک کلمه|
|`D`|حذف از مکان فعلی تا انتهای خط|
|`yy`|کپی یک خط|
|`yw`|کپی یک کلمه|
|`p`|Paste بعد از مکان فعلی|
|`P`|Paste قبل از مکان فعلی|
|`u`|Undo|
|`Ctrl + r`|Redo|

یکی از مهم‌ترین مفاهیم Vim همین ترکیب‌هاست:

```
d + motion
y + motion
c + motion
```

مثلاً:

```
dw    → delete word
d$    → delete تا انتهای خط
yw    → yank/copy word
cw    → change word
```

|---|---|

|`V`|انتخاب خط|
|`Ctrl + v`|انتخاب Block/ستونی|
|`y`|کپی Selection|

### 🟠 جستجو و جایگزینی

|Shortcut|کاربرد|
|---|---|
|`/word`|جستجوی word|
|`n`|نتیجه بعدی|
|`N`|نتیجه قبلی|
|`?word`|جستجو به سمت عقب|
|`:%s/old/new/g`|جایگزینی همه old با new|
|`:noh`|حذف Highlight جستجو|

مثلاً:

```
:%s/http/https/g
```

یعنی تمام `http`ها را با `https` جایگزین کن.

### ⚙️ دستورات مهم Command Mode

|دستور|کاربرد|
|---|---|
|`:w`|Save|
|`:q`|Quit|

# 3. نکاتی که برای حرفه‌ای شدن باید بدانی

### 1. فقط Shortcut حفظ نکن؛ منطق Vim را یاد بگیر

ا-Vim بر اساس ترکیب **Operator + Motion** کار می‌کند.

مثلاً:

```
d + w  → حذف کلمه
d + $  → حذف تا انتهای خط
y + w  → کپی کلمه
c + w  → تغییر کلمه
```

وقتی این منطق را بفهمی، لازم نیست صدها shortcut را حفظ کنی.

---

### 2. با `hjkl` و Motionها راحت شو

به‌مرور سعی کن برای جابه‌جایی دائماً از Arrow Key استفاده نکنی.

مثلاً:

```
w   b   e
0   $
gg  G
```

این‌ها سرعت و کنترل تو را خیلی بالا می‌برند.

---

### 3. Vim را با ابزارهای حرفه‌ای ترکیب کن

وقتی پایه را یاد گرفتی، برو سراغ:

```
.vimrc / vim configuration
Vim plugins
buffers
windows
tabs
macros
marks
registers
search & replace
text objects
```

به‌خصوص **Text Objects** و **Macros** از چیزهایی هستند که تفاوت بین کاربر معمولی و کاربر حرفه‌ای Vim را خیلی محسوس می‌کنند.

مثلاً بعداً با چیزهایی مثل:

```
ci"
```

می‌توانی **محتویات داخل `" "` را تغییر بدهی**؛ این دقیقاً همان جایی است که Vim واقعاً قدرتمند می‌شود.
