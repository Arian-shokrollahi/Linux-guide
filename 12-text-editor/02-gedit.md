# ا-`gedit` چیست؟

ا-`gedit` یک **متن‌ویرایشگر گرافیکی (GUI Text Editor)** برای محیط دسکتاپ GNOME است.

یعنی برخلاف `nano` و `vim` که داخل Terminal اجرا می‌شوند، `gedit` یک پنجره‌ی گرافیکی دارد.

مثلاً:

```
gedit file.txt
```

فایل `file.txt` را در محیط گرافیکی باز می‌کند.

|ویژگی|توضیح|

|Auto Indentation|مرتب‌سازی خودکار فاصله‌ها|
|Plugins|قابلیت اضافه کردن Plugin|
|Encoding|پشتیبانی از Encodingهای مختلف|

# اجرای `gedit`

برای باز کردن یک فایل:

```
gedit file.txt
```

برای باز کردن چند فایل:

```
gedit file1.txt file2.txt
```

اگر فقط بنویسی:

```
gedit
```

یک فایل خالی باز می‌شود.

# `gedit` در مقابل `nano`

|ویژگی|`gedit`|`nano`|
|---|---|---|
|محیط|GUI|Terminal|
|یادگیری|آسان|آسان|
|مناسب Server بدون GUI|❌|✅|
|Syntax Highlighting|✅|محدودتر|
|Mouse|✅|محدود|
|استفاده روی Desktop|⭐⭐⭐|⭐⭐|
|استفاده روی SSH|❌ معمولاً|⭐⭐⭐|
|ویرایش سریع Config|خوب|عالی|
|نیاز به Desktop Environment|معمولاً بله|خیر|

### نکته مهم برای Linux Admin

اگر روی یک **Linux Server از طریق SSH** کار می‌کنی، معمولاً `gedit` گزینه‌ی مناسبی نیست؛ چون Server ممکن است اصلاً محیط گرافیکی نداشته باشد.

در چنین شرایطی بیشتر از:

```
nano
```

یا:

```
vim
```

استفاده می‌کنی.

اما روی Linux Desktop که GUI داری، `gedit` می‌تواند برای ویرایش فایل‌های متنی خیلی راحت باشد.

### یک نکته مهم

ا-`gedit` برای **ویرایش متن** است، نه برای اجرای دستورات Linux. مثلاً اگر فایل زیر را باز کنی:

```
gedit /etc/hosts
```

می‌توانی محتوای فایل را ببینی و ویرایش کنی، اما خود `gedit` دستورهای داخل فایل را اجرا نمی‌کند.

برای Linux Administration، بهتر است `gedit` را به‌عنوان **GUI Text Editor** بشناسی و در کنار آن `nano` و `vim` را هم یاد بگیری.
