# nano 
---
## 1. ا-Nano چیست؟

ا-`nano` یک **Text Editor ساده و ترمینالی** در Linux است که برای ایجاد و ویرایش فایل‌های متنی استفاده می‌شود.

مثلاً برای ویرایش `.bashrc`:

```
nano ~/.bashrc
```

یا برای ساخت یک فایل جدید:

```
nano test.txt
```

اگر فایل وجود نداشته باشد، `nano` آن را ایجاد می‌کند.

یکی از مزیت‌های اصلی `nano` این است که **دستورهای مهم را پایین صفحه نشان می‌دهد**، بنابراین برای شروع کار با Terminal بسیار مناسب است.

مثلاً:

```
^O Write Out
^X Exit
^W Where Is
```

علامت `^` یعنی کلید **Ctrl**.

پس:

```
^O = Ctrl + O
^X = Ctrl + X
^W = Ctrl + W
```

---

# 2. Shortcut های مهم Nano

|Shortcut|کاربرد|
|---|---|
|`Ctrl + O`|ذخیره کردن فایل (Write Out)|
|`Ctrl + X`|خروج از Nano|
|`Ctrl + S`|ذخیره فایل در نسخه‌های جدیدتر|
|`Ctrl + W`|جستجو در متن|
|`Ctrl + K`|بریدن (Cut) خط فعلی|
|`Ctrl + U`|Paste کردن متن Cut شده|
|`Ctrl + C`|نمایش موقعیت Cursor|
|`Ctrl + G`|نمایش راهنمای Nano|
|`Ctrl + _`|رفتن به یک Line خاص|
|`Alt + U`|Undo|
|`Alt + E`|Redo|
|`Ctrl + A`|رفتن به ابتدای خط|
|`Ctrl + E`|رفتن به انتهای خط|
|`Ctrl + V`|صفحه بعد|
|`Ctrl + Y`|صفحه قبل|

### مهم‌ترین‌هایی که فعلاً باید حفظ کنی:

```
Ctrl + O  → Save
Ctrl + X  → Exit
Ctrl + W  → Search
Ctrl + K  → Cut
Ctrl + U  → Paste
Ctrl + G  → Help
```

# 3. نکاتی که باید درباره Nano بدانی

### ① باز کردن فایل

```
nano filename
```

مثلاً:

```
nano ~/.bashrc
```

---

### ② ذخیره کردن

بزن:

```
Ctrl + O
```

بعد Nano اسم فایل را نشان می‌دهد؛ معمولاً فقط:

```
Enter
```

بزن تا ذخیره شود.

---

### ③ خروج

```
Ctrl + X
```

اگر تغییر ذخیره‌نشده داشته باشی، Nano می‌پرسد که آیا می‌خواهی ذخیره کنی یا نه.

معمولاً:

```
Y → Yes
N → No
```

---

### ا-④ `nano` فایل را خودش اجرا نمی‌کند

مثلاً اگر بنویسی:

```
nano ~/.bashrc
```

داری **محتوای `.bashrc` را ویرایش می‌کنی**؛ تغییرات تا زمانی که Shell فایل را دوباره نخواند، لزوماً روی Shell فعلی اعمال نمی‌شوند.

برای اعمال تغییرات:

```
source ~/.bashrc
```

---

### ا-⑤ Comment را می‌توانی با `#` بنویسی

مثلاً:

```
# My custom alias
alias ll='ls -lah'
```

---

### ⑥ قبل از تغییر فایل‌های مهم Backup بگیر

مثلاً:

```
cp ~/.bashrc ~/.bashrc.bak
```

بعد:

```
nano ~/.bashrc
```

این کار مخصوصاً برای فایل‌های مهم تنظیمات خیلی مفید است.

---

### خلاصه Nano

```
nano
 ↓
Terminal Text Editor
 ↓
ساده و مناسب مبتدی‌ها
 ↓
ویرایش Configuration + Script + Text
```

و برای شروع این ۵ تا را **حتماً حفظ کن**:

```
Ctrl + O  → Save
Ctrl + X  → Exit
Ctrl + W  → Search
Ctrl + K  → Cut
Ctrl + U  → Paste
```
