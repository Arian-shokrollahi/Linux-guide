# man command

---
## دستور man چیست?
دستور **`man`** (مخفف **Manual Page**) دفترچه راهنمای رسمی و جامع در سیستم‌عامل‌های لینوکس و یونیکس است. برعکس `help` که فقط برای دستورات داخلی شل است، `man` مرجع کاملی برای تمام برنامه‌ها، فایل‌های کانفیگ، توابع سیستمی و دستورات خارجی است.

---
## بخش‌بندی‌های راهنما (Man Sections)

مستندات لینوکس به بخش‌های شماره‌گذاری شده (۱ تا ۹) تقسیم شده‌اند:

| شماره بخش | محتوا و موضوع | مثال |
|---|---|---|
| ۱ | دستورات کاربری عمومی (User Commands) | `man 1 ls` |
| ۲ | فراخوانی‌های سیستمی هسته (System Calls) | `man 2 open` |
| ۳ | توابع کتابخانه‌ای C (Library Functions) | `man 3 printf` |
| ۴ | فایل‌های دستگاه و سخت‌افزار (Special Files/Devices) | `man 4 null` |
| ۵ | فرمت فایل‌های پیکربندی (File Formats & Configs) | `man 5 passwd` |
| ۶ | بازی‌ها و سرگرمی‌ها (Games) | `man 6 intro` |
| ۷ | مفاهیم متفرقه و پروتکل‌ها (Miscellaneous / Standards) | `man 7 ip` |
| ۸ | دستورات مدیریتی و روت (System Administration) | `man 8 iptables` |

## این جدول رو بلد باشید .
- به دلیل تعاملی بودن دستور man شما باید این کلید ها رو بلد باشید 
- و گفتم اولین چیزی که در فضایه تعاملی بلد باید بشید خروج از اون است

| کلید میانبر | عملکرد و توضیح |
|---|---|
| `q` | خروج کامل از محیط راهنما |
| `Space` یا `f` | حرکت به اندازه یک صفحه به جلو (پایین) |
| `b` | حرکت به اندازه یک صفحه به عقب (بالا) |
| `j` یا `Down Arrow` | حرکت یک خط به پایین |
| `k` یا `Up Arrow` | حرکت یک خط به بالا |
| `/<term>` | جستجوی کلمه/عبارت به سمت جلو (بعدی: `n`، قبلی: `N`) |
| `?<term>` | جستجوی کلمه/عبارت به سمت عقب |
| `g` | پرش به اولین خط سند (ابتدای فایل) |
| `G` | پرش به آخرین خط سند (انتهای فایل) |
| `h` | نمایش راهنمای تمام کلیدها و میانبرها |
