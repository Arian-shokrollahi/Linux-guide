# info command
---
## دستور info چیست؟
دستور **`info`** سیستم مستندسازی رسمی پروژه **GNU** است. برعکس `man` که صفحات متنی خطی و ثابت دارد، `info` ساختاری شبیه به وب‌سایت‌های چندصفحه‌ای متصل به هم (Hypertext بر پایه گره‌ها یا **Nodes**) دارد و مستندات بسیار عمیق‌تر و جامع‌تری از ابزارهای GNU ارائه می‌دهد.

---
## مقایسه info و man؟

| ویژگی | دستور man | دستور info |
|---|---|---|
| **پروژه مرجع** | استاندارد سنتی Unix / POSIX | پروژه رسمی GNU |
| **ساختار محتوا** | سند متنی خطی و یکپارچه | ساختار درختی، پیوندی و چندگرهی (Hypertext) |
| **سطح جزئیات** | مختصر، مرجع سریع سوییچ‌ها | عمیق، دارای مثال‌های گام‌به‌گام و آموزش مفهومی |
| **پیمایش** | اسکرول عمودی با less | جابه‌جایی بین لینک‌ها و گره‌ها (Hyperlinks) |

---
## کلیدهای میانبر اصلی در محیط `info`


| کلید میانبر | عملکرد                                                  |
| ----------- | ------------------------------------------------------- |
| `q`         | خروج از محیط info                                       |
| `Tab`       | پرش به لینک یا گره بعدی                                 |
| `Enter`     | باز کردن گره یا لینک انتخاب‌شده                         |
| `u`         | بازگشت به گره والد (Up Node)                            |
| `n`         | رفتن به بخش یا گره بعدی در همان سطح (Next Node)         |
| `p`         | رفتن به بخش یا گره قبلی در همان سطح (Previous Node)     |
| `t`         | بازگشت به صفحه اول مستند (Top Node)                     |
| `d`         | رفتن به منوی اصلی تمام راهنماهای سیستم (Directory Node) |
| `s` یا `/`  | جستجوی یک کلمه در تمام متن                              |
| `h`         | باز کردن راهنمای تعاملی کلیدهای میانبر                  |
