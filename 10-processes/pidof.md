# ا-`pidof` چیست؟

ا-`pidof` یک دستور ساده در لینوکس است که برای **پیدا کردن PID (Process ID) یک برنامه بر اساس نام آن** استفاده می‌شود.

به زبان ساده:

> اسم یک برنامه را می‌دهی، `pidof` شماره PID مربوط به آن process را برمی‌گرداند.

---

## ساختار دستور:

```
pidof [program_name]
```

مثال:

```
pidof nginx
```

خروجی:

```
1250 1251 1252
```

یعنی:

- سه process با نام nginx در حال اجرا هستند.
- PID آن‌ها:
    - 1250
    - 1251
    - 1252

---

# کاربرد واقعی برای Linux Admin

## 1) پیدا کردن PID سرویس‌ها

مثلاً:

```
pidof sshd
```

خروجی:

```
800
```

بعد می‌توانی:

```
ps -fp 800
```

بزنی و جزئیاتش را ببینی.

---

## 2) بررسی اینکه یک برنامه اجرا است یا نه

مثلاً در script:

```
if pidof nginx > /dev/null
then
    echo "nginx is running"
fi
```

اگر PID برگرداند یعنی سرویس فعال است.

---

## 3) گرفتن PID برای مدیریت process
- نکته <mark>این خیلی مهمه </mark>
مثلاً:

```
kill $(pidof nginx)
```

یعنی:

1. PIDهای nginx را پیدا کن
2. آن processها را متوقف کن

---

# Switchهای مهم `pidof`

## `-s`

فقط یک PID برمی‌گرداند.

مثال:

```
pidof -s nginx
```

خروجی:

```
1250
```

بدون `-s`:

```
pidof nginx
```

ممکن است:

```
1250 1251 1252
```

باشد.

---

## `-c`

فقط processهایی را پیدا می‌کند که در همان root directory اجرا شده‌اند.

مثال:

```
pidof -c nginx
```

کاربرد:

- وقتی چند محیط جدا (مثل chroot) داری.

---

## `-x`

scriptها را هم در نظر می‌گیرد.

مثال:

```
pidof -x backup.sh
```

برای پیدا کردن scriptهای در حال اجرا.

---

# تفاوت `pidof` و `pgrep`

|دستور|کاربرد|
|---|---|
|`pidof nginx`|فقط بر اساس نام executable PID می‌دهد|
|`pgrep nginx`|جستجوی قوی‌تر با امکانات بیشتر|
|`ps aux|grep nginx`|

مثال:

```
pidof nginx
```

خروجی:

```
1250 1251
```

ولی:

```
pgrep -a nginx
```

خروجی:

```
1250 nginx: master process
1251 nginx: worker process
```

---

# برای یک Linux Admin معمولاً:

برای چک سریع:

```
pidof nginx
```

برای اطلاعات بیشتر:

```
pgrep -a nginx
```

برای بررسی کامل:

```
ps -ef | grep nginx
```

خلاصه:

ا-`pidof` = **سریع‌ترین راه برای گرفتن PID یک برنامه با اسم آن**.
