### `ps u`

گزینه‌ی `u` باعث می‌شود خروجی `ps` را با **فرمت کاربرپسند (user-oriented format)** نمایش دهد؛ یعنی اطلاعات بیشتری درباره‌ی هر process نشان می‌دهد.

مثال:

```
ps u
```

خروجی چیزی شبیه این است:

```
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
arian     1234  0.0  1.2  50000 12000 pts/0  Ss   19:00   0:01 bash
arian     1567  2.5  3.5 200000 35000 pts/0  S    19:05   0:10 firefox
```

ستون‌های مهم:

| ستون    | معنی                              |
| ------- | --------------------------------- |
| USER    | کاربری که process را اجرا کرده    |
| PID     | شناسه process                     |
| %CPU    | درصد مصرف CPU                     |
| %MEM    | درصد مصرف RAM                     |
| VSZ     | مقدار Virtual Memory              |
| RSS     | مقدار واقعی RAM مصرف‌شده          |
| TTY     | ترمینالی که process به آن وصل است |
| STAT    | وضعیت process                     |
| START   | زمان شروع process                 |
| TIME    | زمان مصرف CPU                     |
| COMMAND | دستور اجرا شده                    |

### کاربرد واقعی

وقتی به عنوان ادمین می‌خواهی سریع بفهمی:

- کدام user چه processهایی دارد
- کدام process CPU یا RAM زیادی مصرف می‌کند
- وضعیت processها چیست

از این استفاده می‌کنی:

```
ps u
```

ولی در عمل بیشتر این‌ها را می‌بینی:

```
ps aux
```

یا:

```
ps axu
```

چون ترکیب:

- ا-`a` → processهای کاربران دیگر را هم نشان می‌دهد
- ا-`x` → processهای بدون TTY را هم نشان می‌دهد
- ا-`u` → خروجی را خواناتر می‌کند

پس:

```
ps aux
```

یکی از رایج‌ترین دستورهای بررسی process در لینوکس است.

---
## چه جوری میشه به عنوان ادمین پردازه کاربران دیگه رو ببنید

```bash
# ps -switch username
ps  -u alfa
```
