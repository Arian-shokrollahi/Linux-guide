# ps with -a and a switch
---
### ا-`ps a`

**کارش چیست؟**  
ا-`a` باعث می‌شود `ps` پردازه‌های مربوط به **تمام کاربران** را هم نمایش دهد، نه فقط پردازه‌های کاربر فعلی.

**مثال:**

```
ps a
```

**نکته مهم:**  
در `ps`، شکل نوشتن گزینه‌ها مهم است:

```
ps a
```

با:

```
ps -a
```

یکسان نیستند.

- ا-`ps a` → پردازه‌های سایر کاربران را هم در نظر می‌گیرد، با تمرکز روی پردازه‌های دارای ترمینال.
- ا-`ps -a` → یک گزینه‌ی استاندارد است و معنای متفاوتی دارد.

**کاربرد واقعی:**  
وقتی می‌خواهی سریع ببینی **چه پردازه‌هایی از کاربران مختلف روی ترمینال‌ها در حال اجرا هستند**.
