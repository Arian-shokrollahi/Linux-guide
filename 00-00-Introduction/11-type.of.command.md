┌─────────────────────────────────────────────────────────────┐
│ ۱. Alias (نام‌های مستعار)                                    │

│    مثال: alias ll='ls -la'                                  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ ۲. Reserved Keywords (کلمات کلیدی رزرو شده)                 │
│    کلمات ساختاری گرامر شل (مانند if, for, while, time)      │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ ۳. Functions (توابع شل)                                      │
│    توابع لود شده در حافظه Session جاری یا فایل‌های rc        │
│    مثال: my_func() { ... }                                  │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ ۴. Builtin Commands (دستورات داخلی شل)                       │
│    دستوراتی که درون باینری خود شل قرار دارند.                 │
│    مثال: cd, echo, pwd, exit, kill                          │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ ۵. External Commands via PATH (فایل‌های اجرایی روی دیسک)     │
│    جستجو در دایرکتوری‌های متغیر PATH به ترتیب از چپ به راست │
│    مثال: /usr/local/bin -> /usr/bin -> /bin                 │
└─────────────────────────────────────────────────────────────┘
