# 03-filesystem
# در درس سوم این فولدر مقدمه بریم سراغه فایل سیستم درون لینوکس تا اینکه ساختارش رو درک کنید و فرقشو با ویندوز بفهمید
---
### یک سوال چجوری ویندوز و سیستم عامل هایه شبه یونیکسی فایل هایه خوده رو نگه داری و سازماندهی میکنند:
ما مفهمومی داریم به اسم <mark>Hierarchical directory structure</mark> یعنی ساختار سلسه مراتبی دایرکتوری ها که منظورمون از دایرکتوری همون فولدر خودمونه.
- ا-<mark>1)</mark>ویندوز(windows): اگر درون file explorer و درون This pc تون برید مشاهده میکنید که سیستم عامل ویندوز اومده دیسک شما رو به چند پارتیشن تبدیل کرده که هرچی که میخواید بسازید باید درون این پارتیشن ها بسازید که شما با زدن win+x و رفتن به disk management میتونید ببنید که دیسک شما به چه صورت تقسیم شده و چه شکلی میتونید روش فایل هاتون رو ذخیره کنید یعنی شما ساختار سلسه مراتبی تون میتونه چند نقطه شروع داشته باشد .
```
C:\
D:\
E:\
```
- ا-<mark>2)</mark> شبه یونیکسی مثل لینوکس(uinx-like os such az linux):خوب در لینوکس همه چیز از یک نقطه شروع میشود که به اون نقطه root directory(/)میگوند کابر روت نه دایرکتوری روت که اینجا شما فرقه سیستم عامل هایه شبه یونیکسی مانند linux رو فهمیدید همه چی از یک نقطه واحد شروع میشه مثالی برایه این ساختار.
```
/
├── home
│   └── tafavote
│       ├── Documents
│       └── Downloads
├── etc
├── var
├── usr
└── mnt
    └── data

```
- حالا یه سوال جالب ما در سیستم عامل ویندوز که فلش یا یه دستگاه ذخیره ساز خاجی وصل میکردیم یه درایو یا دایرکتوری جدا از دایرکتوری هایه ویندوز میومد در لینوکس به چه صورته:
- خب در لینوکس حتی دستگاه هایه خارجی هم که وصل میشوند در لایه زیر دایرکتوری ریشه یا root dir قرار میگیرند که در درس storage device بیشتر به اون میپردازیم که با مفاهیمی مثل mount کردن و چیزایه دیگه سروکار داریم که جلوتر به برسی انها میپردازیم 
---
# خلاصه :
- 1- سیستم سازماندهی فایل ها (file system organization or file sys tree):
- در سیستم عامل هایی مانند ویندوز و شبه یونیکس مانند لینوکس برای سازماندهی فایل ها از قانون ساختار دایرکتوری سلسه مراتبی (hierarchical directory structure) استفاده میشود که:
- در ویندوز--->چند ریشه ای (mult-root)است که درخت واحد یا ریشه واحد وجود نداره
```
  C:\ (ریشه اول)
  ├── Windows
  └── Program Files

  D:\ (ریشه دوم)
  ├── Movies
  └── Games

  E:\ (ریشه سوم - مثلاً فلش USB)
  └── Backup
```
- در لینوکس--->تک ریشه (single-root)است که فقط یک درخت واحد وجود دارد و همه چی زی شاخه اون است.
```
  / (تنها ریشه کل سیستم)
  ├── bin
  ├── etc
  ├── home
  └── mnt
      └── backup  <-- (مثلاً همون فلش یا هارد دوم اینجاست)
```
- در لینوکس حتی اگر ۱۰ تا هارد دیسک و ۵ تا فلش هم به سیستم وصل کنید، درایو جدیدی مثل `F:` یا `G:` ساخته نمی‌شود؛ بلکه همگی مثل شاخه‌های جدید، به جاهای مختلف همین **یک درخت واحد (`/`)** پیوند (Mount) می‌خورند.
