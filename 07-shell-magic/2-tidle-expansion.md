# 2-Tidle expansion
---
### Tilde Expansion (`~`) در Shell

**Tilde Expansion** یعنی Shell علامت `~` را قبل از اجرای دستور به مسیر **Home Directory کاربر** تبدیل می‌کند.

به زبان ساده:

```
~
```

یعنی:

```
خانه‌ی کاربر فعلی
```

---

### مثال ساده:

فرض کن نام کاربر `fara` باشد و Home او این باشد:

```
/home/fara
```

اگر بنویسی:

```
cd ~
```

Shell قبل از اجرا تبدیل می‌کند به:

```
cd /home/fara
```

و وارد Home Directory می‌شوی.

---

### نمایش مسیر Home:

```
echo ~
```

خروجی:

```
/home/fara
```

---

### استفاده در مسیرها:

مثلاً:

```
ls ~/Documents
```

Shell تبدیل می‌کند به:

```
ls /home/fara/Documents
```

یعنی پوشه Documents داخل Home کاربر.

---

### Tilde برای کاربران دیگر

می‌توانی Home یک کاربر دیگر را هم صدا بزنی:

فرمت:

```
~username
```

مثلاً:

```
ls ~ali
```

اگر کاربر `ali` داشته باشیم:

تبدیل می‌شود به:

```
ls /home/ali
```

---

### تفاوت `~` با `/`

این دو یکی نیستند:

```
cd /
```

می‌رود به:

```
Root Directory
```

یعنی بالاترین سطح سیستم.

ولی:

```
cd ~
```

می‌رود به:

```
Home Directory
```

مثلاً:

```
/
├── bin
├── etc
├── home
│   └── fara   ← ~
└── var
```

---

### نکته مهم در Bash

Tilde فقط در بعضی موقعیت‌ها Expansion می‌شود.

مثلاً:

کار می‌کند:

```
cd ~/projects
```

اما:

```
echo "~"
```

تبدیل نمی‌شود، چون داخل کوتیشن قرار گرفته است.

خروجی:

```
~
```

ولی:

```
echo ~
```

خروجی:

```
/home/fara
```

---

### چند نوع Tilde Expansion وجود دارد:

|شکل|معنی|
|---|---|
|`~`|Home کاربر فعلی|
|`~/path`|مسیر داخل Home|
|`~user`|Home یک کاربر دیگر|
|`~+`|مسیر فعلی (`PWD`)|
|`~-`|مسیر قبلی (`OLDPWD`)|

مثلاً:

```
echo ~+
```

تقریباً مثل:

```
pwd
```

است.

---

برای مسیر DevOps، مهم‌ترین چیزی که باید حفظ کنی:

```
~
```

= **Current User Home Directory**

و اینکه قبل از اجرای دستور، Bash آن را به مسیر واقعی تبدیل می‌کند.
