# 1-brace expansion
---
## گسترش اکولاد(brace expansion)چیست؟
ا-**Brace Expansion** یا **گسترش آکولادی** یکی از قابلیت‌های Shell است که به تو اجازه می‌دهد قبل از اجرای دستور، چندین رشته یا مسیر را با یک الگوی کوتاه تولید کنی.

یعنی به جای اینکه چند بار یک چیز را بنویسی، Shell خودش آن‌ها را می‌سازد.

فرم کلی:

```
{item1,item2,item3}
```

Shell این را تبدیل می‌کند به:

```
item1 item2 item3
```

### مثال ساده:

```
echo file{1,2,3}
```

Shell قبل از اجرا تبدیل می‌کند به:

```
echo file1 file2 file3
```

خروجی:

```
file1 file2 file3
```

---

### ساخت چند فایل با یک دستور:

به جای:

```
touch test1.txt test2.txt test3.txt
```

می‌توانی بنویسی:

```
touch test{1,2,3}.txt
```

Shell آن را تبدیل می‌کند به:

```
touch test1.txt test2.txt test3.txt
```

و سه فایل ساخته می‌شود.

---

### استفاده برای مسیرها:

مثلاً:

```
mkdir project/{src,docs,images}
```

تبدیل می‌شود به:

```
mkdir project/src project/docs project/images
```

نتیجه:

```
project/
├── src/
├── docs/
└── images/
```

---

### Brace Expansion با بازه (Range)

می‌توانی عدد یا حروف را هم گسترش بدهی:

```
echo {1..5}
```

خروجی:

```
1 2 3 4 5
```

یا:

```
echo {a..e}
```

خروجی:

```
a b c d e
```

---

### با Step (گام):

مثلاً فقط اعداد زوج:

```
echo {0..10..2}
```

خروجی:

```
0 2 4 6 8 10
```

فرمت:

```
{start..end..step}
```

---

### نکته مهم برای DevOps:

ا-Brace Expansion فقط **توسط Shell انجام می‌شود** و یک قابلیت Bash است، نه یک دستور Linux.

مثلاً:

```
echo {1..3}
```

در Bash:

```
1 2 3
```

ولی اگر مستقیم به یک برنامه بدهی، خودش نمی‌فهمد:

```
python script.py {1..3}
```

اول Bash آن را باز می‌کند و بعد Python اجرا می‌شود.

---

خلاصه:

**Brace Expansion = ساخت سریع چند مقدار مشابه قبل از اجرای دستور**

کاربردهای اصلی:

- ساخت چند فایل
- ساخت ساختار فولدر
- اجرای دستور روی چند مقدار
- نوشتن اسکریپت‌های Bash کوتاه‌تر
