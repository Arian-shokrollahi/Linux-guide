# 5-arithmetic expansion
---

## ا-Arithmetic Expansion چیست؟

ا-**Arithmetic Expansion** یکی از قابلیت‌های Bash است که به ما اجازه می‌دهد محاسبات ریاضی را مستقیماً داخل Shell انجام دهیم.  
با استفاده از آن می‌توانیم عملیات‌هایی مثل جمع، تفریق، ضرب، تقسیم، باقی‌مانده و افزایش یا کاهش مقدار متغیرها را انجام دهیم.  
نتیجه محاسبه قبل از اجرای دستور اصلی توسط Bash جایگزین می‌شود.

---

# Syntax

ساختار اصلی:

```
$((expression))
```

مثال:

```
echo $((10 + 5))
```

خروجی:

```
15
```

Bash ابتدا مقدار داخل `$(())` را محاسبه می‌کند و بعد نتیجه را نمایش می‌دهد.

---

# عملگرهای Arithmetic Expansion

|عملیات|Operator|مثال|نتیجه|
|---|---|---|---|
|جمع|`+`|`$((5 + 3))`|`8`|
|تفریق|`-`|`$((10 - 4))`|`6`|
|ضرب|`*`|`$((6 * 5))`|`30`|
|تقسیم|`/`|`$((20 / 4))`|`5`|
|باقی‌مانده تقسیم|`%`|`$((10 % 3))`|`1`|
|توان|`**`|`$((2 ** 3))`|`8`|
|افزایش یک واحد|`++`|`((x++))`|x + 1|
|کاهش یک واحد|`--`|`((x--))`|x - 1|

---

# مثال‌های ساده

## 1. جمع دو عدد

```
echo $((20 + 30))
```

Output:

```
50
```

---

## 2. استفاده از متغیرها

در Bash داخل Arithmetic Expansion لازم نیست قبل از متغیر `$` بگذاریم.

```
a=10
b=5

echo $((a + b))
```

Output:

```
15
```

---

## 3. ذخیره نتیجه در متغیر

```
number=$((100 / 10))

echo $number
```

Output:

```
10
```

---

# Increment و Decrement

## افزایش مقدار

```
count=5

((count++))

echo $count
```

Output:

```
6
```

---

## کاهش مقدار

```
count=5

((count--))

echo $count
```

Output:

```
4
```

---

# تفاوت `$(( ))` و `(( ))`

## `$(( ))`

برای گرفتن خروجی محاسبه استفاده می‌شود:

```
result=$((10+20))

echo $result
```

Output:

```
30
```

---

## `(( ))`

برای انجام عملیات روی متغیرها و شرط‌ها استفاده می‌شود:

```
x=10

((x++))

echo $x
```

Output:

```
11
```

---

# مثال‌های کاربردی در Linux

## مثال 1: محاسبه حجم استفاده شده از دیسک

```
used=40
total=100

usage=$((used * 100 / total))

echo "Disk Usage: $usage%"
```

Output:

```
Disk Usage: 40%
```

---

## مثال 2: شماره‌گذاری فایل‌ها

```
for ((i=1; i<=5; i++))
do
    echo "File number $i"
done
```

Output:

```
File number 1
File number 2
File number 3
File number 4
File number 5
```

---

## مثال 3: ساخت Backup با شماره

```
backup=5

next_backup=$((backup + 1))

echo "Backup ID: $next_backup"
```

Output:

```
Backup ID: 6
```

---

## مثال 4: تبدیل ثانیه به دقیقه

```
seconds=300

minutes=$((seconds / 60))

echo "$minutes minutes"
```

Output:

```
5 minutes
```

# نکات مهم

### 1. تقسیم اعشاری نداریم

Bash به صورت پیش‌فرض Integer calculation انجام می‌دهد:

```
echo $((10 / 3))
```

Output:

```
3
```

برای محاسبات اعشاری باید از ابزارهایی مثل `bc` استفاده کنیم.

---

### 2. پرانتز داخلی قابل استفاده است

```
echo $(( (5 + 5) * 2 ))
```

Output:

```
20
```

---

### 3. متغیرها بدون `$` خوانده می‌شوند

صحیح:

```
echo $((a+b))
```

روش معمول ولی غیرضروری:

```
echo $(($a+$b))
```

# مثال واقعی در مدیریت سیستم

گرفتن تعداد CPU و محاسبه Load متوسط:

```
cpu=$(nproc)

load=50

result=$((load / cpu))

echo "Average load: $result"
```
