# 3-parmeter expansion
---
، این قابلیت برای کار با مقدار متغیرها در شِل استفاده می‌شود. ساختار اصلی آن این است:

```bash
${parameter}
```

مثلاً:

```bash
name="Ali"
echo ${name}
```

خروجی:

```
Ali
```

چند کاربرد مهم:

### 1. مقدار پیش‌فرض برای متغیر خالی یا تعریف‌نشده

```bash
echo ${var:-default}
```

اگر `var` مقدار نداشته باشد، `default` چاپ می‌شود.

مثال:

```bash
echo ${username:-guest}
```

خروجی:

```
guest
```

---

### 2. قرار دادن مقدار پیش‌فرض داخل متغیر

```bash
echo ${var:=default}
```

اگر `var` خالی باشد، مقدار `default` را به آن اختصاص می‌دهد.

---

### 3. خطا دادن اگر متغیر تعریف نشده باشد

```bash
echo ${var:?Variable is missing}
```

اگر `var` وجود نداشته باشد، خطا نمایش می‌دهد.

---

### 4. گرفتن طول یک رشته

```bash
text="Linux"
echo ${#text}
```

خروجی:

```
5
```

---

### 5. حذف بخشی از رشته

#### حذف کوتاه‌ترین تطابق از ابتدا:

```bash
file="backup.tar.gz"
echo ${file#*.}
```

خروجی:

```
tar.gz
```

#### حذف بلندترین تطابق از ابتدا:

```bash
echo ${file##*.}
```

خروجی:

```
gz
```

---

### 6. جایگزینی متن

```bash
text="hello linux"

echo ${text/linux/bash}
```

خروجی:

```
hello bash
```

جایگزینی همه موارد:

```bash
${text//old/new}
```

---

### 7. استخراج بخشی از رشته (substring)

```bash
str="abcdef"

echo ${str:2:3}
```

خروجی:

```
cde
```

فرمت:

```bash
${variable:start:length}
```

---

### 8. کار با آرایه‌ها

```bash
arr=("one" "two" "three")

echo ${arr[1]}
```

خروجی:

```
two
```

همه اعضا:

```bash
echo ${arr[@]}
```

---

خلاصه‌ی پرکاربردترین‌ها:

|دستور|کاربرد|
|---|---|
|`${var}`|مقدار متغیر|
|`${#var}`|طول متغیر|
|`${var:-x}`|مقدار پیش‌فرض|
|`${var:=x}`|مقداردهی پیش‌فرض|
|`${var:?x}`|خطا در نبود مقدار|
|`${var#pattern}`|حذف از اول|
|`${var%pattern}`|حذف از آخر|
|`${var/old/new}`|جایگزینی|
|`${var:start:length}`|بریدن رشته|

این‌ها بیشتر در **Bash scripting**، اسکریپت‌های لینوکس و اتوماسیون استفاده می‌شوند.
