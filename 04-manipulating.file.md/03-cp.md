# دستور cp چیست چیکار میکند؟
- دستور `cp
- مخفف کلمه copy است و برای کپی کردن فایل‌ها و دایرکتوری‌ها (پوشه‌ها) در سیستم‌عامل لینوکس به کار می‌رود. تسلط بر این دستور برای مدیریت فایل‌ها، پشتیبان‌گیری (Backup) و سازماندهی دیسک ضروری است.

#### ساختار کلی دستور cp
```bash
cp [OPTIONS] [SOURCE] [DESTINATION]
```

## پر کاربردترین سوییچ هایه دستور cp

| سوئیچ (Flag) | معادل طولانی | کاربرد و توضیحات |
| :--- | :--- | :--- |
| `-r` / `-R` | `--recursive` | کپی بازگشتی دایرکتوری‌ها و تمام فایل‌ها و زیرپوشه‌های درون آن‌ها |
| `-v` | `--verbose` | نمایش زنده پروسه کپی و نام فایل‌های منتقل‌شده در خروجی ترمینال |
| `-i` | `--interactive` | سوال پرسیدن قبل از بازنویسی (Overwrite) فایلی که از قبل وجود دارد |
| `-f` | `--force` | اجبار به کپی و بازنویسی فایل‌ها بدون سوال، حتی اگر فایل مقصد قفل/فقط‌خواندنی باشد |
| `-n` | `--no-clobber` | جلوگیری از بازنویسی؛ اگر فایل در مقصد وجود داشت، از روی آن رد می‌شود و کپی نمی‌کند |
| `-u` | `--update` | فقط زمانی کپی می‌کند که فایل مبدأ جدیدتر از فایل مقصد باشد یا در مقصد وجود نداشته باشد |
| `-p` | `--preserve=mode,ownership,timestamps` | حفظ سطح دسترسی‌ها (Permissions)، مالکیت (Owner/Group) و تاریخ/زمان فایل |
| `-a` | `--archive` | حالت آرشیو؛ معادل ترکیب `-dR --preserve=all` (بهترین گزینه برای بک‌آپ دقیق پوشه‌ها و لینک‌ها) |
| `-b` | `--backup` | گرفتن خودکار یک نسخه بک‌آپ (معمولاً با پسوند `~`) از فایل مقصدی که قرار است بازنویسی شود |
| `-l` | `--link` | ساخت Hard Link به جای کپی فیزیکی داده‌ها روی دیسک |
| `-s` | `--symbolic-link` | ساخت Symbolic Link (میانبر یا Symlink) به جای کپی فایل |
| `-L` | `--dereference` | در صورت مواجهه با یک Symlink، خود فایل اصلی پشت لینک را کپی می‌کند |
| `-P` | `--no-dereference` | عدم دنبال کردن Symlinkها و کپی خودِ فایل لینک (رفتار پیش‌فرض) |

## برین سراغه کاربرد هایی دستور cp؟
- 1-**پشتیبان‌گیری سریع:** قبل از تغییر در فایل‌های حساس (مثل `nginx.conf` یا `.bashrc`)، همیشه یک نسخه کپی از آن بگیرید:
```bash
   cp config.txt config.txt.bak
```
- 2-**مدیریت ساختار:** انتقال و تکثیر پروژه‌ها بدون تغییر در فایل اصلی.
- 3-**اتوماسیون:** در اسکریپت‌نویسی Bash، برای انتقال لاگ‌ها یا خروجی برنامه‌ها به دایرکتوری‌های مقصد.

---
### چند مثال کاربردی

1-**کپی یک فایل به دایرکتوری دیگر:**
```bash
cp file.txt /home/user/documents/
```
- 2-کپی یک پوشه و تمام محتویات آن:
```bash
cp -rv project_folder /backup/project_folder_copy
```
- 3-کپی چندین فایل به یک مقصد:
```bash
cp file1.txt file2.txt /home/user/backup/
```
- 4-بک‌آپ کامل یک دایرکتوری با حفظ دقیق همه متادیتا و لینک‌ها:
```bash
  cp -av /path/to/source /path/to/backup
```
- 5-کپی امن و مطمئن برای جلوگیری از پاک شدن ناخواسته داده‌ها:
```bash
  cp -iv file.txt /destination/
```
- 6-سینک کردن ساده فایل‌های تغییریافته (فقط فایل‌های جدیدتر کپی شوند):
```bash
  cp -uvr /project_dev /project_stage]
```
