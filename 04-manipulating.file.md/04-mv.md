# 04-mv command
---
# دستور mv چیست و چیکار میکند؟
- دستور `mv` مخفف **Move** است. این دستور دو کار اصلی و بسیار حیاتی در لینوکس انجام می‌دهد:

1. **جابه‌جایی (Moving):** انتقال یک فایل یا پوشه از یک مکان به مکان دیگر.
2. **تغییر نام (Renaming):** تغییر نام یک فایل یا پوشه در همان مکان یا مکان جدید.

در واقع در لینوکس، وقتی شما یک فایل را “تغییر نام” می‌دهید، سیستم در واقع آن را از نام قدیمی به نام جدید “منتقل” می‌کند.

---
## ساختار دستور mv به چه صورت است؟

```bash
mv [OPTIONS] [SOURCE] [DESTINATION]
```

---
# جدول سوییچ هایه مهم دستور mv

| سوئیچ (Flag) | معادل طولانی | کاربرد و توضیحات |
| :--- | :--- | :--- |
| `-i` | `--interactive` | **امنیت بالا:** قبل از بازنویسی (Overwrite) فایلی که در مقصد وجود دارد، از شما سوال می‌پرسد. |
| `-f` | `--force` | **اجبار:** بدون سوال پرسیدن، فایل مقصد را بازنویسی می‌کند (حتی اگر فایل مقصد قفل باشد). |
| `-n` | `--no-clobber` | **جلوگیری از تخریب:** اگر فایلی با همان نام در مقصد باشد، هیچ کاری انجام نمی‌دهد و از روی آن رد می‌شود. |
| `-u` | `--update` | **هوشمند:** فقط زمانی فایل را منتقل یا جایگزین می‌کند که فایل مبدأ جدیدتر باشد یا در مقصد وجود نداشته باشد. |
| `-v` | `--verbose` | **نمایش جزئیات:** در خروجی ترمینال نشان می‌دهد که چه فایلی به کجا منتقل شد. |
| `-b` | `--backup` | **بک‌آپ خودکار:** قبل از بازنویسی فایل مقصد، یک نسخه از فایل قدیمی را با پسوند `~` ذخیره می‌کند. |

---
## مثال هایه کاربردی دستور mv
**۱. تغییر نام یک فایل (Rename):**

اگر می‌خواهی فایل `old.txt` را به `new.txt` تغییر دهی:
```bash
mv old.txt new.txt
```
**۲. جابه‌جا کردن یک فایل به یک پوشه دیگر:**

انتقال `photo.jpg` به پوشه `Pictures`:
```bash
mv photo.jpg /home/user/Pictures/
```
**۳. جابه‌جا کردن و تغییر نام همزمان:**

انتقال فایل به یک پوشه و در همان لحظه تغییر نامش:
```bash
mv report.pdf /archives/final_report.pdf
```
**۴. جابه‌جا کردن یک پوشه کامل:**

برخلاف `cp` که حتماً نیاز به `-r` دارد، دستور `mv` برای پوشه‌ها **نیاز به سوئیچ اضافه ندارد**:
```bash
mv my_folder /tmp/
```
**۵. استفاده از حالت ایمن (بسیار توصیه می‌شود):**

برای اینکه اشتباهاً فایلی را که در مقصد هست پاک نکنی، همیشه از `-i` استفاده کن:
```bash
mv -i important_file.txt /destination/
```
---
### یک نکته فنی برای سطح Intermediate:

در لینوکس، وقتی `mv` را در **همان پارتیشن (File System)** انجام می‌دهی، عملیات بسیار سریع است چون سیستم فقط “آدرس” فایل را در جدول فایل‌ها (Inode) تغییر می‌دهد و داده‌های فیزیکی روی دیسک جابه‌جا نمی‌شوند. اما اگر بین دو پارتیشن مختلف (مثلاً از هارد اصلی به یک USB) فایل جابه‌جا کنی، لینوکس ابتدا فایل را کپی می‌کند و سپس فایل اصلی را پاک می‌کند (این یعنی زمان‌برتر و مصرف بیشتر منابع).
