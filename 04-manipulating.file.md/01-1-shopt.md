# shopt command
---
# دستور shopt چیست؟
دستور **`shopt`** (مخفف **Shell Options**) یکی از دستورات داخلی (Built-in) در پوسته **Bash** است. این دستور به شما امکان می‌دهد تا ویژگی‌های پیشرفته، اختیاری و رفتارهای کنترلی Bash را مشاهده، فعال یا غیرفعال کنید.

---
# جدول نحوه کار و سوییچ‌های اصلی `shopt`

| دستور / فلگ | کاربرد | مثال |
| :--- | :--- | :--- |
| `shopt` (بدون آرگومان) | نمایش لیست تمام آپشن‌ها و وضعیت فعال (`on`) یا غیرفعال (`off`) بودن آن‌ها | `shopt` |
| `shopt -s <opt>` | **فعال کردن (Set)** یک آپشن | `shopt -s autocd` |
| `shopt -u <opt>` | **غیرفعال کردن (Unset)** یک آپشن | `shopt -u autocd` |
| `shopt -p` | چاپ تمام آپشن‌ها با فرمتی که بتوان مجدداً به عنوان دستور اجرا کرد | `shopt -p` |
| `shopt -q <opt>` | حالت بی‌صدا (Quiet)؛ خروجی متنی ندارد و وضعیت را در کد بازگشتی (`$?`) ذخیره می‌کند (مخصوص اسکریپت) | `shopt -q globstar` |

---
# کاربردی‌ترین آپشن‌های `shopt` در لینوکس
| آپشن (Option) | کاربرد و رفتار پس از فعال‌سازی (`-s`) | مثال کاربردی |
| :--- | :--- | :--- |
| `extglob` | فعال‌سازی وایلدکاردهای پیشرفته مانند `!(pattern)` یا `@(pattern)` | `rm -rf !(main.py)` |
| `globstar` | فعال‌سازی عملگر `**` برای جستجو در تمام زیرپوشه‌ها به صورت بازگشتی | `ls **/*.log` |
| `dotglob` | گنجاندن فایل‌های پنهان (شروع با `.`) در جستجوهای وایلدکارد `*` | `cp -r * /backup/` (همراه دات‌فایل‌ها) |
| `nocaseglob` | حساس نبودن به حروف کوچک و بزرگ در جستجوی فایل‌ها (Case-insensitive) | `ls *.jpg` (فایل‌های `.JPG` را هم می‌آورد) |
| `nullglob` | اگر الگوی وایلدکارد فایلی پیدا نکند، به جای متن خام، رشته خالی برمی‌گرداند | حلقه `for file in *.tmp; do ...` |
| `autocd` | اگر فقط نام یک دایرکتوری را تایپ کرده و اینتر بزنید، خودکار وارد آن می‌شود | تایپ `/etc/nginx` (بدون نیاز به نوشتن `cd`) |
| `cdspell` | اصلاح خودکار غلط‌های املایی کوچک و جابجایی حروف حین زدن دستور `cd` | `cd /etx/ngnix` به `/etc/nginx` تصحیح می‌شود |
| `histappend` | به جای رونویسی کامل هیستوری، دستورات جدید را به انتهای فایل هیستوری اضافه می‌کند | حفظ تاریخچه در صورت باز بودن چند ترمینال |
| `dirspell` | اصلاح املایی نام پوشه‌ها در حین زدن کلید `Tab` (Auto-completion) | تکمیل خودکار مسیرهای با غلط تایپی |
| `expand_aliases` | امکان استفاده از `alias`ها در داخل اسکریپت‌های غیرتعاملی Bash | فعال‌سازی نام‌های مستعار در اسکریپت |

# مثال‌های عملی
- ۱. جابجایی سریع بین پوشه‌ها بدون نوشتن `cd`
```bash
# فعال‌سازی
shopt -s autocd

# حالا کافیست نام پوشه را تایپ کنید:
/var/log
# وارد مسیر /var/log می‌شوید!

```
- ۲. کپی کردن همه فایل‌ها حتی فایل‌های مخفی (مثل `.env` یا `.bashrc`)
```bash
# به طور پیش‌فرض * فایل‌های دات را کپی نمی‌کند
shopt -s dotglob
cp -r my_folder/* /backup/

```
- ۳. استفاده در شرط‌های Bash Script (بررسی بی‌صدا با `-q`)
```bash
if shopt -q globstar; then
    echo "Globstar is already enabled"
else
    echo "Enabling globstar..."
    shopt -s globstar
fi

```

### کته مهم: ماندگار کردن تنظیمات (Persistence)

دستوراتی که با `shopt` در ترمینال اجرا می‌کنید، **فقط تا زمان باز بودن همان سشن ترمینال** معتبر هستند.

اگر می‌خواهید آپشنی همیشه فعال باشد، آن را در انتهای فایل `~/.bashrc` خود اضافه کنید:
```bash
# باز کردن فایل کانفیگ
nano ~/.bashrc

# اضافه کردن به انتهای فایل:
shopt -s autocd globstar extglob dotglob cdspell

# اعمال فوری بدون بستن ترمینال:
source ~/.bashrc

```
