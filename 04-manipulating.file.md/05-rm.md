# 05-rm command
---
# دستور rm چیست و چیکار میکند؟
- دستور `rm` مخفف **Remove** است و برای **حذف فایل‌ها و دایرکتوری‌ها** در لینوکس استفاده می‌شود.

> ⚠️ **نکته بسیار حیاتی:** در لینوکس CLI چیزی به نام «سطل آشغال (Recycle Bin / Trash)» به‌صورت پیش‌فرض وجود ندارد. وقتی فایلی با `rm` پاک شود، بازگرداندن آن بسیار سخت یا ناممکن است؛ پس همیشه با دقت از آن استفاده کن.

---
### ساختار دستور rm 
```bash
rm [OPTIONS] [FILE/DIR...]
```
---
### جدول سوییچ هایه مهم دستور rm ؟

| سوئیچ (Flag) | معادل طولانی | کاربرد و توضیحات |
| :--- | :--- | :--- |
| `-r` / `-R` | `--recursive` | حذف بازگشتی دایرکتوری‌ها همراه با تمام فایل‌ها و زیرپوشه‌های درون آن‌ها |
| `-f` | `--force` | حذف اجباری بدون تایید یا سوال؛ خطاهای فایل‌های ناموجود را هم نادیده می‌گیرد |
| `-i` | `--interactive` | سوال پرسیدن قبل از حذف هر تک‌تک فایل‌ها (تایید تک‌به‌تک) |
| `-I` | *(بزرگ)* | سوال پرسیدن فقط یک‌بار قبل از حذف، آن هم در صورتی که بیشتر از ۳ فایل یا دایرکتوری بازگشتی باشد |
| `-d` | `--dir` | حذف دایرکتوری‌های خالی (مشابه دستور `rmdir`) |
| `-v` | `--verbose` | نمایش نام فایل‌ها و پوشه‌های حذف‌شده در خروجی ترمینال |
| `--no-preserve-root` | — | غیرفعال کردن محافظت از حذف ریشه سیستم (`/`)؛ بسیار خطرناک و مرگبار! |

---
- کاربرد ۱: حذف یک فایل تکی
```BASH
rm file.txt
```

- کاربرد ۲: حذف چند فایل هم‌زمان
```BASH
rm file1.txt file2.txt file3.pdf
```

- کاربرد ۳: حذف تمام فایل‌های یک پسوند خاص
```BASH
rm *.log
```

- کاربرد ۴: حذف یک پوشه خالی
```BASH
rm -d empty_folder/
```

- کاربرد ۵: حذف یک پوشه همراه با محتویات (بازگشتی)
```BASH
rm -r project_folder/
```

- کاربرد ۶: حذف امن با درخواست تأیید تک‌به‌تک
```BASH
rm -i sensitive_data.txt
```

- کاربرد ۷: تایید گرفتن قبل از حذف دسته‌جمعی (بیش از ۳ فایل)
```BASH
rm -I *.tmp
```

- کاربرد ۸: حذف اجباری بدون سوال و خطا
```BASH
rm -f locked_file.txt
```

- کاربرد ۹: حذف پوشه با محتویات به‌صورت اجباری و با نمایش جزئیات
```BASH
rm -rfv /tmp/old_build/
```

- کاربرد ۱۰: حذف فایلی که نامش با خط‌تیره شروع می‌شود
```BASH
rm -- -bad_name.txt
```
