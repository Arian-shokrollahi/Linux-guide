# Command chaining
---
## جدول مقایسه عملگرهای اجرای متوالی دستورات

| عملگر | نام عملگر | رفتار شرطی | مثال کاربردی |
|---|---|---|---|
| `;` | Semicolon (ترتیبی بدون شرط) | بعدی را اجرا می‌کند حتی اگر قبلی با خطا متوقف شود. | `mkdir test ; cd test ; ls` |
| `&&` | Logical AND (به شرط موفقیت) | بعدی را فقط در صورتی اجرا می‌کند که قبلی موفقیت‌آمیز (`exit 0`) باشد. | `make && make install` |
| `\|\|` | Logical OR (به شرط شکست) | بعدی را فقط در صورتی اجرا می‌کند که قبلی با خطا مواجه شود. | `ping -c 1 host \|\| echo "Host is down"` |
| `&` | Background (پس‌زمینه) | دستور را در پس‌زمینه می‌فرستد و بلافاصله به دستور بعدی می‌رود. | `sleep 5 & echo "Done immediately"` |

---
## مثال هایه این قسمت
### ۱. عملگر `;` (Sequential - بدون شرط)

دستورات بدون توجه به خطا داشتن یا نداشتن، به ترتیب اجرا می‌شوند.

- **سناریو (پاکسازی و بررسی دیسک):**
```BASH
  clear ; df -h ; free -m
```
_توضیح:_ ابتدا صفحه پاک می‌شود، سپس فضای دیسک نمایش داده می‌شود و بعد از آن مصرف رم چاپ می‌شود (حتی اگر یکی با خطا مواجه شود، بقیه حتماً اجرا می‌شوند).

---
### ۲. عملگر `&&` (Logical AND - به شرط موفقیت)

دستور بعدی **تنها در صورتی اجرا می‌شود** که دستور قبلی با موفقیت (Exit Code `0`) تمام شود.
- سناریو ۱ <mark>(آپدیت مخازن و سپس ارتقای پکیج‌ها):</mark> 
```bash
  sudo apt update && sudo apt upgrade -y
```
_توضیح:_ اگر اینترنت قطع باشد و `apt update` خطا دهد، هرگز `apt upgrade` اجرا نمی‌شود تا پکیج ناقص نصب نشود.
- سناریو ۲ (ساخت پوشه و ورود به آن):
```bash
  mkdir myproject && cd myproject
```
_توضیح:_ فقط در صورتی وارد پوشه می‌شود که پوشه با موفقیت ساخته شده باشد.

---
### ۳. عملگر `||` (Logical OR - به شرط شکست/خطا)

دستور بعدی **تنها در صورتی اجرا می‌شود** که دستور قبلی با خطا (Exit Code غیر صفر) مواجه شود (برای فال‌بک یا مدیریت خطا).

- **سناریو ۱ (پینگ سرور و ارسال پیام خطا):**
```bash
  ping -c 1 8.8.8.8 || echo "Network is unreachable!"
```
_توضیح:_ اگر پینگ ناموفق باشد، پیام خطا روی صفحه چاپ می‌شود.
- **سناریو ۲ (ساخت پوشه در صورت نبودن):**
```bash
`cd backup_dir || mkdir backup_dir'
```

_توضیح:_ سعی می‌کند وارد پوشه شود؛ اگر پوشه وجود نداشت (خطا داد)، آن را می‌سازد.

---
### ۴. عملگر `&` (Background Execution - ارسال به پس‌زمینه)

دستور در پس‌زمینه اجرا می‌شود و پرامپت ترمینال بلافاصله برای دستورات بعدی آزاد می‌شود.

- **سناریو ۱ (دانلود فایل حجیم در بک‌گراند بدون قفل شدن شل):**
```bash
  `wget https://example.com/bigfile.iso &`
```
_توضیح:_ دانلود بدون متوقف کردن ترمینال در پس‌زمینه اجرا می‌شود.
- **سناریو ۲ (اجرای همزمان چند تسک موازی):**
```bash
  `python3 script1.py & python3 script2.py &`
```
_توضیح:_ هر دو اسکریپت به صورت همزمان (Parallel) در پس‌زمینه شروع به کار می‌کنند.

---
### ترکیب حرفه‌ای: ساختار شرطی کامل (If-Else تک‌خطی)

می‌توانی `&&` و `||` را ترکیب کنی:
```bash
systemctl is-active nginx && echo "Nginx is running" || echo "Nginx is stopped"
```
