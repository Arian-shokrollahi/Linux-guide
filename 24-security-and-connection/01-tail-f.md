# 01-tail -f command
# دستور tail -f-
---
- دستور **`tail -f`** (مخفف **Follow**) برای **دیدن تغییرات زنده و لحظه‌ای انتهای یک فایل** استفاده می‌شود. یعنی تا زمانی که دستور فعال است، هر خط جدیدی که برنامه‌ها به آن فایل اضافه کنند، بلافاصله روی صفحه ترمینال شما چاپ می‌شود.

#### و کاربرد هایی که دارد رو خلاصشو بهتون میگم
- برسی امنیت و تلاش های ورود ناموفق(SSH)
```bash
tail -f /var/log/auth.log
```
- مثلا میتونید ببنید کسی در حال تست پسورد رویه سرور شما است یا نه

خیلی کار هایه دیگه هم میکند ولی چون گذاشتم امنیت اسم فولدرشو به همین دلیل این کاربردشو گفتم

---
### اگر فرد از راه دور (از طریق شبکه و SSH) حمله کند، IP کجاست؟
- در لاگ تلاش برای ورود با SSH، آی‌پی دقیقاً ثبت می‌شود:
```bash
Aug 28 16:10:05 ubuntu-server sshd[4521]: Failed password for invalid user admin from 192.168.1.105 port 54321 ssh2

```
#### تحلیل IP در این لاگ:

- ا-**`Failed password`**: پسورد اشتباه بود.
- ا-**`from 192.168.1.105`**: **آی‌پی شخص مهاجم/ورود کننده.**
- ا-**`port 54321`**: پورتی که فرد از سیستم خودش وصل شده.
- ا-**`user admin`**: نام کاربری‌ای که فرد تلاش کرده با آن لاگین کند.

---
## و نکات پایانی درمورد tail -f  /var/log/auth.log
- 1-برایه اونایی که با ssh وصل میشوند رو نشون 
- 2- اگر دستور sudo رو اشتباه بزنید نشون 
- و خیلی کارهایه دیگه هم میکنند 
- کلا باید این رو بزارید در یه ترمینال باشه تا لحظه ای چک کنید
- و جدا کردن خطه مد نظرتون از اخر فایل tail -f /var/log/auth.log
```bash
tail -f -n (number line of last ../auth.log you want) /var/log/auth.log
```
