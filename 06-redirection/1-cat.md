# cat command
---
## ## ا-`cat` چیست؟

ا-`cat` مخفف **concatenate** است و در لینوکس برای **نمایش محتویات فایل، ترکیب فایل‌ها و انتقال محتوا** استفاده می‌شود

### ### سویچ‌های مهم `cat`

تبدیل چند خط خالی پشت‌سرهم به یک خط خالی

| Switch | کاربرد |
|---|---|
| -n | شماره‌گذاری تمام خطوط |
| -b | شماره‌گذاری فقط خطوط غیرخالی |
| -A | نمایش کاراکترهای مخفی |
| -E | نمایش انتهای هر خط با `$` |
| -T | نمایش Tab به صورت `^I` |
| -s | تبدیل چند خط خالی پشت‌سرهم به یک خط خالی |

### ۳ مثال مهم

**1. نمایش فایل:**

```bash
cat file.txt
```

**2. شماره‌گذاری خطوط:** این مهمه 

```bash
cat -n file.txt
```

**3. ترکیب دو فایل:**

```bash
cat file1.txt file2.txt > combined.txt
```

یعنی محتوای `file1.txt` و `file2.txt` را پشت سر هم می‌گذارد و داخل `combined.txt` ذخیره می‌کند.
