# grep command 
---
## 1. دستور `grep` چیست؟

دستور `grep` برای جست‌وجوی کلمه یا الگوی متنی در فایل‌ها و خروجی دستورات استفاده می‌شود.

```bash
grep [options] "pattern" file
```
---
# سوییچ هایه مهم دستور grep

| سوییچ | توضیح                                 |
| ----- | ------------------------------------- |
| `-i`  | نادیده گرفتن تفاوت حروف بزرگ و کوچک   |
| `-n`  | نمایش شماره خطوط                      |
| `-v`  | نمایش خطوطی که با الگو مطابقت ندارند  |
| `-r`  | جست‌وجوی بازگشتی داخل پوشه‌ها         |
| `-w`  | جست‌وجوی کلمه کامل                    |
| `-c`  | شمارش خطوط منطبق                      |
| `-l`  | نمایش نام فایل‌های دارای نتیجه        |
| `-E`  | استفاده از Regular Expression پیشرفته |
| `-A`  | نمایش خطوط بعد از نتیجه               |
| `-B`  | نمایش خطوط قبل از نتیجه               |
| `-C`  | نمایش خطوط قبل و بعد از نتیجه         |

---
## . مثال‌ها

جست‌وجوی یک کلمه داخل فایل:

```
grep "error" log.txt
```

جست‌وجو بدون حساسیت به حروف بزرگ و کوچک:

```
grep -i "linux" file.txt
```

نمایش شماره خطوط پیدا‌شده:

```
grep -n "error" log.txt
```

جست‌وجو در تمام فایل‌های یک پوشه:

```
grep -r "database" /etc
```

جست‌وجو در خروجی یک دستور:

```
ps aux | grep "nginx"
```

شمارش خط‌های دارای کلمه `error`:

```
grep -c "error" log.txt
```

جست‌وجوی چند الگو:

```
grep -E "error|warning" log.txt
```

نمایش سه خط قبل و بعد از نتیجه:

```
grep -C 3 "error" log.txt
```

## کاربرد دستور `grep`

دستور `grep` زمانی استفاده می‌شود که بخواهیم اطلاعات مشخصی را میان حجم زیادی از متن پیدا کنیم. برخی کاربردهای مهم آن عبارت‌اند از:

- پیدا کردن خطاها در فایل‌های Log
- جست‌وجو داخل فایل‌های تنظیمات
- پیدا کردن یک Process در خروجی دستورات
- بررسی فایل‌های پروژه و کدهای برنامه‌نویسی
- فیلتر کردن خروجی دستورات دیگر

مثال در مدیریت سرور:

```
grep -i "failed" /var/log/auth.log
```

این دستور تلاش‌های ناموفق ثبت‌شده در فایل لاگ احراز هویت را پیدا می‌کن
