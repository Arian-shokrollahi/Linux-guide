# tee command
---
## 1. دستور `tee` چیست؟

دستور `tee` خروجی یک دستور را هم‌زمان در ترمینال نمایش می‌دهد و داخل یک فایل ذخیره می‌کند.

```bash
command | tee [options] file
```
---

## 2. سوییچ‌های مهم

| سوییچ       | توضیح                                                     |
| ----------- | --------------------------------------------------------- |
| `-a`        | اضافه‌کردن خروجی به انتهای فایل بدون پاک‌کردن محتوای قبلی |
| `-i`        | نادیده گرفتن سیگنال‌های وقفه مانند `Ctrl+C`               |
| `-p`        | مدیریت و گزارش خطاهای مربوط به Pipe                       |
| `--help`    | نمایش راهنمای دستور                                       |
| `--version` | نمایش نسخه برنامه                                         |

---
## 3. مثال‌ها

نمایش خروجی و ذخیره آن در فایل:

```
ls -la | tee files.txt
```

اضافه‌کردن خروجی به انتهای فایل:

```
date | tee -a log.txt
```

ذخیره خروجی در چند فایل:

```
ls | tee file1.txt file2.txt
```

ذخیره خروجی یک دستور و ارسال آن به دستور بعدی:

```
cat access.log | tee backup.log | grep "404"
```

نوشتن داخل فایل سیستمی با دسترسی `sudo`:

```
echo "127.0.0.1 example.local" | sudo tee -a /etc/hosts
```

مخفی‌کردن خروجی ترمینال و ذخیره آن در فایل:

```
ls | tee files.txt > /dev/null
```

---
## کاربرد دستور `tee`

دستور `tee` زمانی استفاده می‌شود که بخواهیم خروجی یک دستور را هم مشاهده کنیم و هم برای بررسی‌های بعدی داخل فایل ذخیره کنیم.

کاربردهای مهم آن:

- ذخیره خروجی دستورات هنگام عیب‌یابی
- ثبت گزارش اجرای اسکریپت‌ها
- ذخیره اطلاعات داخل چند فایل
- اضافه‌کردن محتوا به فایل‌های سیستمی با `sudo`
- ارسال خروجی به یک فایل و دستور دیگر به‌صورت هم‌زمان

تفاوت آن با `>`:

```
command > file
```

خروجی را فقط داخل فایل ذخیره می‌کند؛ اما:

```
command | tee file
```

ا-<mark>خروجی را هم نمایش می‌دهد و هم داخل فایل ذخیره می‌کن</mark>
