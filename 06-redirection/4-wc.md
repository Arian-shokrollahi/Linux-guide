# wc command
---

## 1. دستور `wc` چیست؟

دستور `wc` مخفف **Word Count** است و برای شمارش خطوط، کلمات، کاراکترها و حجم یک فایل استفاده می‌شود.

```bash
wc [options] file
```

| سوییچ | توضیح                     |
| ----- | ------------------------- |
| `-l`  | شمارش تعداد خطوط          |
| `-w`  | شمارش تعداد کلمات         |
| `-c`  | شمارش حجم فایل برحسب بایت |
| `-m`  | شمارش تعداد کاراکترها     |
| `-L`  | نمایش طولانی‌ترین خط      |

--- 
## مثال هایه مهم دستور wc

نمایش تعداد خطوط، کلمات و بایت‌های فایل:

```
wc file.txt
```

شمارش تعداد خطوط:

```
wc -l file.txt
```

شمارش تعداد کلمات:

```
wc -w file.txt
```

شمارش تعداد کاراکترها:

```
wc -m file.txt
```

شمارش فایل‌های داخل یک پوشه:

```
ls | wc -l
```

شمارش خطوطی که شامل کلمه `error` هستند:

```
grep "error" log.txt | wc -l
```
