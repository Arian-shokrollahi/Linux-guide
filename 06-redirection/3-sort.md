# sort command
---

## 1. دستور `sort` چیست؟

دستور `sort` برای مرتب‌سازی خطوط یک فایل یا خروجی یک دستور استفاده می‌شود.

```bash
sort [options] file
```
## 2.سوییچ هایه مهم دستور sort

| سوییچ | توضیح                               |
| ----- | ----------------------------------- |
| `-n`  | مرتب‌سازی عددی                      |
| `-r`  | مرتب‌سازی معکوس                     |
| `-u`  | مرتب‌سازی و حذف خطوط تکراری         |
| `-f`  | نادیده گرفتن تفاوت حروف بزرگ و کوچک |
| `-k`  | مرتب‌سازی براساس ستون مشخص          |
| `-t`  | تعیین جداکننده ستون‌ها              |
| `-o`  | ذخیره نتیجه در یک فایل              |

---
## 3.مثال هایه مهم دستور sort
مرتب‌سازی حروف الفبایی:

```shell
sort names.txt
```

مرتب‌سازی عددی:

```shell
sort -n numbers.txt
```
حذف خطوط تکراری:

```bash
sort -u names.txt
```
ذخیره خروجی مرتب‌شده در فایل:

```s
sort names.txt -o sorted-names.txt
```
