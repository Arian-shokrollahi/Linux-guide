Escape Sequence چیست؟

در Bash، وقتی می‌خواهیم داخل Prompt اطلاعات خاصی را نمایش دهیم، از Escape Sequenceها استفاده می‌کنیم.

این Escapeها معمولاً با \ شروع می‌شوند و Bash آن‌ها را هنگام نمایش Prompt به یک مقدار واقعی تبدیل می‌کند.

مثلاً:

PS1="\u@\h:\w\$ "

در اینجا:

\u → نام کاربر
\h → نام سیستم
\w → مسیر فعلی
\$ → علامت $ یا #

بنابراین ممکن است نتیجه چیزی شبیه این باشد:

arian@ubuntu:~/projects$

یعنی به‌جای اینکه اطلاعات را مستقیماً داخل Prompt بنویسیم، از Escape Sequenceها استفاده می‌کنیم تا Bash آن اطلاعات را به‌صورت داینامیک نمایش دهد.

Escape Sequenceهای مهم در Bash Prompt
Escape	کاربرد	مثال نتیجه
\u	Username	arian
\h	Hostname تا اولین .	ubuntu
\H	Hostname کامل	ubuntu.example.com
\w	مسیر کامل دایرکتوری فعلی	/home/arian/project
\W	فقط نام دایرکتوری فعلی	project
\~	—	معمولاً از \w برای مسیر استفاده می‌شود
\$	$ برای user و # برای root	$
\t	ساعت با فرمت 24 ساعته	14:30:25
\T	ساعت 12 ساعته	02:30:25
\@	ساعت 12 ساعته با AM/PM	02:30 PM
\d	تاریخ	Thu Sep 10
\n	رفتن به خط بعد	—
\e	Escape character	برای رنگ‌ها و کنترل‌های ترمینال
\[	شروع کاراکترهای غیرقابل‌نمایش	برای رنگ‌ها
\]	پایان کاراکترهای غیرقابل‌نمایش	برای رنگ‌ها
\!	شماره دستور در History	125
\#	شماره ترتیبی دستور	125
\j	تعداد Jobهای در حال اجرا	2
\a	صدای هشدار (Bell)	—
\\	نمایش \	\
چند موردی که اول باید خوب بلد باشی

برای شروع، این‌ها مهم‌ترین‌ها هستند:

\u    Username
\h    Hostname
\w    Current Directory
\W    Current Directory Name
\t    Time
\d    Date
\n    New Line
\$    $ / #

بعد از این‌ها، رنگ‌ها و \[ / \] را یاد بگیر؛ چون برای ساخت Promptهای حرفه‌ای خیلی کاربردی هستند.
