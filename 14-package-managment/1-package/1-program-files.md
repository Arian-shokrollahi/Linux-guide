# 1. ا-Program Files چیست؟

یکی از مهم‌ترین بخش‌های یک **Package**، فایل‌های مربوط به خود برنامه است که به آن‌ها **Program Files** می‌گوییم.

این فایل‌ها همان چیزهایی هستند که باعث می‌شوند نرم‌افزار بتواند **اجرا شود و کار اصلی خودش را انجام دهد**.

مثلاً فرض کن Package مربوط به `nginx` را نصب می‌کنیم. داخل Package فایل‌هایی وجود دارند که برنامه‌ی `nginx` برای اجرا به آن‌ها نیاز دارد.

معمولاً فایل‌های اجرایی برنامه در مسیرهایی مثل این قرار می‌گیرند:

```
/usr/bin
/usr/sbin
```

مثلاً:

```
/usr/bin/python3
/usr/bin/curl
/usr/sbin/nginx
```

---

## ا-Program Files دقیقاً شامل چه چیزهایی هستند؟

ا-Program Files می‌توانند شامل موارد مختلفی باشند:

```
Program Files
   |
   ├── Executable files
   ├── Binary files
   ├── Program resources
   └── Supporting files
```

### 1. ا-Executable / Binary

این‌ها فایل‌هایی هستند که برنامه را اجرا می‌کنند.

مثلاً:

```
/usr/bin/curl
```

وقتی اجرا می‌کنی:

```
curl example.com
```

سیستم در نهایت فایل اجرایی مربوط به `curl` را اجرا می‌کند.

---

### 2. ا-Supporting Files

بعضی برنامه‌ها برای اجرا به فایل‌های دیگری هم نیاز دارند؛ مثلاً فایل‌های resource یا فایل‌های داخلی برنامه.

ممکن است در مسیرهایی مثل این قرار داشته باشند:

```
/usr/lib
/usr/share
```

---

## یک مثال ساده

فرض کن Package مربوط به یک برنامه این ساختار را داشته باشد:

```
myapp-package
   |
   ├── /usr/bin/myapp
   ├── /usr/lib/myapp/...
   └── /usr/share/myapp/...
```

اینجا:

```
/usr/bin/myapp
```

فایل اصلی اجرایی برنامه است و فایل‌های دیگر برای پشتیبانی از آن هستند.
