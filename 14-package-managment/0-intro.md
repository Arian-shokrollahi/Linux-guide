### مقدمه‌ای بر Package Management در Linux

در لینوکس، **Package Management** به مجموعه‌ای از ابزارها و روش‌ها گفته می‌شود که برای **نصب، حذف، بروزرسانی، جستجو و مدیریت نرم‌افزارها و وابستگی‌های آن‌ها** استفاده می‌شود.

در لینوکس معمولاً نرم‌افزارها به شکل **Package** توزیع می‌شوند. یک Package فقط خود برنامه نیست؛ می‌تواند شامل فایل‌های اجرایی، کتابخانه‌ها، فایل‌های تنظیمات، اطلاعات نسخه و وابستگی‌های موردنیاز برنامه باشد.

برای مدیریت این Packageها از ابزاری به نام **Package Manager** استفاده می‌کنیم.

مثلاً در Debian و Ubuntu ابزار اصلی:

```
apt
```

و در سیستم‌های مبتنی بر Red Hat معمولاً:

```
dnf
```

است.

ا-Package Manager کارهایی مثل این را انجام می‌دهد:

```
Install     → نصب نرم‌افزار
Remove      → حذف نرم‌افزار
Update      → بروزرسانی اطلاعات Packageها
Upgrade     → بروزرسانی نرم‌افزارها
Search      → جستجوی Package
Dependency  → مدیریت وابستگی‌ها
```

### یک مثال ساده

فرض کن می‌خواهیم `nginx` را نصب کنیم:

```
sudo apt install nginx
```

ا-Package Manager علاوه بر نصب `nginx`، **Dependencyهای موردنیاز آن را نیز بررسی و در صورت نیاز نصب می‌کند.**

پس به‌صورت خلاصه:

> ا-**Package Management یعنی مدیریت چرخه‌ی عمر نرم‌افزارها در Linux؛ از پیدا کردن و نصب Package تا بروزرسانی، حذف و مدیریت Dependencyهای آن‌ها.**
