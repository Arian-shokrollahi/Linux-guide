## ا-Special Character چیست؟

در Regex، **Special Character** کاراکتری است که برخلاف یک Literal Character، **معنی خاصی در ساختن Pattern دارد**.

یعنی Regex آن را صرفاً به‌عنوان خودِ آن کاراکتر در نظر نمی‌گیرد؛ بلکه آن کاراکتر به Regex می‌گوید **چطور Pattern را تفسیر کند**.

مثلاً:

```
.
```

در بسیاری از Regexها، `.` یعنی:

> هر کاراکتر

پس اگر Pattern این باشد:

```
a.b
```

می‌تواند این‌ها را match کند:

```
aab
acb
a7b
a-b
```

چون `.` در اینجا خودش یک نقطه معمولی نیست؛ یک **Special Character** است.

---

چند Special Character مهم:

```
.   *   +   ?   ^   $   [ ]   ( )   |
```

هرکدام در Regex یک معنی خاص دارند.

مثلاً:

```
^error
```

`^` می‌گوید:

> ا-Pattern باید از ابتدای خط شروع شود.

و:

```
error$
```

`$` می‌گوید:

> ا-Pattern باید در انتهای خط قرار داشته باشد.

---

### تفاوت با Literal Character

```
a
```

`a` → **Literal Character**  
یعنی دقیقاً حرف `a`.

```
.
```

`.` → **Special Character**  
یعنی یک معنی خاص در Regex دارد.

اگر واقعاً بخواهی **خودِ نقطه `.`** را پیدا کنی، باید آن را از حالت special خارج کنی که به این کار **escaping** می‌گوییم:

```
\.
```

یعنی:

> دقیقاً یک نقطه واقعی `.` را پیدا کن.

پس:

ا-**Literal Character → خودش را نشان می‌دهد.**

ا-**Special Character → به Regex دستور یا معنی خاصی می‌دهد.**
