برای تبدیل یک **Special Character** به **Literal Character** در Regex، معمولاً از **Escape Character یعنی `\`** استفاده می‌کنیم.

یعنی با گذاشتن `\` قبل از Special Character، به Regex می‌گوییم:

> «این کاراکتر را به معنی خاصش تفسیر نکن؛ خودِ همین کاراکتر را دنبال کن.»

مثلاً:

```
.
```

اینجا `.` یک Special Character است و معمولاً معنی «هر کاراکتر» دارد.

اگر بخواهیم خودِ نقطه را match کنیم:

```
\.
```

حالا `.` به‌صورت Literal در نظر گرفته می‌شود.

چند مثال:

```
.   → \.
*   → \*
+   → \+
?   → \?
^   → \^
$   → \$
(   → \(
)   → \)
[   → \[
]   → \]
```

پس مفهوم اصلی که باید یادت بماند:

```
Special Character
       ↓
      \ 
       ↓
Literal Character
```

به این عمل **escaping** می‌گوییم.
