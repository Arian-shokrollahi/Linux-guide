## ا-Pattern چیست؟

ا-**Pattern یعنی یک الگو یا قانون مشخص برای اینکه بگویی «دقیقاً دنبال چه شکلی از داده یا متن هستم».**

ا-Pattern می‌تواند خیلی ساده باشد یا پیچیده.

مثلاً اگر بگویی:

```
error
```

این یک Pattern ساده است؛ یعنی دنبال همین متن می‌گردی.

اما می‌توانی Pattern را عمومی‌تر تعریف کنی:

```
چیزی که با error شروع می‌شود
```

یا:

```
چیزی که شامل یک عدد است
```

یا:

```
چیزی که با .log تمام می‌شود
```

در واقع Pattern لزوماً خودِ داده نیست؛ **توصیفی از شکل داده‌ای است که می‌خواهی پیدا کنی.**

مثلاً اگر این متن را داشته باشیم:

```
error
error123
warning
error connection failed
```

و Pattern ما این باشد:

```
چیزی که با error شروع می‌شود
```

آن‌وقت:

```
error                  ✓
error123               ✓
error connection failed ✓
warning                ✗
```

پس Pattern مشخص می‌کند:

> **چه چیزی Match شود و چه چیزی Match نشود.**

در Regex، ما از syntax مخصوص Regex استفاده می‌کنیم تا این Patternها را دقیق و قابل‌فهم برای کامپیوتر بنویسیم.
