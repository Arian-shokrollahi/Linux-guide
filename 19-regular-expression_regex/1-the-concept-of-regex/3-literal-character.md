## ا-Literal Character چیست؟

در Regex، **Literal Character** یعنی کاراکتری که می‌خواهی **دقیقاً خودِ همان کاراکتر** در متن وجود داشته باشد.

یعنی کاراکتر هیچ معنی خاص و ویژه‌ای در Regex ندارد و Regex آن را همان‌طور که هست در نظر می‌گیرد.

مثلاً:

```
a
```

یعنی:

> دقیقاً یک `a` پیدا کن.

اگر متن این باشد:

```
cat
```

حرف `a` یک **literal character** است و با `a` موجود در `cat` match می‌شود.

مثلاً:

```
error
```

در اینجا تمام کاراکترهای:

```
e r r o r
```

به‌صورت literal هستند؛ یعنی Regex به دنبال همین حروف می‌گردد.

### نکته مهم

در Regex بعضی کاراکترها **معنی ویژه** دارند، مثل:

```
.  *  +  ?  ^  $  [  ]  (  )
```

اما حروف معمولی مثل:

```
a
b
x
7
```

معمولاً literal هستند.

پس خیلی ساده:

> ا-**Literal Character = کاراکتری که Regex آن را دقیقاً به‌عنوان همان کاراکتر در متن جستجو می‌کند، نه به‌عنوان یک دستور یا الگوی ویژه.**
