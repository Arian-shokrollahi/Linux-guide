

# ا-Quantifier چیست؟

فرض کن این Regex را داریم:

```
a
```

یعنی:

> یک `a` پیدا کن.

حالا اگر بخواهیم بگوییم:

> ا-`a` باید چند بار تکرار شود

از **Quantifier** استفاده می‌کنیم.

مثلاً:

```
a*
```

یعنی:

> ا-`a` صفر بار یا بیشتر تکرار شود.

---

## ا-Quantifierهای اصلی

|Quantifier|معنی|
|---|---|
|`*`|صفر بار یا بیشتر|
|`+`|یک بار یا بیشتر|
|`?`|صفر بار یا یک بار|
|`{n}`|دقیقاً `n` بار|
|`{n,}`|حداقل `n` بار|
|`{n,m}`|بین `n` تا `m` بار|

حالا یکی‌یکی:

---

## 1. `*` — صفر بار یا بیشتر

```
a*
```

یعنی:

> ا-`a` می‌تواند **صفر بار، یک بار، دو بار، سه بار، ...** تکرار شود.

مثلاً:

```
a
aa
aaa
aaaa
```

همه با `a*` سازگارند.

حتی:

یعنی هیچ `a`ای هم وجود نداشته باشد.

### مثال مهم

```
colou*r
```

می‌تواند این‌ها را match کند:

```
color
colour
colouur
colouuur
```

چون `u*` یعنی:

> ا-`u` صفر بار یا بیشتر.

---

# 2. `+` — یک بار یا بیشتر

```
a+
```

یعنی:

> ا-`a` باید **حداقل یک بار** وجود داشته باشد.

پس:

```
a
aa
aaa
aaaa
```

match می‌شوند.

ولی:

match نمی‌شود.

تفاوت مهم:

```
a*
```

یعنی:

> صفر یا بیشتر

ولی:

```
a+
```

یعنی:

> یک یا بیشتر

### مثال

```
[0-9]+
```

یعنی:

> یک یا چند رقم پشت سر هم.

پس:

```
1
12
123
12345
```

match می‌شوند.

---

# 3. `?` — صفر یا یک بار

```
a?
```

یعنی:

> `a` اختیاری است؛ یا وجود دارد یا ندارد.

مثلاً:

```
colou?r
```

هر دو را match می‌کند:

```
color
colour
```

چون `u?` یعنی:

```
u → 0 یا 1 بار
```

ولی این:

```
colouur
```

match نمی‌شود، چون `u` دو بار آمده است.

---

# 4. `{n}` — دقیقاً n بار

```
a{3}
```

یعنی:

> دقیقاً ۳ تا `a`.

مثلاً:

```
aaa
```

ولی:

```
aa
aaaa
```

نه.

مثال خیلی کاربردی:

```
[0-9]{4}
```

یعنی:

> دقیقاً چهار رقم.

مثلاً:

```
1234
2026
9876
```

---

# 5. `{n,}` — حداقل n بار

```
a{3,}
```

یعنی:

> حداقل ۳ تا `a`.

پس:

```
aaa
aaaa
aaaaa
aaaaaa
```

همه می‌توانند match شوند.

اما:

```
aa
```

نه.

مثلاً:

```
[0-9]{8,}
```

یعنی:

> حداقل ۸ رقم.

---

# 6. `{n,m}` — بین n تا m بار

```
a{2,4}
```

یعنی:

> `a` حداقل ۲ بار و حداکثر ۴ بار.

پس:

```
aa
aaa
aaaa
```

مجاز هستند.

ولی:

```
a
aaaaa
```

نه.

مثال:

```
[0-9]{3,5}
```

یعنی:

> عددی با ۳ تا ۵ رقم.

---

# ا-Quantifier فقط برای یک کاراکتر نیست

این قسمت خیلی مهم است.

ا-Quantifier می‌تواند روی **Character Class** هم اعمال شود:

```
[0-9]+
```

یعنی:

> یک یا چند رقم.

یا:

```
[a-z]{3}
```

یعنی:

> سه حرف کوچک انگلیسی.

مثلاً:

```
cat
dog
abc
```

---

همچنین می‌تواند روی **گروه** اعمال شود:

```
(ab)+
```

یعنی:

> `ab` یک یا چند بار تکرار شود.

پس:

```
ab
abab
ababab
```

match می‌شوند.

اینجا دقت کن:

```
ab+
```

با:

```
(ab)+
```

فرق دارد.

### `ab+`

یعنی فقط `b` تکرار شود:

```
ab
abb
abbb
abbbb
```

### `(ab)+`

یعنی کل `ab` تکرار شود:

```
ab
abab
ababab
```

---

# یک تصویر ذهنی خیلی خوب

ا-Quantifier را مثل یک **کنترل تعداد** ببین:

```
Pattern + Quantifier
       ↓
      [a] + 
       ↓
   چند بار؟
       ↓
   1 یا بیشتر
```

مثلاً:

```
[0-9]+
```

ساختارش:

```
[0-9]   +
  ↓     ↓
یک رقم   یک یا بیشتر
```

پس:

```
123456
```

یعنی:

```
1 2 3 4 5 6
└──────────┘
   [0-9]+
```

---

## خلاصه‌ای که باید حفظ کنی

```
*       → 0 یا بیشتر
+       → 1 یا بیشتر
?       → 0 یا 1
{n}     → دقیقاً n
{n,}    → حداقل n
{n,m}   → بین n و m
```

مثلاً:

```
[0-9]*       # صفر یا بیشتر رقم
[0-9]+       # یک یا بیشتر رقم
[0-9]?       # صفر یا یک رقم
[0-9]{3}     # دقیقاً 3 رقم
[0-9]{3,}    # حداقل 3 رقم
[0-9]{3,5}   # 3 تا 5 رقم
```

**اصل اصلی Quantifier این است:**

> ا-Character Class یا Character یا Group می‌گوید **چه چیزی** را می‌خواهم؛ Quantifier می‌گوید **چند بار** می‌خواهم.
