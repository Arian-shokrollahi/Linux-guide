## علائم اصلی Regex

|Syntax|نام|معنی|
|---|---|---|
|`a`|Literal|خودِ `a`|
|`.`|Dot|هر یک کاراکتر|
|`^`|Anchor|ابتدای خط|
|`$`|Anchor|انتهای خط|
|`*`|Quantifier|صفر یا بیشتر|
|`+`|Quantifier|یک یا بیشتر|
|`?`|Quantifier|صفر یا یک|
|`{n}`|Quantifier|دقیقاً `n` بار|
|`{n,m}`|Quantifier|بین `n` تا `m` بار|
|`[]`|Character Class|یکی از کاراکترهای داخل `[]`|
|`[^]`|Negated Class|هر کاراکتری به‌جز موارد داخل `[]`|
|`()`|Group|گروه‌بندی Pattern|
|`\|`|Alternation|یا|
|`\`|Escape|خارج کردن کاراکتر از معنی خاصش|

---

### 1. Literal

```
error
```

یعنی دقیقاً دنبال:

```
error
```

بگرد.

---

### 2. `.`

```
a.b
```

یعنی:

```
aab
acb
a7b
a-b
```

چون `.` می‌تواند یک کاراکتر باشد.

---

### 3. `^`

```
^error
```

یعنی `error` باید **ابتدای خط** باشد.

```
error: failed      ✓
something error    ✗
```

---

### 4. `$`

```
error$
```

یعنی `error` باید **انتهای خط** باشد.

```
something error    ✓
error something    ✗
```

# Quantifierها

ا-Quantifier می‌گوید یک Pattern **چند بار تکرار شود**.

### `*`

```
ab*
```

یعنی:

```
a
ab
abb
abbb
...
```

ا-`b` می‌تواند **صفر بار یا بیشتر** تکرار شود.

---

### `+`

```
ab+
```

یعنی:

```
ab
abb
abbb
...
```

ا-`b` باید **حداقل یک بار** وجود داشته باشد.

---

### `?`

```
colou?r
```

می‌تواند match کند:

```
color
colour
```

چون `u` می‌تواند **صفر یا یک بار** باشد.

---

### `{n}`

```
a{3}
```

یعنی دقیقاً:

```
aaa
```

---

### `{n,m}`

```
a{2,4}
```

یعنی:

```
aa
aaa
aaaa
```

# Character Class

یکی از مهم‌ترین بخش‌های Regex:

```
[abc]
```

یعنی:

> یکی از `a` یا `b` یا `c`

پس:

```
a   ✓
b   ✓
c   ✓
d   ✗
```

### Range

```
[a-z]
```

یکی از حروف کوچک انگلیسی.

```
[0-9]
```

یکی از اعداد.

می‌توانی ترکیب هم بکنی:

```
[a-zA-Z0-9]
```

یعنی یک حرف کوچک، حرف بزرگ یا عدد.

---

# Negated Character Class

با `^` داخل `[]`:

```
[^0-9]
```

یعنی:

> هر کاراکتری به‌جز عدد.

مثلاً:

```
a   ✓
-   ✓
@   ✓
5   ✗
```

**دقت کن:** `^` داخل `[]` با `^` ابتدای Pattern یک مفهوم متفاوت دارد.

---

# Group

با:

```
()
```

قسمتی از Pattern را گروه‌بندی می‌کنیم.

مثلاً:

```
(ab)+
```

یعنی `ab` را یک واحد در نظر بگیر و آن را یک یا بیشتر تکرار کن:

```
ab
abab
ababab
```

---

# Alternation — `|`

یعنی **OR**.

مثلاً:

```
cat|dog
```

یعنی:

> `cat` یا `dog`

پس:

```
cat   ✓
dog   ✓
cow   ✗
```

معمولاً همراه Group خیلی استفاده می‌شود:

```
(cat|dog)s
```

یعنی:

```
cats
dogs
```

---

# Escape — `\`

برای اینکه یک Special Character را **Literal** کنیم.

مثلاً:

```
\.
```

یعنی خودِ نقطه واقعی:

```
.
```

مثلاً برای پیدا کردن:

```
file.txt
```

بهتر است بنویسیم:

```
file\.txt
```

چون `.` در حالت عادی Special Character است.

---

# یک دسته Syntax خیلی کاربردی دیگر

Regex چند shorthand مهم هم دارد که بعداً خیلی با آنها کار می‌کنی:

|Syntax|معنی|
|---|---|
|`\d`|یک digit|
|`\D`|غیر digit|
|`\w`|word character|
|`\W`|غیر word character|
|`\s`|whitespace|
|`\S`|غیر whitespace|

مثلاً:

```
\d+
```

یعنی:

> یک یا چند digit پشت سر هم.

مثل:

```
123
42
98765
```
