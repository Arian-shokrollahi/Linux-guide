# ا-1. Groups — گروه‌ها `()`

در Regex از پرانتز استفاده می‌کنیم:

```
(...)
```

برای اینکه چند کاراکتر را **به‌عنوان یک واحد** در نظر بگیریم.

مثلاً:

```
(ab)+
```

اینجا:

```
(ab)
 ↑
یک Group
```

و `+` روی **کل `ab`** اعمال می‌شود.

پس:

```
ab
abab
ababab
```

match می‌شوند.

اما اگر بنویسیم:

```
ab+
```

`+` فقط روی `b` اعمال می‌شود:

```
ab
abb
abbb
abbbb
```

پس یکی از مهم‌ترین کاربردهای Group:

> **چند کاراکتر را تبدیل به یک واحد کنیم تا بتوانیم روی کل آن Quantifier اعمال کنیم.**

---

## مثال کاربردی

فرض کن می‌خواهی این الگو را پیدا کنی:

```
ha
haha
hahaha
```

می‌توانی بنویسی:

```
(ha)+
```

چون:

```
(ha)
 ↓
یک واحد

(ha)+
 ↓
یک یا چند بار
```

# ا-2. Group برای سازمان‌دهی Pattern

ا-Group فقط برای Quantifier نیست.

مثلاً:

```
(ab|cd)
```

اینجا کل:

```
ab|cd
```

داخل یک گروه قرار گرفته است.

یعنی:

```
(ab|cd)
```

یک واحد محسوب می‌شود.

این ما را می‌رساند به **Alternation**.

---

# 3. Alternation — انتخاب بین چند حالت `|`

علامت:

```
|
```

یعنی:

> **OR** یا «یا»

مثلاً:

```
cat|dog
```

یعنی:

> `cat` یا `dog`

پس در این متن:

```
I have a cat.
I have a dog.
I have a bird.
```

دو مورد match می‌شوند:

```
cat
dog
```

ولی:

```
bird
```

نه.

---

# 4. Group + Alternation

اینجا قدرت واقعی‌شان مشخص می‌شود.

فرض کن می‌خواهی یکی از این‌ها را پیدا کنی:

```
cat
dog
bird
```

می‌نویسی:

```
(cat|dog|bird)
```

یعنی:

```
       ┌── cat
       ├── dog
(...) ─┤
       └── bird
```

در واقع:

```
(cat|dog|bird)
```

یعنی:

> یکی از `cat` یا `dog` یا `bird`.

---

# 5. تفاوت `|` بدون Group و با Group

این قسمت **خیلی مهم** است.

فرض کن بنویسیم:

```
I like cat|dog
```

از نظر Regex معمولاً به شکل زیر تفسیر می‌شود:

```
I like cat
     OR
dog
```

یعنی `|` فقط بین دو بخش خودش عمل می‌کند.

اما اگر منظورمان این باشد:

> `I like cat` یا `I like dog`

باید بنویسیم:

```
I like (cat|dog)
```

حالا:

```
          ┌── cat
I like (  ┤
          └── dog
```

یعنی:

```
I like cat
OR
I like dog
```

---

# 6. Group + Quantifier + Alternation

می‌توانیم این سه مفهوم را با هم ترکیب کنیم.

مثلاً:

```
(go|run)+
```

یعنی:

> `go` یا `run` یک یا چند بار تکرار شود.

پس می‌تواند match کند:

```
go
run
gog o
runrun
gorun
rung o
```

البته بدون فاصله، مثلاً:

```
gogorun
runrun
gorungo
```

اینجا ساختار Regex این است:

```
(go|run)+
   │   │
   │   └── Alternation
   │
   └────── Group

       +
       ↓
   تکرار کل Group
```

---

# یک مثال خیلی کاربردی

فرض کن می‌خواهی URLهایی را پیدا کنی که با:

```
http
```

یا:

```
https
```

شروع می‌شوند.

می‌توانی بنویسی:

```
https?
```

ولی از دید **Group + Alternation** می‌توانی مفهوم مشابه را این‌طور ببینی:

```
(http|https)
```

اینجا:

```
(http|https)
      ↑
     OR
```

یعنی:

```
http
OR
https
```

# یک نکته مهم درباره Group

هر چیزی که داخل `()` قرار بگیرد، یک **واحد منطقی** می‌شود.

مثلاً:

```
(abcd)+
```

یعنی:

```
abcd
abcdabcd
abcdabcdabcd
```

ولی:

```
abcd+
```

یعنی فقط `d` تکرار شود:

```
abcd
abcdd
abcddd
abcdddd
```

پس همیشه از خودت بپرس:

> ا-Quantifier روی **کدام قسمت** اعمال می‌شود؟

---

## خلاصه

### Group

```
(...)
```

یعنی:

> چند قسمت را به یک واحد منطقی تبدیل کن.

### Alternation

```
|
```

یعنی:

> این **یا** آن.

### ترکیبشان

```
(cat|dog)
```

یعنی:

> `cat` یا `dog`

و:

```
(cat|dog)+
```

یعنی:

> ا-`cat` یا `dog`، یک بار یا بیشتر تکرار شود.

**پس سه مفهوم را این‌طور در ذهنت نگه دار:**

```
()  → گروه‌بندی
|   → یا
+   → تکرار
```

و وقتی ترکیب می‌شوند:

```
(cat|dog)+
```

یعنی:

```
      ┌── cat ──┐
      │         │
     (cat|dog)  + 
      │         │
      └── dog ──┘
          ↓
    یکی از این دو
    یک یا چند بار
```
