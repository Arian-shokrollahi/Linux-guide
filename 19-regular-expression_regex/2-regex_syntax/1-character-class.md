## ا-Character Class چیست؟

ا-**Character Class** یکی از مهم‌ترین بخش‌های Regex است و با `[]` نوشته می‌شود.

ایده اصلی خیلی ساده است:

> ا-Character Class می‌گوید: **در این جای Pattern، یکی از این کاراکترها باید قرار بگیرد.**

مثلاً:

```
[abc]
```

یعنی:

> یک کاراکتر که `a` یا `b` یا `c` باشد.

پس:

```
a  ✓
b  ✓
c  ✓
d  ✗
```

نکته مهم این است که `[abc]` به معنی **رشته‌ی `abc`** نیست؛ فقط **یک کاراکتر** را match می‌کند.

---

### چند کاراکتر مشخص

```
[aeiou]
```

یعنی یک vowel:

```
a ✓
e ✓
i ✓
o ✓
u ✓
b ✗
```

مثلاً:

```
c[aeiou]t
```

می‌تواند این‌ها را match کند:

```
cat
cet
cit
cot
cut
```

---

## Range

داخل Character Class می‌توانی یک محدوده تعریف کنی.

```
[a-z]
```

یعنی:

> هر حرف کوچک انگلیسی از `a` تا `z`

مثلاً:

```
a ✓
m ✓
z ✓
A ✗
5 ✗
```

همین‌طور:

```
[A-Z]
```

حروف بزرگ.

و:

```
[0-9]
```

یک رقم.

می‌توانی چند Range را هم ترکیب کنی:

```
[a-zA-Z0-9]
```

یعنی:

> یک حرف کوچک، حرف بزرگ یا عدد.

---

# Negated Character Class

اگر `^` را **اول Character Class** قرار بدهی، معنی آن برعکس می‌شود:

```
[^0-9]
```

یعنی:

> هر کاراکتری **به‌جز** عدد.

مثلاً:

```
a  ✓
X  ✓
@  ✓
-  ✓
5  ✗
```

پس:

```
[0-9]
```

یعنی:

> فقط این‌ها

ولی:

```
[^0-9]
```

یعنی:

> همه‌چیز به‌جز این‌ها

---

# چند Character Class در یک Pattern

مثلاً:

```
[0-9][0-9][0-9]
```

یعنی:

> سه رقم پشت سر هم.

پس:

```
123  ✓
456  ✓
12   ✗
abc  ✗
```

اما این را می‌توانیم کوتاه‌تر کنیم:

```
[0-9]{3}
```

یعنی:

> یک رقم، دقیقاً سه بار.

---

# نکته خیلی مهم درباره `[]`

وقتی می‌نویسی:

```
[abc]
```

این:

```
a
b
c
```

را **یکی‌یکی** بررسی می‌کند.

اما:

```
(abc)
```

یک **گروه** می‌سازد که شامل رشته‌ی:

```
abc
```

است.

بنابراین:

```
[abc]
```

≠

```
(abc)
```

اولی یعنی **یکی از سه کاراکتر**؛ دومی یعنی **رشته‌ی `abc` به‌عنوان یک گروه**.

---

## خلاصه

```
[abc]       → یکی از a یا b یا c
[a-z]       → یکی از a تا z
[A-Z]       → یکی از A تا Z
[0-9]       → یکی از 0 تا 9
[a-zA-Z]    → یک حرف انگلیسی
[a-zA-Z0-9] → یک حرف یا عدد
[^0-9]      → هر چیزی به‌جز عدد
```

پس مفهوم اصلی Character Class این است:

> **`[]` به Regex می‌گوید در این موقعیت، یک کاراکتر از مجموعه‌ای که مشخص کرده‌ای انتخاب شود.**
