تفاوت `grep` و `grep -E` در اصل برمی‌گرده به **نوع Regexای که `grep` استفاده می‌کنه**.

## ا-`grep` vs `grep -E`

به‌صورت پیش‌فرض:

```
grep 'REGEX' file.txt
```

از **BRE (Basic Regular Expressions)** استفاده می‌کند.

اما:

```
grep -E 'REGEX' file.txt
```

از **ERE (Extended Regular Expressions)** استفاده می‌کند.

یعنی خود دستور `grep` عوض نشده؛ چیزی که تغییر می‌کند **Regex syntax**ای است که `grep` قبول می‌کند.

---

## تفاوت اصلی

|مفهوم|`grep` → BRE|`grep -E` → ERE|
|---|---|---|
|Zero or more|`*`|`*`|
|One or more|`\+`|`+`|
|Zero or one|`\?`|`?`|
|Exactly n|`\{n\}`|`{n}`|
|Range|`\{n,m\}`|`{n,m}`|
|Group|`\(...\)`|`(...)`|
|OR|`\|`|`|
|Character Class|`[...]`|`[...]`|
|Start|`^`|`^`|
|End|`$`|`$`|

پس تفاوت اصلی این است که در **ERE** بعضی syntaxها مستقیماً special هستند و دیگر لازم نیست برایشان `\` بگذاری.

---

## یک مثال ساده

فرض کن می‌خواهیم:

> یک یا چند رقم

را پیدا کنیم.

با `grep` معمولی:

```
grep '[0-9]\+' file.txt
```

با `grep -E`:

```
grep -E '[0-9]+' file.txt
```

هر دو یک مفهوم دارند:

```
[0-9]+
   ↓
یک یا چند رقم
```

فقط syntax متفاوت است.

---

## مثال Group و OR

فرض کن می‌خواهیم `cat` یا `dog` را پیدا کنیم.

### با `grep`

```
grep '\(cat\|dog\)' file.txt
```

### با `grep -E`

```
grep -E '(cat|dog)' file.txt
```

دومی خواناتر است.

---

## یک مثال مهم‌تر

فرض کن می‌خواهیم خط‌هایی را پیدا کنیم که با:

```
error
```

یا:

```
warning
```

شروع می‌شوند و بعد از آن یک یا چند رقم دارند.

با ERE خیلی تمیز می‌شود:

```
grep -E '^(error|warning): [0-9]+$' file.txt
```

ساختار:

```
^                  → ابتدای خط
(error|warning)    → error یا warning
:                  → :
[0-9]+             → یک یا چند رقم
$                  → انتهای خط
```

مثلاً:

```
error: 404
warning: 123
```

می‌توانند match شوند.

---

# پس چرا `grep -E` استفاده کنیم؟

چون وقتی Regex ساده است، تفاوت زیادی احساس نمی‌کنی.

مثلاً:

```
grep 'error' file.txt
```

کاملاً کافی است.

اما وقتی Regex شامل:

- `+`
- `?`
- `{n,m}`
- `()`
- `|`

می‌شود، `grep -E` معمولاً **خواناتر و راحت‌تر** است.

مثلاً این:

```
grep -E '(cat|dog)+'
```

خیلی راحت‌تر از:

```
grep '\(cat\|dog\)\+'
```

خوانده می‌شود.

---

## یک نکته مهم

ا-`grep -E` به معنی «Regex قوی‌تر در تمام جنبه‌ها» نیست.

در واقع:

```
grep
 ↓
BRE
```

و:

```
grep -E
 ↓
ERE
```

هر دو **Regular Expression** هستند؛ فقط syntax و مجموعه‌ی operatorهایشان متفاوت است.

همچنین `grep -E` همان چیزی است که قدیم‌تر با نام:

```
egrep
```

شناخته می‌شد. امروزه معمولاً بهتر است از:

```
grep -E
```

استفاده کنی.

### خلاصه‌ی خیلی مهم

```
grep
  ↓
BRE
  ↓
syntax قدیمی‌تر
  ↓
برای + ? () | معمولاً نیاز به \ دارد


grep -E
  ↓
ERE
  ↓
syntax راحت‌تر
  ↓
+ ? () | مستقیماً قابل استفاده‌اند
```

اگر بخواهی در کارهای Linux و DevOps Regex بنویسی، **`grep -E` را خیلی زیاد خواهی دید**، مخصوصاً وقتی Regex از حالت ساده خارج می‌شود.
