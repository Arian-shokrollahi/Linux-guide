# 12-which of command 
---
## دستور Which  چیکار میکند؟
دستور **`which`** یکی از دستورات پرکاربرد لینوکس است که وظیفه دارد **مسیر فایل اجرایی (Executable Path)** یک دستور خارجی را در دایرکتوری‌های متغیر `$PATH` پیدا کند و آدرس کامل آن را نمایش دهد.

---
### ۱. کارکرد `which` به زبان ساده

وقتی شما می‌نویسید:
```bash
which python3
```
شل به ترتیب دایرکتوری‌های متغیر `$PATH` (مثلاً `/usr/local/bin`، `/usr/bin` و …) را می‌گردد و اولین فایلی با نام `python3` را که دسترسی اجرا (Executable) دارد پیدا کرده و چاپ می‌کند:
```bash
/usr/bin/python3
```
### 2تفاوت بسیار مهم: `which` در برابر `type`

بزرگ‌ترین محدودیت `which` این است که **فقط دیسک و متغیر `$PATH` را می‌شناسد** و از ساختار داخلی شل (مثل Aliasها، Functionها و Builtinها) کاملاً بی‌خبر است.

| ویژگی | دستور `which` | دستور `type` |
| :--- | :--- | :--- |
| **شناسایی فایل‌های خارجی ($PATH)** | ✅ دارد | ✅ دارد |
| **شناسایی دستورات توکار (Builtin)** | ❌ ندارد (برای `cd` چیزی پیدا نمی‌کند) | ✅ دارد (`cd is a shell builtin`) |
| **شناسایی توابع شل (Functions)** | ❌ ندارد | ✅ دارد |
| **شناسایی کلمات کلیدی (Keywords)** | ❌ ندارد | ✅ دارد |
| **شناسایی نام‌های مستعار (Aliases)** | ⚠️ بسته به توزیع/نسخه شل | ✅ دقیقاً نشان می‌دهد |
| **محل اجرا** | یک برنامه باینری خارجی (`/usr/bin/which`) | داخلی شل (Shell Builtin) |

---
### 3. کاربرد عملی در دنیای واقعی

1. **عیب‌یابی محیط‌های مجازی (Virtual Environments):**برای اینکه بفهمید پایتون از سیستم اصلی اجرا می‌شود یا از درون venv:
```bash

   which python
   # /home/user/myenv/bin/python
```
2. **نوشتن Shebang در اسکریپت‌ها:**وقتی می‌خواهید مسیر دقیق مفسر را در خط اول اسکریپت بگذارید
```bash
   which bash
   # خروجی: /bin/bash -> پس می‌نویسید: #!/bin/bash
```
