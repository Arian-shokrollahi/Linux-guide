## دستور type چیست و چیکار میکند؟
- دستور `type` یکی از ابزارهای داخلی (Builtin) شل (مانند Bash یا Zsh) است که به شما کمک می‌کند بفهمید یک دستور خاص دقیقاً چیست و سیستم آن را چگونه شناسایی و اجرا می‌کند.

- به زبان ساده: وقتی شما دستوری را در ترمینال تایپ می‌کنید، شل باید تصمیم بگیرد که آن را چگونه اجرا کند. `type` به شما نشان می‌دهد که شل چه تصمیمی می‌گیرد.

---

| ردیف | نوع دستور | ماهیت (داخلی/خارجی) | نحوه عملکرد | مثال |
| :---: | :--- | :---: | :--- | :--- |
| **۱** | **Aliases** (نام‌های مستعار) | داخلی | جایگزین‌های متنی کوتاه برای دستورات طولانی | `alias update='sudo apt update'` |
| **۲** | **Keywords** (کلمات کلیدی) | داخلی | گرامر ساختاری زبان شل برای شروط و حلقه‌ها | `if`, `then`, `for`, `while`, `case` |
| **۳** | **Functions** (توابع) | داخلی | مجموعه‌ای از دستورات نام‌گذاری‌شده در حافظه شل | `backup() { tar -czf ... ; }` |
| **۴** | **Builtins** (دستورهای توکار) | داخلی | کدهای کامپایل‌شده داخل باینری شل (به دلیل نیاز به تغییر محیط شل) | `cd`, `pwd`, `export`, `exit`, `history` |
| **۵** | **External Executables** (فایل‌های خارجی) | خارجی | فایل‌های باینری کامپایل‌شده (C/Go/...) یا اسکریپت‌ها (`.sh`, `.py`) روی هارد | `/bin/ls`, `/usr/bin/git`, `/usr/bin/python3` |

### مثال‌های کاربردی

برای تست، این دستورات را در ترمینال خود بزنید:
```bash
# بررسی یک دستور داخلی
type cd
# خروجی: cd is a shell builtin

# بررسی یک دستور اجرایی
type grep
# خروجی: grep is /usr/bin/grep

# بررسی یک Alias (اگر تعریف شده باشد)
type ll
# خروجی: ll is aliased to `ls -alF'

```

### سوییچ‌های (Options) مهم

گاهی نیاز دارید جزئیات بیشتری بدانید:

- **`type -a` (همه موارد):** اگر یک دستور هم به صورت Alias باشد و هم به صورت فایل اجرایی، این سوییچ همه مکان‌های آن را لیست می‌کند.
- **`type -t` (فقط نوع):** خروجی را کوتاه می‌کند و فقط نوع دستور را می‌گوید (مثلاً فقط چاپ می‌کند `file` یا `builtin`).
- **`type -p` (فقط مسیر):** فقط مسیر فایل اجرایی را برمی‌گرداند (اگر دستور یک فایل باشد).

**چرا `type` مهم است؟**

این دستور برای عیب‌یابی (Troubleshooting) عالی است. مثلاً اگر فکر می‌کنید نسخه خاصی از یک برنامه (مثل Python) در حال اجراست اما نسخه دیگری اجرا می‌شود، با `type python` می‌توانید ببینید شل دقیقاً کدام فایل اجرایی را از کدام مسیر در حال صدا زدن است.
