# alias command
## create your own command with alias 
---
## دستور alias چیست و چیکار میکند
دستور **`alias`** در لینوکس (محیط شل) ابزاری است برای ساخت **نام مستعار** یا میانبر برای دستورات طولانی، پیچیده یا پرکاربرد. با `alias` می‌توانی تایپ دستورات را بسیار سریع‌تر و کار در ترمینال را راحت‌تر کنی.

این دستور جزو دستورات داخلی شل (**Shell Built-in**) است.

---
### جدول فرمت و سینتکس دستور `alias`

| ساختار دستور | توضیح عملکرد | مثال |
|---|---|---|
| `alias` | نمایش تمام aliasهای فعال در شل فعلی | `alias` |
| `alias name='command'` | ساخت یک alias موقت جدید | `alias ll='ls -la'` |
| `alias name='cmd1; cmd2'` | ساخت alias برای چند دستور متوالی | `alias update='sudo apt update && sudo apt upgrade -y'` |
| `unalias name` | حذف یک alias مشخص | `unalias ll` |
| `unalias -a` | حذف تمام aliasهای تعریف‌شده در شل فعلی | `unalias -a` |
| `\command` | اجرای دستور اصلی بدون اعمال alias روی آن | `\ls` |

---
## نمونه کاربردی و واقعی (Real-world Aliases)

| نام Alias | دستور کامل | فایده و هدف |
|---|---|---|
| `ll` | `ls -la --color=auto` | لیست کردن فایل‌ها به صورت کامل، با جزئیات و رنگی |
| `update` | `sudo apt update && sudo apt upgrade -y` | آپدیت کامل سیستم با تایپ فقط یک کلمه |
| `rm` | `rm -i` | جلوگیری از فاجعه: قبل از حذف هر فایل تاییدیه (Prompt) می‌گیرد |
| `c` | `clear` | پاک کردن سریع ترمینال با فشردن یک کلید |
| `ports` | `ss -tulpn` | دیدن پورت‌های باز و سرویس‌های در حال شنود (Listening) |

### نکته مهم: موقت بودن در برابر دائم کردن Aliasها (Persistence)

1. **حالت موقت:**اگر در ترمینال بنویسی:
```bash
 `alias gs='git status'`
```
این دستور کار می‌کند، اما به محض بستن پنجره ترمینال یا ری‌استارت، **از بین می‌رود**.

2. **حالت دائمی (Permanent):**
    
    برای اینکه همیشه فعال بماند، باید آن را در فایل کانفیگ شل کاربر ذخیره کنی:
    
    - فایل `~/.bashrc` (برای شل Bash)
    - فایل `~/.zshrc` (اگر از Zsh استفاده می‌کنی)
    
    **روش ذخیره دائمی:**
    ```bash
    `echo "alias gs='git status'" >> ~/.bashrc    source ~/.bashrc`or . .bashrc
    ```

---
### چطور یک Alias را موقتاً دور بزنیم (Bypass)؟

اگر برای `rm` الیاس `rm -i` تعریف کرده باشی و بخواهی یک‌بار بدون پرسیدن تاییدیه اجرا شود، کافیست یک بک‌اسلش (`\`) اول آن بگذاری:
```bash
`\rm file.txt`
```

این کار باعث می‌شود شل دقیقاً باینری اصلی دستور را صدا بزند و alias را نادیده بگیرد.
